# 开发文档

本目录说明系统的技术架构、开发环境、演示数据和生产部署方式。

| 文档 | 内容 |
|---|---|
| [开发指南](guidance.md) | 依赖安装、环境配置、数据库初始化、服务管理、演示数据和开发数据重置 |
| [技术决策与系统架构](技术决策.md) | 双前端与四角色后端、实时事件、任务队列、资源权限、文件上传、审计及文本规则 |
| [部署说明](部署说明.md) | 公网接入、生产资源、构建发布、服务激活、健康检查、备份与版本保留 |

开发使用 `backend/.env.dev`，生产发布从 `shared/.env.prod` 取得配置。API、WS、worker 和 scheduler 共享同一环境的数据服务，按角色使用独立连接池。
