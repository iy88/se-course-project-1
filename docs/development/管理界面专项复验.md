# 管理界面专项复验

## 实现与权限范围

管理端侧栏增加“审计查询”（`/audit`）。支持事件类型、操作者ID、目标类型/ID、执行结果、请求ID和起止时间精确筛选；分页沿用已提交条件，每页20/50/100条。详情只读展示白名单字段及脱敏的变更前后记录，无修改或删除入口。时间输入明确浏览器时区，提交ISO时间；列表使用北京时间。失败清除旧列表并可重试，过期响应不能覆盖新查询。

消息举报、交易争议和异常交易的认领管理员可在事项详情打开“事项关联会话（只读）”，每页30条并加载更早消息。会话ID由已授权事项详情解析提供；不提供任意会话搜索。消息举报标记目标消息，正文按纯文本显示。其他事项不出现入口。服务端继续校验认领人与直接关联范围；已处置事项仍按原权限只读。管理员不加入会话、不发送消息、不推进参与方已读。切换事项、重新加载或权限失效时清理旧内容，防止显示上一事项记录。
