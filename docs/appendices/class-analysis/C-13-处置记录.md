# C-13 处置记录

状态：候选类分析初稿，负责人张新悦；是否拆出独立沟通对象待分析，未开展人工模型评审。

## 职责与边界

记录管理员对某事项的认领、处置结论、理由与执行者，并承载处置通知与沟通单的留痕。处置对象包括商品审核、举报、交易争议、异常交易及账户封禁相关事项。

边界：与 C-04 审核记录分工——C-04 只记商品审核结论，C-13 记管理事项的处理与沟通；与 C-12 分工——C-12 是举报提交内容与进度，C-13 是处理结论与通知沟通。处置通知与沟通单由本类承担并关联沟通消息，已定不另立对象；沟通单不是买卖双方 IM；不预设独立工单系统、派单或转派功能（BR-51）。

## 主要业务属性

事项类型与对象、认领人、处置结论与理由、执行时间、沟通记录（说明、反驳／申诉及管理员回复）。不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 处置记录—认领管理员（C-01） | 0..* : 1 | 同一事项同时仅归属一名管理员 |
| 处置记录—举报记录（C-12） | 0..* : 0..1 | 一条举报对应一份处置结论 |
| 处置记录—商品／评论／消息／评价 | 0..* : 0..* | 违规对象，按事项必要范围访问 |
| 处置记录—账户限制记录（C-14） | 0..* : 0..* | 处置涉及封禁时关联 |
| 处置记录—交易记录（C-09） | 0..* : 0..* | 争议、异常交易及冻结相关 |

## 关联规则、场景与用例

- 共享待处理池由管理员主动认领，同一事项同时仅一名认领人；处理权限限认领人：BR-51。
- 审核、举报、账户限制及解除须留痕，记录执行者、时间、结论与理由：BR-33、TR-22—TR-24。
- 处置通知与沟通单向受处置用户保留说明、反驳／申诉及管理员回复；解除须管理员确认：BR-22、BR-53。
- 违规处置涉及交易时冻结整个进度、禁止该笔交易双方 IM、撤销涉事商品公开访问：BR-53、DT-02、DT-03。
- 解除后自动恢复原权限及因处置停止的展示，不将原非在售商品变为在售：BR-22、TR-11。
- 场景：SC-06、SC-07；用例：UC-C08。

## 状态归属

处理进度候选：待处理（共享池）、处理中（已认领）、已处置（含解除）。名称与边界待细化（[5.2](../../requirements/05-行为与状态.md)）；冻结是交易进度的暂停标记，不是处置记录的状态。沟通单是否需独立对象待分析，暂不预设。

## 待决与边界

- 处置通知与沟通单已定由本类承担并关联沟通消息，不另立沟通对象；P-22 仅影响告知与申诉对象范围及 DT-05 口径校对。
- 举报处置不承诺处理时限（BR-50）；其他事项的处置时限在规则中亦未承诺，本类不设超时自动关闭。
