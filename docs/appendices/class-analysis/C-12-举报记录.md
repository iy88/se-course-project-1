# C-12 举报记录

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

描述一次举报的对象、理由、可选证据及处理进度，并与 C-13 处置记录关联。举报由未被封禁的登录用户提交，被举报对象不因举报自动判定违规（BR-20）；处理结论由认领该事项的管理员记录，结果确认后隐去用户与管理员信息向所有已登录用户公开（BR-20、BR-50）。

边界：举报可指向商品、评论、消息、评价或用户；本条不设计证据形式与存储实现，证据要素待 P-23。举报记录不等于处置记录，也不代替交易争议。

## 主要业务属性

举报者、被举报对象及对象类型、理由、可选证据、处理结论与理由、匿名公开结果。属性为业务口径描述，不写字段类型或索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 举报记录—举报者（C-01） | 0..* : 1 | 未被封禁的登录用户 |
| 举报记录—被举报对象 | 0..* : 1 | 对象可为商品、评论、消息、评价或用户 |
| 举报记录—处置记录（C-13） | 0..* : 0..1 | 处置结论与理由，归属认领管理员 |
| 举报记录—账户限制记录（C-14） | 0..* : 0..* | 处置涉及封禁时关联 |

同一用户对同一对象能否重复举报待 P-23，本类不预设唯一性约束。

## 关联规则、场景与用例

- 未被封禁的登录用户可举报商品、评论、消息、评价或用户，提交理由及可选证据：BR-20。
- 管理员按举报核查，记录结论及理由，可不予处理、移除违规内容或封禁账户；证据不足记录无法认定：BR-21。
- 举报结果须经管理员确认后匿名公开，确认前不可见：BR-20、BR-50、DT-05。
- 涉及私聊证据时，仅认领管理员查看该事项处理所需的相关消息：BR-18、BR-51。
- 违规处置涉及交易时按冻结规则处理，并撤销涉事商品公开访问：BR-53。
- 封禁期间禁止新增举报，已有记录保留只读：BR-22。
- 场景：SC-07；用例：UC-C07。

## 状态归属

进度：待处理（进入共享待处理池）、处理中（已认领）、无法认定、认定违规并处置（可含移除内容或封禁）。结果公开以管理员确认为前提，确认前不可见。具体状态名称待细化，见 [5.2](../../requirements/05-行为与状态.md)。

## 待决与边界

- P-22：处置告知与申诉的对象范围，以及 DT-05 与 BR-22／53 口径校对，影响本类与 C-13 的协作。
- P-23：举报证据要素、同一用户重复举报是否限制、评价是否可删除。
- 举报处理时限：不承诺（BR-50），不在本类增加倒计时或自动关闭。
