# C-14 账户限制记录

## 职责与边界

记录账户封禁及解除的原因、执行者、时间与处置依据，支撑限制期间的权限执行与解除后按原资格恢复（BR-32）。

边界：交易冻结不是账户限制，由交易进度的暂停标记表达（BR-33）；本类不记录买卖双方 IM 限制，也不记录商品展示资格，后者由 C-02 与 TR-10 表达。限制记录保留、不覆盖历史。

## 主要业务属性

受限账户、限制类型、原因与处置依据、执行者、生效及解除时间。

## 关联与数量约束

| 关联 | 关联重数 | 说明 |
|---|---|---|
| 账户限制记录—受限账户（C-01） | `0..* : 1` | 一次封禁一条记录，解除后保留 |
| 账户限制记录—处置记录（C-13） | `0..* : 0..*` | 处置依据与解除确认 |

## 关联规则、场景与用例

- 封禁后禁止发布／修改商品、交易操作、评论、IM、新增举报及评价既往已完成交易；本人相关记录保留只读：BR-32。
- 允许使用本人处置通知与沟通单与认领管理员沟通、反驳／申诉：BR-32、BR-33。
- 封禁账户可浏览原本有权查看的公共内容及本人收藏；禁止收藏／取消收藏等业务写操作：BR-32、DT-03。
- 仅交易冻结且账户未封禁时，既往已完成交易评价、其他举报与收藏操作仍允许：BR-33。
- 解除后自动恢复原权限及因处置停止的展示：BR-32。
- 场景：SC-07；用例：UC-C08。

## 状态归属

状态：未限制、封禁生效、已解除（记录保留）。封禁与交易冻结分别表达，单方确认或争议解决后，既有账户封禁继续生效（BR-33）。

## 补充业务约束

- 交易冻结通过 C-09 的进度暂停标记表达，账户封禁及解除通过本类记录。
- 实际受处置者可查看本人原因并通过 C-13 申辩；限制解除后仍保留处理历史。
