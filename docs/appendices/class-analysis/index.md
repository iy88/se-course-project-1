## 关键业务数据说明

本表汇集关键业务数据的含义、产生来源、维护角色和隐私访问入口；具体属性、数量约束及规则由所链接的类分析与第4章定义。用户ID用于稳定关联主体；商品、交易、审核及处置记录分别表达发布内容、交易进度和管理依据，不能相互替代。

| 业务数据及定义入口 | 关键含义 | 产生来源与维护角色 | 主要约束、隐私及访问依据 |
|---|---|---|---|
| [C-01 用户账户](C-01-用户账户.md) | 用户ID、登录邮箱、显示名称、账户状态与管理资格；买卖身份随具体业务确定 | 用户注册与本人资料维护；系统分配稳定ID，管理员按规则实施账户限制 | 邮箱唯一，改名或换邮箱不改变历史归属；本人身份验证、邮箱与密码保护见BR-20—BR-22、4.19及第6章6.6；不核验校园身份 |
| [C-02 商品](C-02-商品.md) | 发布内容、标价、分类、生命周期、展示资格及编辑历史 | 卖方发布、合规编辑与上下架；审核、交易和管理事件形成相应状态或展示限制 | 公共读取须登录并满足展示资格；完整编辑历史不对普通第三方开放，本人／相关买方／认领管理员范围见BR-10—BR-15、4.18 |
| [C-03 商品分类](C-03-商品分类.md)、[C-16 禁发范围](C-16-禁发范围.md) | 分类主名、别名及启用状态；当前禁发细目、修改主体与时间 | 管理员维护；卖方随商品申请标签，认领审核管理员按流程处理；禁发范围独立维护 | 登录用户可按资格读取，普通用户不得维护；分类申请、别名、停用及历史口径见4.16，禁发范围见BR-13 |
| [C-04 审核记录](C-04-审核记录.md) | 每次商品审核的结论、原因、时间与审核主体 | 认领管理员提交审核结论；商品修改重提形成新的审核记录 | 历次审核独立保留，不覆盖旧结论；发布者查看本人审核结果，管理处理限事项认领人，见BR-10、BR-13、BR-34 |
| [C-05 收藏记录](C-05-收藏记录.md) | 本人与商品的收藏关系及失效提示 | 本人收藏或取消收藏，系统按商品当前资格显示内容 | 收藏清单仅本人可见；失效后不据收藏获得商品访问资格，封禁期间只读，见BR-16、BR-32及4.18 |
| [C-06 商品评论](C-06-商品评论.md) | 商品页交流内容、作者、时间与删除／移除依据 | 有资格用户评论、卖方回复；作者删除或管理员按违规事项处理 | 不等同交易约定或评价；读取依商品展示资格，写入受封禁与内容限制，见BR-17、BR-32及4.11 |
| [C-07 会话](C-07-咨询会话.md)、[C-08 消息](C-08-消息.md) | 双人普通私聊、逐笔交易分支、消息归属及独立已读进度 | 用户发起普通私聊并发送消息；有效请求产生交易分支及系统消息 | 私人内容限会话参与者，管理员限认领事项必要范围；归档、冻结禁发及历史读取见BR-18、BR-19、BR-33、BR-34，不因消息已读确认交易 |
| [C-09 交易记录](C-09-交易记录.md) | 请求与交易阶段、商品当时内容、双方约定与变更、当前确认及状态历史 | 买方发起请求，卖方接受／拒绝；双方确认约定及业务操作；系统识别超时，认领管理员有据调整 | 同一商品同时至多一笔锁单；交易金额可不同于标价，不记录实际支付流水或核实履约；私人记录限双方及必要管理访问，见BR-01—BR-08、4.15、4.18 |
| [C-10 交易完成确认记录](C-10-交易完成确认记录.md) | 本方声明交付与支付均完成的确认人、时间、可选说明及当前有效标记 | 交易双方分别提交本人确认；恢复流程清空当前标记并保留历史 | 每方每笔至多一条当前有效确认，历史可多轮；用户声明不等同平台核验，见BR-27—BR-30；读取随交易资格 |
| [C-11 评价](C-11-评价.md) | 已完成交易的评分、文字、评价者与被评价者 | 已完成交易的有资格双方各自提交；管理员处理违规评价并留据 | 每方每笔至多一条，评分1—5；不支持本人修改／删除，仅本人发表／收到及必要管理访问，不提供公开评价列表，见BR-24 |
| [C-12 举报记录](C-12-举报记录.md)、[C-13 处置记录](C-13-处置记录.md)、[C-14 账户限制记录](C-14-账户限制记录.md) | 举报对象与证据、认领及处置依据、问询／申辩、封禁与解除历史 | 用户提交举报及本人说明／申辩；管理员认领、核查、处置或解除限制；异常交易等业务事件进入管理流程 | 举报身份及无关私人内容不得披露；未认领可无认领人，处理须唯一认领人；用户与管理员仅按相关事项资格访问，公开结果按匿名规则，见BR-19、BR-25—BR-26、BR-32—BR-34、4.17—4.18 |
| [C-15 站内通知](C-15-站内通知.md) | 业务事件、接收人、来源事项与通知已读标记 | 系统随有效业务事件产生；接收人打开具体通知推进已读 | 每条通知一名接收人，不复制原业务结论；旧入口重查权限，不额外授予私人访问权；通知与聊天独立已读，见4.17 |

共同访问约束见[统一权限矩阵](../../requirements/04-规则与权限.md#411-统一权限矩阵)；历史保留、逻辑删除及关联内容访问见[历史与公开范围](../../requirements/04-规则与权限.md)。记录不按时间自动清理，也不承诺永久保存；具体属性及维护行为仍从各类分析进入。
