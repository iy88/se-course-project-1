# C-05 收藏记录

## 职责与边界

记录用户与商品的收藏关系，支撑本人收藏清单、失效提示与只读访问。收藏清单仅本人可见（BR-16）。本类不承载商品信息或交易结果，也不向他人公开收藏关系。

边界：在售搜索与详情分别按当前资格校验；交易中商品仍有登录详情访问，收藏项是否提示失效按 BR-14、BR-16 判断。封禁期间收藏只读，仅交易冻结不限制无关收藏操作（BR-32、BR-33）。

## 主要业务属性

收藏者、商品、收藏时间。

## 关联与数量约束

| 关联 | 关联重数 | 说明 |
|---|---|---|
| 收藏记录—收藏者（C-01） | `0..* : 1` | 仅本人清单，不向他人公开 |
| 收藏记录—商品（C-02） | `0..* : 1` | 商品撤销公开访问后仅提示失效，不泄露内容 |

## 关联规则、场景与用例

- 用户可收藏／取消收藏公开商品，清单仅本人可见：BR-16。
- 真正撤销公开访问的商品只保留失效提示，不泄露不可见内容：BR-14、BR-16。
- 封禁期间允许查看本人收藏，禁止收藏／取消收藏：BR-32。
- 仅交易冻结不限制无关收藏操作：BR-33。
- 场景：SC-03；用例：UC-C04。

## 状态归属

可表达“有效”与“失效提示”两种展示结果，属展示条件而非生命周期状态；不因商品交易中而删除收藏记录。本类不设独立状态模型。

## 补充业务约束

- 本人收藏清单按收藏者归属管理，商品访问资格变化后保留对应收藏关系及失效提示。
