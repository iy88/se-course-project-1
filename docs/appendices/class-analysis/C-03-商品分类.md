# C-03 商品分类（单级标签）

## 职责与业务属性

组织商品归类及筛选，保存分类标识、主名称、别名、启用状态及管理依据；无父子层级、不设排序。同义别名归属同一实体，不创建重复分类；商品可多选，筛选要求全部所选标签及关键词／价格条件同时满足。

## 关联与管理行为

| 事项 | 结果与边界 |
|---|---|
| 商品关系 | 多对多，审核通过商品至少一个获认可标签；一类可对应多件商品 |
| 新建 | 管理员可主动创建；用户随商品申请，至少选已有标签或提交一个申请才能送审 |
| 关联审批 | 商品通过时才一并批准新标签／同义别名；商品退回或拒绝不单独公开申请。名称不合适可选已有合适标签并说明原因，否则按不通过记录并写明退回补充原因 |
| 改名／别名 | 改主名保持身份，旧名作别名；当前展示新名，交易历史留当时名称；可移除别名，不改商品归属／历史 |
| 停用 | 新发布不可选；旧商品保留、不下架或影响交易，有公开在售商品时保留筛选入口 |
| 删除 | 关联过商品仅停用；从未关联可逻辑删除，不硬删除 |
| 纠类 | 管理员可有依据纠正交易中商品分类，记录前后内容、原因、主体和时间并通知卖方；不改交易状态、约定及历史交易内容 |

分类不承担商品展示资格或交易状态，不与禁发物品清单合并。分类维护是管理员的常设职责；私人记录访问按具体事项认领关系及必要范围授权。初始标签条目属于管理员准备，按校园物品类别配置。

## 依据

[规则权限4.16](../../requirements/04-规则与权限.md#416-单级分类标签)、BR-11、BR-12、BR-15；FR-13；UC-C02／C13；SC-03／10。

## 主要业务属性

分类标识、主名称、别名、启用状态。

## 必要行为与协作

| 行为职责 | 关联业务属性 | 协作目标 |
|---|---|---|
| 解析主名与别名 | 分类标识、主名称、别名、启用状态 | UC-C02、UC-C03、UC-C13 |
| 维护分类及停用状态 | 分类标识、主名称、别名、启用状态 | UC-C02、UC-C03、UC-C13 |
| 提供多标签筛选依据 | 分类标识、主名称、别名、启用状态 | UC-C02、UC-C03、UC-C13 |

业务动作由关联用例的当前主体、对象归属和状态资格触发；协作顺序见[完整用例索引](../use-cases/index.md)。
