# C-03 商品分类

状态：候选类分析初稿，负责人张新悦；维护操作受 P-18 限制，未开展人工模型评审。

## 职责与边界

为商品提供统一归类，并作为检索与筛选的分类依据（BR-24、BR-52）。分类由平台管理员统一维护（FR-13），维护权限不因“管理”而扩大为可任意删除带历史商品的分类。

边界：分类属于商品关键内容之一（BR-12），修改分类受商品修改规则约束；分类维护与禁发范围维护（BR-40）分开，不合并为同一配置对象。分类不承担商品展示资格或交易状态。

## 主要业务属性

名称、启用状态。已定设置启用状态、不设排序；操作集与初始分类待 P-18。不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 商品分类—商品 | 1 : 0..* | 商品在任一时刻归属一个分类（候选）；停用或删除后的既有商品处理待 P-18 |

## 关联规则、场景与用例

- 分类属于商品关键内容，交易中／已售出禁止修改：BR-12、BR-15。
- 筛选支持关键词、分类与价格区间组合，含端点，无匹配返回空列表：BR-24、BR-52。
- 维护者已定为平台管理员；操作集、初始分类、停用／删除及既有商品与筛选处理待 P-18。
- 场景：SC-03；用例：UC-C13。

## 状态归属

启用／停用为已定表述；停用后既有商品如何显示及是否影响筛选待 P-18，本节不预设。分类不设交易类状态。

## 待决与边界

- P-18：新增、改名、停用、删除的操作集；初始分类；停用／删除后既有商品与筛选处理。启用状态已定设置，排序不设。
- 管理员维护权限仍需与 BR-51 的认领机制区分：分类维护是常设管理职责，不是按事项认领。
