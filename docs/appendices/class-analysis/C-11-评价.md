# C-11 评价

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

保存已完成交易双方的互评：评分、文字、评价者与被评价者及提交时间；在商品详情页向所有已登录用户展示（BR-19）。评价以交易完成为前提，不评价未完成交易，也不代他人评价。

边界：评价与商品页评论（C-06）是不同对象，不合并；首版不支持用户修改已提交评价；管理员可处理违规评价并记录理由（BR-19）。评价不承担举报处理，举报走 C-12。

## 主要业务属性

所属交易、评价者、被评价者、评分、文字、提交时间。评分范围为项目设定；不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 评价—交易记录（C-09） | 0..2 : 1 | 每方每笔交易至多一条 |
| 评价—评价者／被评价者（C-01） | 各 1 | 必须是本笔交易双方 |

## 关联规则、场景与用例

- 交易完成后未被封禁的双方可互评，每方每笔交易一条，含 1—5 分及文字：BR-19。
- 不得评价未完成交易或代他人评价：BR-19。
- 首版不支持修改已提交评价；管理员可处理违规评价并记录理由：BR-19。
- 评价在商品详情页向已登录用户展示：BR-19。
- 封禁期间禁止评价此前已完成交易；仅交易冻结允许既往已完成交易评价：BR-22、BR-53。
- 场景：SC-07；用例：UC-C07。

## 状态归属

状态：已提交（不可修改）、管理员已处理（违规，记录理由）。用户自行删除是否允许待 P-23，本节不预设；评价不因商品下架或撤销公开访问而删除。

## 待决与边界

- P-23：评价是否可删除（用户删除与管理员处理需区分），影响本类是否引入“已删除”结果。
- 评分是否展示平均分与分布：规则只要求展示评价本身，不预设聚合口径（BR-19、BR-34 不含评价聚合）。
