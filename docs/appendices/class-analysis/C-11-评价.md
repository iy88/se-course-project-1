# C-11 评价

## 职责与边界

保存已完成交易双方的互评：评分、文字、评价者与被评价者及提交时间；仅在本人“我的评价”按发表／收到查看（BR-24）。评价以交易完成为前提，不评价未完成交易，也不代他人评价。

边界：评价与商品页评论（C-06）是不同对象，不合并；首版不支持用户修改已提交评价；管理员可处理违规评价并记录理由（BR-24）。评价不承担举报处理，举报走 C-12。

## 主要业务属性

交易、评价者及被评价者、评分〔1—5分〕、文字、提交时间、违规处理依据。

## 关联与数量约束

| 关联 | 关联重数 | 说明 |
|---|---|---|
| 评价—交易记录（C-09） | `0..2 : 1` | 每方每笔交易至多一条 |
| 评价—评价者／被评价者（C-01） | 各 1 | 必须是本笔交易双方 |

## 关联规则、场景与用例

- 交易完成后未被封禁的双方可互评，每方每笔交易一条，含 1—5 分及文字：BR-24。
- 不得评价未完成交易或代他人评价：BR-24。
- 首版不支持修改已提交评价；管理员可处理违规评价并记录理由：BR-24。
- 评价仅向本人发表／收到归属开放读取，认领管理员按事项必要范围访问，不在商品页或公开评价列表展示：BR-24。
- 封禁期间禁止评价此前已完成交易；仅交易冻结允许既往已完成交易评价：BR-32、BR-33。
- 场景：SC-07；用例：UC-C07。

## 状态归属

评价提交后保存。管理员违规处理记录处理结果与理由，原评价及处理依据关联保留。

## 补充业务约束

- 不提供用户自行删除评价；管理员违规处理保留，处理须记录理由。
- 本期仅查看本人发表／收到的评价，不提供公开评价列表，不新增评分聚合口径（BR-24、BR-31 不含评价聚合）。
