# C-08 消息

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

保存咨询会话内的文字消息及发送者、发送时间，并承载访问资格：仅会话双方与认领事项的管理员可读取。消息不向非会话成员公开（BR-26）。

边界：首版不支持撤回、编辑、附件及群聊；消息不承载处置通知与沟通单（BR-26、BR-22）。管理访问限于认领事项处理所需的相关消息（BR-18、BR-51）。

## 主要业务属性

所属会话、发送者、内容、发送时间。不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 消息—咨询会话（C-07） | 0..* : 1 | 消息归属会话 |
| 消息—发送者（C-01） | 0..* : 1 | 必须是会话参与方 |

## 关联规则、场景与用例

- 会话内发送文字消息，不提供撤回、编辑与附件：BR-26。
- 封禁或涉事冻结期间禁止发送，历史消息保留读取：BR-22、BR-27、BR-53。
- 管理员仅在举报或争议处理时查看相关消息：BR-18、BR-51。
- 场景：SC-04；用例：UC-C04。

## 状态归属

消息不设生命周期状态；可表达的是发送资格与读取资格随封禁、冻结、商品展示资格变化。消息一经发送不修改，故不需要状态机。

## 待决与边界

- 未读提示的归属（会话级还是消息级）与 FR-11 通知的关系待 P-20，本类不预设已读规则。
