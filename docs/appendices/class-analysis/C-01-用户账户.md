# C-01 用户账户

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

承载校园用户的账户身份与登录入口，并作为其他业务对象的参与方：商品发布者、交易买方或卖方、评论作者、会话参与方、评价者、举报者、确认人、认领事项的管理员。账户负责提供身份，不代替各业务对象保存业务结果。

边界：买方、卖方是相对于商品或交易的身份，不是互斥账户类型，也不另立为类；管理员不是账户类型，而是“认领某事项”的关系；首版不核验校园身份或学籍；账户不承担站内通知（候选 C-15）与处置沟通内容（C-13）。

## 主要业务属性

账户标识（邮箱或手机号，全平台唯一）、显示名称、账户状态、限制期间。属性为业务口径描述，不写字段类型、长度或索引，不构成数据字典。账户不保存学籍、教职工身份信息、付款金额或支付流水。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 用户账户—商品 | 1 : 0..* | 作为发布者；一人可有多件商品 |
| 用户账户—收藏记录 | 1 : 0..* | 仅本人清单可见 |
| 用户账户—商品评论 | 1 : 0..* | 作为作者 |
| 用户账户—咨询会话 | 1 : 0..* | 作为买方或卖方参与 |
| 用户账户—交易记录 | 1 : 0..* | 分别作为买方、卖方 |
| 用户账户—评价 | 1 : 0..* | 作为评价者或被评价者 |
| 用户账户—举报记录 | 1 : 0..* | 作为举报者 |
| 用户账户—账户限制记录 | 1 : 0..* | 多次封禁与解除分别记录 |

账户标识重复注册应被拒绝，不自动合并或接管既有账户（BR-36）。

## 关联规则、场景与用例

- 注册、登录、退出、自助重置、修改密码、更换绑定标识及修改显示名称：BR-35—BR-38、FR-01；新增细则见 P-19。
- 封禁期间禁止业务写操作，保留只读访问与管理沟通；仅交易冻结不扩大为账户封禁：BR-22、BR-53。
- 评价与举报资格：已完成交易、未被封禁；BR-19、BR-20。
- 管理访问限本人认领事项及必要范围：BR-18、BR-51。
- 场景：SC-01、SC-07；用例：UC-C01、UC-C08、UC-C12。

## 状态归属

账户限制状态：未限制、封禁生效、已解除（记录保留），依据 BR-22、TR-24。账户本身不设“管理员”状态；注销或停用不在本期范围，未在规则中出现，不预设。

## 待决与边界

- P-19：退出登录的会话处理、修改密码与更换绑定标识的验证方式、显示名称修改限制。
- P-22：处置告知与申诉的对象范围，影响本类与 C-13 的协作。
- 管理身份是否单列，候选结论为不单列、以认领关系表达；待评审确认。
