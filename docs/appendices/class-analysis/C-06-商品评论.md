# C-06 商品评论

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

承载登录用户在商品页发表的公开咨询，以及卖方对买方评论的回复（BR-47）。评论与交易完成后的评价（C-11）是不同业务对象，不合并、不互相替代。

边界：首版不支持买方之间互相回复；不提供编辑已发布评论；作者可删除本人评论，违规评论由管理员移除并记录理由（BR-26）。评论不承担私聊或处置沟通功能。

## 主要业务属性

所属商品、作者、内容、发表时间、是否已删除及处置理由。不写字段类型与索引；长度与频率阈值留待设计（BR-47）。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 商品评论—商品（C-02） | 0..* : 1 | 评论归属商品 |
| 商品评论—作者（C-01） | 0..* : 1 | 作者可删除本人评论 |
| 商品评论—处置记录（C-13） | 0..* : 0..* | 违规移除须记录理由 |

## 关联规则、场景与用例

- 登录用户可评论已公开展示或处于交易中的商品；已售出禁止评论及回复：BR-16、BR-47。
- 撤销公开访问后不允许新评论；已有评论保留读取：BR-27。
- 卖方回复买方评论，不主动开启新的评论关系：BR-47。
- 作者删除本人评论，管理员可移除违规评论并记录理由：BR-26。
- 封禁期间禁止发表评论：BR-22。
- 场景：SC-04；用例：UC-C04。

## 状态归属

可表达：已发表、作者已删除、管理员已移除（含理由）。删除与移除分别记录，不覆盖对方；已售出后不新增评论属发表资格条件，不是评论状态。

## 待决与边界

- 评论长度与发表频率阈值：BR-47 明确留待设计阶段细化，本类不填数值。
- 评论是否允许被举报、举报后处理路径按 C-12／C-13 既有规则，不另设机制。
