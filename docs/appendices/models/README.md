# 图文件目录

本目录保存PlantUML可编辑源文件及[图索引](index.md)，PNG集中于[渲染目录](../rendered/README.md)。UC-01为系统用例图，UC-02为关键用例能力分组；CL-01为核心类属性及行为，CL-02—CL-04为模块类图；ST-01／ST-02为商品与交易生命周期，ST-03为约定及确认进度，ACT-01—ACT-11为活动图。

共享类在不同模块沿用同一编号。图中的业务属性、必要行为、关联及状态依据正文和逐类分析，实际评审状态由A报告承载。

## 业务流程与模型入口

[图索引](index.md)登记全部类图、状态图、活动图及用例图的业务关联与源文件；章节选择关键图展示，完整PNG尺寸及DPI见[渲染索引](../rendered/README.md)。

模型可编辑源文件与渲染PNG保持一致；实际像素尺寸、DPI及源文件摘要见渲染索引和图片伴随记录。
