# US-10 查看管理统计

## 用户目标与价值

作为平台管理员，我希望查看查询时点指标，并显式选择时间范围或全部统计完成交易，以便按统一口径理解账户、商品、待办和交易结果规模。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-10 |
| 主用例 | UC-C10，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | 统计读取各业务记录，不改变其原业务结果 |
| 场景 | SC-08 |
| 优先级／批次 | 中／3 |
| 触发规律 | 管理员需要了解当前平台业务情况 |
| 规则依据 | BR-06、BR-31 |

## 业务内容与操作资格

- 进入统计先校验管理员身份，当前指标按查询时点统计。
- 用户总数包含封禁用户，另列封禁数；商品各状态数与待审核／举报事项数分别统计。
- 完成交易时间范围由管理员显式选择范围或全部，按结果确认时间计算。
- 统计为业务记录派生数量，不记录付款流水或真实收入。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-10-AC-01 | 普通校园用户 | 访问统计入口 | 拒绝统计访问 | BR-31 |
| US-10-AC-02 | 管理员查看当前指标 | 执行查询 | 显示用户总数及封禁数、各状态商品数、审核／举报待办数及已完成／已终止／有争议交易数 | BR-31 |
| US-10-AC-03 | 尚未选择时间范围 | 进入完成交易范围统计 | 等待管理员显式选择范围或全部，不套用默认时间范围 | BR-31 |
| US-10-AC-04 | 已选择范围或全部 | 统计完成交易数 | 按交易结果确认时间计算，与查询时点状态指标分别标明 | BR-31 |
| US-10-AC-05 | 范围无匹配记录 | 查询 | 返回空结果或零计数，不推断缺失原因 | BR-31 |
| US-10-AC-06 | 交易记录含拒绝、撤回、关闭及终止 | 查看失败交易数量 | 已终止计失败，拒绝／撤回／锁单关闭不计已接受交易失败数；不输出真实资金数据 | BR-06、BR-31 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验管理员资格；提供用户总数及封禁账户统计口径 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 生命周期状态 | 提供查询时点的各状态商品计数 |
| [C-04 审核记录](../class-analysis/C-04-审核记录.md) | 商品及当次内容、审核结论 | 提供查询时点未完成审核计数，结合 C-13 待审事项区分商品状态与待办 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 请求及交易状态、结果确认时间 | 提供完成、终止、争议状态计数及所选时间范围完成数；区分请求结束与失败交易 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 处理进度、处理结论 | 提供查询时点待处理举报计数 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项类型、处理进度 | 读取审核及举报待处理事项，提供计数依据，不认领或处置事项 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 提供当前有效封禁计数依据，不执行封禁或解除 |
