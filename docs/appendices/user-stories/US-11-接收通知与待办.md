# US-11 接收通知与待办

## 用户目标与价值

作为校园用户，我希望收到与本人资格相关的站内提醒并进入当前事项，以便及时处理业务变化，区分阅读消息与正式确认。平台管理员通过共享处理池查看待办，不接收站内通知。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-11 |
| 主用例 | UC-C11，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C02、UC-C04、UC-C05、UC-C07、UC-C08、UC-C14、UC-C12 |
| 场景 | SC-11及各业务事件通知条目 |
| 优先级／批次 | 中／2 |
| 触发规律 | 审核、请求、约定、完成、取消、商品编辑、举报及管理事件生效 |
| 规则依据 | FR-11；4.17；BR-01、BR-04、BR-10、BR-18、BR-25、BR-33、BR-34 |

## 业务内容与操作资格

- 按事件类型及接收人资格产生通知，关联原业务事项，通知中心和分支入口定位同一请求；管理员待办来自共享处理池，不发送站内通知。
- 用户查看通知列表和具体通知；仅打开具体通知才标为已读。
- 待办汇总本人当前有资格且需处理的请求、约定、完成确认及问询等事项；办结或无需本人处理后移出，原业务历史与通知保留，进入时重新校验当前资格。
- 进入旧通知时重新校验身份及对象资格，显示事项当前状态。
- 聊天消息按会话／分支实际展示范围单独标读；业务操作仍在对应入口明确执行。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-11-AC-01 | 有效请求已创建 | 查看卖方提醒及通知中心 | 提醒与交易分支定位同一请求，不重复生成请求 | BR-01；4.17 |
| US-11-AC-02 | 多个未读通知 | 仅打开列表或其中一条通知 | 列表不标读；打开哪一条仅该通知标为已读；已读不消除未办结待办，办结或无需本人处理后自动移出 | 4.17 |
| US-11-AC-03 | 通知及聊天均未读 | 将通知读完 | 聊天未读保持，聊天消息按具体分支实际展示范围标读 | BR-18；4.17 |
| US-11-AC-04 | 请求已撤回、关闭或交易已结束 | 从旧通知进入 | 显示当前状态并校验当前资格，旧入口不能继续执行失效操作 | 4.17 |
| US-11-AC-05 | 审核、约定、完成、取消、编辑或管理事件生效 | 按事件发送提醒 | 接收方和内容符合4.17；单方确认只提醒待确认方，未通知为交易已完成；管理员待办从共享池读取，不发送站内通知 | 4.17、BR-34 |
| US-11-AC-06 | 收到他人事项链接 | 尝试访问 | 拒绝超出资格的私人内容；已读不代替请求接受、约定确认或完成确认 | BR-19、BR-27；4.17 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验通知接收人、关联事项访问资格及管理员共享池查看资格 |
| [C-04 审核记录](../class-analysis/C-04-审核记录.md) | 商品、审核结论、拒绝原因 | 提供审核结果事件及当前内容，供通知定位，不在通知入口重新审核 |
| [C-07 IM会话](../class-analysis/C-07-咨询会话.md) | 会话类别、参与双方、所属交易分支、归档标记 | 定位通知关联的会话或分支，区分各分支消息已读范围 |
| [C-08 消息](../class-analysis/C-08-消息.md) | 所属分支、关联请求、接收方已读标记 | 读取分支消息及未读；仅按实际展示范围标读；本人发送成功同时推进至本消息序号并清除较早未读，不被通知已读替代 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 请求或交易标识、当前状态、相关事件 | 提供业务事件及旧通知所指事项的当前结果，阻止失效入口继续操作 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 举报标识、处理进度、可公开结论 | 提供举报结果事件及本人可见内容，不开放对方申辩 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、认领管理员、处理进度、问询及处置结果 | 提供问询或处置事件及有资格的沟通入口；管理员待办从共享池读取 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 业务事件、接收人、来源业务对象、内容、产生时间、未读标记 | 生成并查看通知；打开具体通知标读，进入事项时重新校验资格 |
