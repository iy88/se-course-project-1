# US-03 检索商品

## 用户目标与价值

作为校园用户，我希望组合关键词、分类标签和价格区间查找商品并查看详情，以便找到符合需要且当前有资格查看的闲置物品。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-03 |
| 主用例 | UC-C03，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C09、UC-C13 |
| 场景 | SC-03、SC-10 |
| 优先级／批次 | 高／1 |
| 触发规律 | 有物品需求或浏览在售商品 |
| 规则依据 | BR-14、BR-15、BR-22；4.16 |

## 业务内容与操作资格

- 登录后按关键词、一个或多个标签及价格区间组合查询。
- 多标签要求全部匹配；关键词、标签、价格条件共同生效，价格区间包含端点。
- 结果只含当前公开可交易且有展示资格的商品；打开详情时重新校验资格。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-03-AC-01 | 已登录且有匹配商品 | 同时使用关键词、多标签和价格区间 | 返回同时满足全部条件的公开可交易商品，价格端点可命中 | BR-15 |
| US-03-AC-02 | 分类具有主名称及别名 | 使用主名或别名筛选 | 定位同一分类，别名不重复计作标签 | 4.16 |
| US-03-AC-03 | 没有满足条件的商品 | 执行查询 | 显示空列表和无匹配商品提示 | BR-15 |
| US-03-AC-04 | 商品处于交易中 | 搜索或通过已有链接访问详情 | 不进入在售搜索；登录用户可按展示资格查看详情 | BR-14、BR-15 |
| US-03-AC-05 | 商品已下架或被撤销公开访问 | 访问公开详情或旧链接 | 拒绝公开详情访问；本人历史及既有事项按对应资格处理 | BR-14；4.18 |
| US-03-AC-06 | 访问者未登录 | 检索、查看列表或详情 | 引导登录，不返回业务内容 | BR-22 |
