# US-14 处理异常交易

## 用户目标与价值

作为交易双方及认领事项的管理员，我希望让单方确认超时的交易进入可追溯管理处理并知晓恢复结果，以便避免超时被误判为成交或取消，保留双方说明与处理依据。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-14 |
| 主用例 | UC-C14，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C05、UC-C08、UC-C09、UC-C11 |
| 场景 | SC-09、SC-05、SC-06、SC-11 |
| 优先级／批次 | 中／3 |
| 触发规律 | 已有有效约定且一方统一完成确认，另一方7天未回应；超时由系统内部识别 |
| 规则依据 | BR-04、BR-05、BR-07、BR-08、BR-33、BR-34；4.15、4.17 |

## 业务内容与操作资格

- 超时转异常并冻结、锁单保持，进入共享池由一名管理员认领。
- 双方读取本人历史并通过管理事项说明／申辩，买卖双方互动和推进暂停。
- 认领管理员核查并留据调整状态，通知双方；可调整完成但不伪造双方确认。
- 恢复进行中保留有效约定、清当前确认，恢复本身不解冻；完成／终止自动解除本笔冻结、归档分支。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-14-AC-01 | 一方确认后有效等待累计7天未回应，未进入争议且当前未冻结 | 系统识别超时 | 转异常并冻结、商品锁单保持，不自动成交或取消 | BR-05 |
| US-14-AC-02 | 等待期进入争议 | 处理原计时 | 争议视为回应，原计时结束；恢复不启动计时，任一方重新提交完成确认后才开始完整等待 | BR-05、BR-07 |
| US-14-AC-03 | 异常事项待处理 | 管理员认领 | 同一事项仅一名认领人有权核查处理，相关私人访问限必要范围 | BR-19、BR-34 |
| US-14-AC-04 | 交易被冻结 | 双方尝试交易推进或相互发消息 | 拒绝相应操作，双方历史只读访问及管理沟通保留，第三方会话按各自资格；已有单方确认后冻结须暂停旧计时，仅解冻且原确认有效时续算剩余时间 | BR-33；D-51 |
| US-14-AC-05 | 管理员恢复进行中 | 查看约定与当前确认 | 保留未调整有效约定及历史，清当前确认；恢复不自动解冻，非结束解除须有依据 | 4.15 |
| US-14-AC-06 | 认领管理员有依据调整完成或终止 | 记录并通知处理结果 | 全部转移留据，结束解本笔冻结及锁单、分支归档，其他限制保持；商品默认下架或按资格明确继续 | BR-08、BR-14、BR-33 |
| US-14-AC-07 | 用户提出说明／申辩 | 在本人事项提交 | 管理员回复结论原因并通知，不因提交自动撤销限制 | 4.17—4.18 |
| US-14-AC-08 | 已完成或已终止交易，同商品有或无其他锁单 | 认领管理员提交恢复或其他终态变更 | 一律拒绝，保留现有交易、商品、会话及限制；记录拒绝结果，不重开旧交易 | BR-08；2026-11-14 终态决定 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验交易双方读取、管理沟通及认领管理员调整资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 生命周期状态、展示资格 | 异常期间保持锁单；管理结束交易时释放锁单并按资格处理上架结果 |
| [C-07 IM会话](../class-analysis/C-07-咨询会话.md) | 参与双方、分支所属交易、归档标记 | 按双人冻结范围禁发两类 IM；交易结束归档该笔分支，保留历史 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 交易状态、有效约定、当前确认、等待计时、冻结及转移依据 | 识别超时转异常并冻结；管理调整状态，恢复时清空当前进度，结束解除本笔冻结 |
| [C-10 交易完成确认记录](../class-analysis/C-10-交易完成确认记录.md) | 所属交易、确认人、确认时间、当前有效标记 | 提供单方确认及计时依据；管理恢复时重置当前标记并保留历史 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 异常事项、认领管理员、结论、理由、依据、说明或申辩及回复 | 进入共享池并唯一认领；记录管理调整、解除及沟通依据，回复说明或申辩 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取并保留独立账户封禁，避免交易结束或解冻误解除其他限制 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 异常、冻结、管理调整及解除事件、接收人、来源交易或事项、通知内容 | 通知双方原因、实际恢复范围、剩余限制及管理沟通入口 |
