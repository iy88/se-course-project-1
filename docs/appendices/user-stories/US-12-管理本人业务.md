# US-12 管理本人业务

## 用户目标与价值

作为校园用户，我希望集中查看本人商品、交易、收藏、双向评价、举报及处置沟通，以便不依赖旧通知也能找到并继续处理自己的业务。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-12 |
| 主用例 | UC-C12，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C01、UC-C02、UC-C04、UC-C05、UC-C07、UC-C08 |
| 场景 | SC-12 |
| 优先级／批次 | 中／2 |
| 触发规律 | 返回平台查看历史、查询进度或继续处理本人事项 |
| 规则依据 | FR-12；BR-16、BR-24、BR-25、BR-26、BR-27、BR-32；4.18 |

## 业务内容与操作资格

- 我的商品覆盖全部生命周期和关联请求、审核原因；我的交易覆盖买卖两种身份的请求及交易。
- 收藏及评价按本人归属查询，评价区分我发表与我收到，并定位原交易。
- 我的举报与我收到的举报分别进入，收到事项仅列已实际处置且有访问资格的记录。
- 进入后续操作继续使用各业务的当前资格；结束交易只读，评价或管理沟通按独立规则处理。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-12-AC-01 | 本人有不同状态商品及请求 | 查看我的商品 | 可按本人归属找到全部状态商品、审核原因及关联请求 | 4.18 |
| US-12-AC-02 | 本人曾作为买方或卖方 | 查看我的交易 | 覆盖两种身份的全部请求及交易，结束交易只读并保留历史 | BR-27；4.18 |
| US-12-AC-03 | 本人发表或收到评价 | 查询双向评价 | 仅本人按发表／收到查看并关联交易，商品下架不影响本人读取；他人越权读取及自行修改／删除被拒绝 | BR-24；4.18 |
| US-12-AC-04 | 有本人提交或已实际处置的举报事项 | 查看两个举报入口 | 独立可查，收到的举报隐去举报人身份，未处置事项不额外披露 | 4.18 |
| US-12-AC-05 | 商品或对象已失效但有既有本人举报 | 进入本人事项 | 按既有举报资格读取关联内容，不开放对方申辩及其他私有记录 | 4.18 |
| US-12-AC-06 | 他人业务链接或本人资格已变化 | 从聚合入口继续操作 | 重新校验对象及当前权限；聚合入口不增加访问、删除或重开权限 | BR-27、BR-32；4.18 |
| US-12-AC-07 | 本人买方请求已撤回、拒绝、关闭，或交易已完成、终止，商品之后发生编辑 | 从本人历史入口查看商品编辑历史并核对通知 | 按本人资格可看请求对应内容及之后变更；不向该已结束请求／交易发送商品变更通知，不扩大为其他私人记录访问权 | 4.18；BR-11；D-43 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态 | 校验本人业务归属及当前访问资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、生命周期状态、编辑历史及关联审核结果 | 按本人归属展示全部状态商品和有资格的历史，后续发布维护沿用 UC-C02 |
| [C-05 收藏记录](../class-analysis/C-05-收藏记录.md) | 收藏者、商品、收藏时间 | 读取本人收藏清单及失效提示；收藏写操作沿用 UC-C04 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 买卖双方、请求及交易状态、商品及交易时内容 | 聚合本人两种身份的全部请求和交易；结束记录只读，后续操作沿用 UC-C05／C06 |
| [C-11 评价](../class-analysis/C-11-评价.md) | 交易、评价者、被评价者、评分、文字 | 按本人归属分别读取我发表及我收到的评价，关联交易，拒绝他人越权；商品下架不影响本人读取，不提供修改删除 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 举报者、举报对象、处理进度、可见结论 | 查询我的举报及已实际处置的我收到的举报，隐去举报人身份，不披露未处置事项 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、说明或申辩、回复、当前处理结果 | 按本人事项资格提供沟通入口及可见记录；问询和申辩处理沿用 UC-C08 |
