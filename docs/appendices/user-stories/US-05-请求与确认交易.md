# US-05 请求与确认交易

## 用户目标与价值

作为交易买方或卖方，我希望发起并处理请求、确认交易约定及结果，并按阶段取消或解决争议，以便让平台外交易在系统中有明确、可追溯的过程与结果。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-05 |
| 主用例 | UC-C05，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C06、UC-C04、UC-C09、UC-C11、UC-C14 |
| 场景 | SC-05、SC-06、SC-09、SC-11 |
| 优先级／批次 | 高／1 |
| 触发规律 | 买方购买某件商品，或双方继续处理已经发起的请求／交易 |
| 规则依据 | BR-01—BR-09、BR-14、BR-18、BR-28—BR-30、BR-33；4.15 |

## 业务内容与操作资格

- 购买请求独立创建，自动打开专属交易分支并通知卖方；卖方明确接受前商品不锁单。
- 卖方接受一条请求后锁单，其他待接受请求关闭并通知原因。
- 任一方提出交付时间、文字地点、方式及支付安排，对方明确同意后生效；变更同样须对方确认。
- 有效约定后，双方分别提交一次同时涵盖交付与支付的完成声明；双确认后交易完成。
- 撤回、拒绝、分阶段取消、争议及单方确认超时分别按对应路径处理，结束时归档分支并联动商品。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-05-AC-01 | 商品公开可交易、非本人、无本人重复有效请求且资格允许 | 提交购买请求 | 产生独立待接受记录及交易分支、通知卖方，不提前锁单 | BR-01、BR-02 |
| US-05-AC-02 | 同商品有多个待接受请求 | 卖方接受一条 | 仅一笔锁单，其余请求已关闭并注明其他用户锁单，分别通知买方 | BR-02、BR-03 |
| US-05-AC-03 | 卖方尚未接受 | 买方撤回或卖方拒绝 | 分别记已撤回／已拒绝，归档该分支，后续有资格可另发新请求 | BR-02、BR-06 |
| US-05-AC-04 | 交易进行中、尚无有效约定 | 提出首次约定并由另一方同意 | 交付及支付要素完整后生效；拒绝或提案人撤回后保持锁单和待约定，保留提案及决定历史 | BR-04；4.15 |
| US-05-AC-05 | 已有有效约定 | 提出变更但对方未同意 | 原约定继续有效，变更历史保留，首次约定前取消权不恢复；争议期间暂缓约定操作，恢复后可继续回应待决提案 | 4.15 |
| US-05-AC-06 | 首次约定前或后且未冻结、资格允许 | 发起取消 | 约定前买方可直接取消、卖方须买方同意；约定后双方同意才终止，计失败 | BR-06 |
| US-05-AC-07 | 已有有效约定 | 双方分别完成确认 | 单方只记进度，双方均确认才普通完成；确认是US-06同一操作 | BR-04、BR-28 |
| US-05-AC-08 | 交易存在争议并已解决 | 恢复进行中并继续确认 | 清当前确认、保留历史；有有效约定回待完成，无有效约定回待约定；恢复不启动计时，任一方重新提交完成确认后才重新计算完整 7 天等待 | BR-07 |
| US-05-AC-09 | 单方确认7天未回应 | 触发超时处理 | 转异常并冻结，进入UC-C14，不自动成交或取消 | BR-05 |
| US-05-AC-10 | 交易完成或有效终止 | 查看商品及会话 | 买方直接取消或双方协商终止后商品恢复公开状态；交易完成或管理终止时下架，由卖方按资格重新上架。分支归档、解除本笔冻结，其他限制继续适用 | BR-14、BR-33 |
| US-05-AC-11 | 进行中已有有效约定及单方完成确认 | 双方同意约定变更 | 生效时清当前确认、结束旧计时并保留历史；未同意不清空；生效后不自动计时，重新单方完成确认后才开始完整7天等待 | 4.15；D-49 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验买卖双方身份、操作资格及介入管理员资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、交易时内容、生命周期状态、展示资格 | 接受时锁单并退出在售搜索；结束释放锁单，按卖方选择及资格处理上架结果 |
| [C-07 IM会话](../class-analysis/C-07-咨询会话.md) | 参与双方、交易分支所属请求或交易、归档标记 | 为有效请求建立独立分支，结束请求或交易时归档，保留历史 |
| [C-08 消息](../class-analysis/C-08-消息.md) | 所属交易分支、系统来源、内容、发送时间、关联商品及请求 | 保存关联该笔请求的系统消息，不将聊天当作业务确认 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 商品及交易时内容、买卖双方、请求及交易状态、有效约定和提案历史、当前确认、计时、冻结及转移依据 | 创建和处理请求；确认或变更约定；推进完成、取消、争议及恢复，联动商品与分支 |
| [C-10 交易完成确认记录](../class-analysis/C-10-交易完成确认记录.md) | 所属交易、确认人用户ID、确认时间、可选说明、当前有效标记 | 保存双方统一完成声明；恢复时清空当前标记并保留历史 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 争议或异常事项、认领管理员、处理结论、理由及依据 | 登记争议或异常处理依据，限定管理调整及恢复权限；管理沟通复用 UC-C08／C14 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 业务事件、接收人、来源请求或交易、内容 | 发送请求、约定、确认、取消及状态变化通知，入口定位原业务 |
