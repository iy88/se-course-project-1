# US-13 维护商品分类

## 用户目标与价值

作为有分类管理权限的平台管理员；申请标签的卖方参与关联审核，我希望维护单级多标签及别名，处理随商品提出的标签申请，以便使商品归类、名称变更与检索使用一致依据。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-13 |
| 主用例 | UC-C13，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C02、UC-C03、UC-C08、UC-C11 |
| 场景 | SC-10、SC-03 |
| 优先级／批次 | 中／2 |
| 触发规律 | 管理员创建或维护分类、卖方发布时缺少合适标签、需要纠正商品归类 |
| 规则依据 | FR-13；BR-11、BR-12、BR-15；4.16 |

## 业务内容与操作资格

- 管理员可主动建立公共分类标签，用户可随商品提出申请。
- 申请新名称与已有分类同义时可作别名，批准随商品审核通过生效。
- 主名更改保持分类身份，旧名保留别名，当前显示新名、历史交易留当时名称。
- 已关联商品分类仅停用，从未关联可逻辑删除；有在售商品仍保留其筛选入口。
- 管理员有依据纠正交易中分类并通知卖方，交易约定及历史内容保持。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-13-AC-01 | 卖方发布且缺少合适已有分类 | 随商品提交新标签申请 | 允许送审；仅商品通过时一并批准并公开新标签或别名 | BR-12、BR-13 |
| US-13-AC-02 | 申请标签不合适但商品合规 | 管理员审核 | 有合适已有标签则说明原因后通过；否则按不通过记录并写明退回补充原因，不因标签名当然拒绝商品 | BR-13 |
| US-13-AC-03 | 分类存在主名及别名 | 改名或移除别名 | 分类身份及商品归属不变；改主名保留旧别名，历史交易保留当时名称 | 4.16 |
| US-13-AC-04 | 分类曾关联商品 | 请求删除或停用 | 仅停用，旧商品及交易保持；有在售商品时仍可筛选，新的发布不可选 | 4.16 |
| US-13-AC-05 | 分类从未关联商品 | 管理员删除 | 逻辑删除并保留必要依据 | 4.16 |
| US-13-AC-06 | 交易中商品需纠正分类 | 有权限管理员留据调整 | 记录前后分类、原因、执行者及时间并通知卖方；不改约定、交易状态及历史内容 | BR-11；4.16 |
| US-13-AC-07 | 商品匹配多个选定标签 | 检索 | 全部所选标签均匹配且同时满足关键词与价格；同义别名不重复计标签 | BR-15 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、管理资格、账户状态 | 校验常设分类维护资格及商品标签申请资格，具体审核仍校验认领归属 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 商品分类标签、生命周期状态、编辑历史 | 随商品关联分类申请；管理员纠正分类时保存前后内容，不改变交易约定及历史 |
| [C-03 商品分类](../class-analysis/C-03-商品分类.md) | 分类标识、主名称、别名、启用状态及商品关联 | 创建、改名、维护别名、停用或逻辑删除分类；提供全部标签匹配与停用标签筛选依据 |
| [C-04 审核记录](../class-analysis/C-04-审核记录.md) | 商品及当次内容、审核结论、拒绝原因 | 提供同批商品审核结果，决定申请标签或别名是否生效；保留退回补充原因 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 分类纠正事件、卖方、来源商品、通知内容 | 纠正商品分类后通知卖方，审核结果通知复用 UC-C02 |
