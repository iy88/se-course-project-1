# US-09 了解商品状态

## 用户目标与价值

作为校园用户或卖方，我希望查看商品状态、展示资格及相应操作范围，以便正确理解能否搜索、查看、请求、评论或维护商品。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-09 |
| 主用例 | UC-C09，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C02、UC-C03、UC-C05、UC-C08、UC-C14 |
| 场景 | SC-02、SC-03、SC-05、SC-06、SC-09 |
| 优先级／批次 | 高／1 |
| 触发规律 | 浏览详情或本人商品、接受请求、交易结束或管理处置 |
| 规则依据 | BR-03、BR-04、BR-07、BR-09—BR-11、BR-14、BR-32、BR-33；4.18 |

## 业务内容与操作资格

- 商品生命周期为待审核、审核未通过、公开可交易、交易中和已下架，展示资格另按限制判断。
- 接受请求转交易中并锁单，搜索退出，但有资格登录用户仍可看详情及评论。
- 交易结束默认下架，卖方按当前资格明确继续上架；下一笔为独立交易。
- 违规撤销访问、解除恢复、封禁及交易冻结与生命周期分开解释。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-09-AC-01 | 商品初次发布或审核拒绝 | 查看状态与公开入口 | 分别显示待审核／审核未通过，公开搜索和详情不展示 | BR-10 |
| US-09-AC-02 | 商品公开可交易 | 卖方接受一条请求 | 转交易中并停止新请求；已登录有资格用户仍可看详情并评论 | BR-03、BR-14 |
| US-09-AC-03 | 普通商品交易完成或终止 | 查看上架结果 | 默认已下架；卖方明确继续且资格满足才公开可交易 | BR-14 |
| US-09-AC-04 | 本人商品处于已下架状态、审核有效且当前账户及商品限制允许 | 卖方重新上架 | 恢复公开可交易，新交易和聊天分支独立 | BR-14 |
| US-09-AC-05 | 管理处置撤销公开访问 | 访问旧链接或解除处置 | 处置期间拒绝公开详情；解除只恢复原展示资格，原非在售状态保留 | BR-14、BR-32、BR-33 |
| US-09-AC-06 | 商品已下架 | 查看公开详情或本人历史 | 公开详情不可访问，授权本人历史或既有事项可按规则读取 | BR-14；4.18 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验状态读取及卖方重新上架资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、生命周期状态、展示资格 | 呈现状态及可操作范围；按接受、交易结束及本人重新上架结果更新商品 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 交易状态、买卖双方、锁单及结束结果 | 提供接受锁单、结束释放的业务结果，驱动商品状态联动，不在此重新执行交易确认 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、处置及解除依据、处理结果 | 提供管理撤销公开及解除的依据；恢复原展示资格，处置沿用 UC-C08 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取账户限制，决定商品展示和重新上架资格 |
