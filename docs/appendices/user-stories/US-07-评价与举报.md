# US-07 评价与举报

## 用户目标与价值

作为已完成交易的参与方，或未被封禁的登录用户，我希望评价交易对方，或独立举报违规对象并查看处理结果，以便反馈体验及问题，让违规核查有对象、原因和可追溯结论。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-07 |
| 主用例 | UC-C07，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C08、UC-C11、UC-C12 |
| 场景 | SC-07 |
| 优先级／批次 | 中／2 |
| 触发规律 | 交易完成后评价，或发现可举报对象存在问题 |
| 规则依据 | BR-24—BR-26、BR-27、BR-32；4.17—4.18 |

## 业务内容与操作资格

- 评价与举报是独立目标，举报不以已经成交或先评价为前提。
- 完成交易每方每笔可提交一条1—5分及文字评价，仅在本人“我的评价”按发表／收到查看。
- 举报选择商品、评论、消息、评价或用户，必填原因，说明和截图等证据可选。
- 未结同对象举报在原事项补充；结案后该举报事项归档，不再接受补充或重新提交。
- 结论经管理员确认匿名公开；举报人收到本人处理结果通知，受影响者的说明／申辩另行授权。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-07-AC-01 | 交易完成且用户未封禁 | 首次评价对方 | 保存每方每笔唯一评价，含1—5分及文字；本人在“我的评价”按发表／收到查看，商品页不公开；未完成或重复评价拒绝 | BR-24 |
| US-07-AC-02 | 评价已提交 | 用户修改或删除 | 拒绝自行修改删除；管理员可有依据处理违规评价 | BR-24 |
| US-07-AC-03 | 未被封禁的登录用户发现违规对象 | 填写对象与原因并选择是否附证据 | 原因与对象完整即可提交；截图和补充说明可选 | BR-25 |
| US-07-AC-04 | 同用户同对象已有未结举报，或原举报已结案 | 再次提出相同对象问题 | 未结：在原事项补充，不重复新建；已结案：事项归档只读，拒绝补充或重新提交 | BR-25、4.18 |
| US-07-AC-05 | 举报已结案并由管理员确认 | 查看通知及公开结果 | 举报人收到可公开结论和原因；公开结果隐去用户及管理员信息 | BR-25、BR-26 |
| US-07-AC-06 | 举报对象失效 | 查看已有举报或尝试新举报 | 既有事项按资格关联可查；失效后新举报失败；对方申辩不因举报身份开放 | 4.18 |
| US-07-AC-07 | 账户仅有交易冻结或已封禁 | 评价既往完成交易或提交其他举报 | 仅冻结仍按原资格允许；封禁拒绝新增评价及举报 | BR-32、BR-33 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态 | 校验评价者、举报者身份及封禁限制 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 关联举报对象、生命周期状态、展示资格 | 提供商品举报对象及其可定位性；商品展示资格不决定本人评价的读取资格 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 交易标识、买卖双方、交易状态 | 读取完成结果及参与方，判定每方每笔评价资格，不推进交易 |
| [C-11 评价](../class-analysis/C-11-评价.md) | 交易、评价者、被评价者、评分、文字、提交时间、违规处理依据 | 提交每方每笔唯一评价；按本人发表／收到归属读取，拒绝越权读取及用户修改删除；违规处理复用 UC-C08 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 举报者、对象及类型、原因及证据、处理进度、结论及公开结果 | 提交或在未结事项补充举报；结案归档，按资格读取进度与经确认的匿名结论 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 关联举报、认领管理员、处理结论及可公开理由 | 关联并读取举报处理结果；对方申辩内容不因举报身份开放，处置沿用 UC-C08 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取封禁限制，校验新增评价与举报资格 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 举报处理事件、接收人、来源举报、通知内容 | 向举报人发送处理结果通知，关联可公开结论及原因 |
