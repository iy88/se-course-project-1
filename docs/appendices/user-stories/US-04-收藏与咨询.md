# US-04 收藏与咨询

## 用户目标与价值

作为校园用户，或具体商品的买方／卖方，我希望独立使用收藏、商品页评论或普通私聊，并在请求后进入对应交易分支沟通，以便按自己的任务获取和保留信息，分清普通咨询与具体交易上下文。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-04 |
| 主用例 | UC-C04，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C05、UC-C11、UC-C12 |
| 场景 | SC-03、SC-04、SC-11 |
| 优先级／批次 | 高／1 |
| 触发规律 | 关注商品、在商品页提问／回复、主动私聊或继续某笔交易交流 |
| 规则依据 | BR-02、BR-16—BR-19、BR-32、BR-33 |

## 业务内容与操作资格

- 收藏、评论与私聊分别选择执行，用户无需先收藏或评论才能发起普通私聊。
- 本人收藏清单保留商品关联；失效时显示通用失效提示，有资格用户可取消本人收藏。
- 校园用户可从卖方个人页等入口主动发起双人普通私聊；卖方也可主动发起，同一对用户复用普通会话。
- 每笔有效购买请求关联独立交易分支；系统引导该笔沟通进入对应分支，各会话消息与已读分别计算。
- 交易结束分支默认归档、保留历史，普通私聊继续独立存在；处置沟通经管理员事项渠道进行。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-04-AC-01 | 已登录且商品公开 | 选择收藏或查看本人清单 | 按本人归属建立收藏及展示清单，其他人无权查看；商品进入交易中但仍有公开详情资格时，已有收藏保持有效 | BR-16 |
| US-04-AC-02 | 收藏已失效且账户未封禁 | 查看并取消收藏 | 仅显示失效提示，取消本人收藏，不泄露不可见商品内容 | BR-16、BR-32 |
| US-04-AC-03 | 商品公开可交易或交易中且账户允许 | 发表评论或卖方回复买方评论 | 公开展示；已下架或撤销公开后拒绝新增，作者可按资格删除本人旧评论 | BR-17 |
| US-04-AC-04 | 与对方无商品或购买请求 | 任一方主动发起普通私聊 | 校验不同账户及发送资格后建立或复用双人会话 | BR-02、BR-18 |
| US-04-AC-05 | 已有不同的购买请求 | 进入交易咨询 | 每笔分支独立，系统引导该笔交流，普通私聊历史不迁移 | BR-01、BR-18 |
| US-04-AC-06 | 存在多个会话或分支未读 | 查看其中一个分支的部分消息 | 仅已展示消息标读，列表、其他分支及通知已读均不清除本分支未查看消息 | BR-18 |
| US-04-AC-07 | p、q之间任一交易被冻结 | p、q发送普通私聊或任一交易分支消息 | 两类均禁发、历史可读；p–s及q–t不受本笔冻结影响，账户封禁另适用 | BR-33 |
| US-04-AC-08 | 请求拒绝、撤回、关闭或交易结束 | 重新打开对应分支并尝试发送 | 归档分支历史可读、发送被拒绝；普通私聊独立保留，转入须用户选择，旧交易消息不自动迁移 | BR-18 |
| US-04-AC-09 | 本人仍保留因管理处置失效的收藏 | 管理员解除对应限制后重新查看清单 | 商品恢复公开访问资格时收藏自动恢复有效，无须重新收藏；仍有其他撤销公开限制或商品已下架时保持失效，不泄露内容 | BR-16、BR-14；D-44 |

## 领域类、属性及行为协作

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验登录身份、本人归属、卖方回复资格及相关管理资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、生命周期状态、展示资格 | 读取详情及发布者信息，校验收藏、评论与回复资格 |
| [C-05 收藏记录](../class-analysis/C-05-收藏记录.md) | 收藏者、商品、收藏时间 | 建立或取消本人收藏；返回本人清单及失效提示 |
| [C-06 商品评论](../class-analysis/C-06-商品评论.md) | 商品、作者、正文、回复对象、发表时间、删除或移除标记及理由 | 发表评论或卖方回复；按作者或认领管理员资格删除、移除，保留依据 |
| [C-07 IM会话](../class-analysis/C-07-咨询会话.md) | 会话类别、参与双方、所属请求或交易、归档标记 | 建立或复用双人普通私聊；定位既有逐笔交易分支；按归档及双方限制校验发送 |
| [C-08 消息](../class-analysis/C-08-消息.md) | 所属会话或分支、发送者、内容、发送时间、接收方已读标记 | 发送并保存文字消息；仅将当前会话或分支已展示消息标为已读 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 买卖双方、所属商品、请求及交易状态、冻结依据 | 定位该笔交易咨询分支并提供当前交互资格；交易操作沿用 UC-C05 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、认领管理员、处置理由及依据 | 校验违规评论移除及私人消息查看的认领权限，留存移除依据 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取封禁限制，校验评论、收藏及发送操作；不在本用例执行封禁解除 |
