# US-01 账户生命周期

## 用户目标与价值

作为访客或校园用户，我希望注册、使用邮箱登录、退出，并自主维护密码、邮箱和显示名称，以便持续访问本人业务，同时保持审计身份与历史归属稳定。

| 项目 | 内容 |
|---|---|
| 关联功能 | FR-01 |
| 主用例 | UC-C01，详见[完整用例索引](../use-cases/index.md) |
| 协作用例 | UC-C08 |
| 场景 | SC-01 |
| 优先级／批次 | 高／1 |
| 触发规律 | 首次访问、再次登录、忘记密码或主动维护账户资料 |
| 规则依据 | BR-32、BR-20—BR-23；4.19 |

## 业务内容与操作资格

- 注册填写邮箱、显示名称和密码，创建账户前须验证邮箱由本人控制；验证通过且邮箱唯一、必填资料有效后，系统分配稳定且唯一的用户 ID；邮箱另行唯一，用于登录。
- 邮箱或密码错误时拒绝登录；首版不设登录失败次数阈值，不因失败次数触发账户自动锁定（BR-21）。
- 正常登录后进入本人业务，用户可主动退出；忘记密码时通过绑定邮箱验证后自助重置。
- 主动修改密码须验证当前密码；更换邮箱须验证新旧邮箱并校验新邮箱未被占用。
- 显示名称可自行修改，用户 ID 与既有业务及审计归属保持不变。

各操作按当前账户、对象归属、商品／交易状态及事项权限校验；封禁、冻结与管理沟通例外分别按对应业务规则处理。

## 验收条件

| 编号 | 前置情境 | 用户操作或事件 | 预期结果 | 依据 |
|---|---|---|---|---|
| US-01-AC-01 | 未注册且邮箱未被占用 | 验证注册邮箱控制权并提交有效注册资料 | 验证通过后创建独立账户，分配唯一用户 ID，邮箱可用于登录 | BR-20、BR-21 |
| US-01-AC-02 | 邮箱已被其他账户使用 | 注册或更换为该邮箱 | 拒绝并提示邮箱已被使用，保留原账户及其记录 | BR-21；4.19 |
| US-01-AC-03 | 账户存在 | 使用邮箱和密码登录或主动退出 | 有效凭证进入本人账户；邮箱或密码错误时拒绝，首版不设失败次数阈值、不因失败次数自动锁定；退出后访问业务内容须重新登录 | BR-20、BR-21、BR-22 |
| US-01-AC-04 | 忘记密码 | 验证绑定邮箱后重置 | 允许设置新密码并保留原用户 ID | BR-20 |
| US-01-AC-05 | 已登录 | 主动改密或更换邮箱 | 改密验证当前密码；换邮箱验证新旧邮箱和唯一性，生效后使用新邮箱登录 | 4.19 |
| US-01-AC-06 | 已有历史业务及审计记录 | 更换邮箱或显示名称 | 历史记录仍关联原用户 ID，原操作主体可追溯 | 4.19 |
| US-01-AC-07 | 账户已被封禁 | 登录并访问业务 | 允许原资格只读访问及管理沟通，拒绝受限业务写操作；封禁生效关闭该账户参与的待接受请求、通知双方并归档分支，解除不重开；已接受未结束交易冻结，已有单方确认时暂停原计时 | BR-32；D-51、D-52 |
| US-01-AC-08 | 注册邮箱尚未验证、验证失败，或验证后更换为另一邮箱 | 提交注册 | 拒绝创建账户，提示先完成当前注册邮箱的控制权验证；不占用该邮箱或生成正式用户ID | BR-20；D-47 |
