验收要点 关键 AC，界面据此设计
  • US-08-AC-01：事项在共享池且未认领 → 界面显示“待认领”；认领后仅认领人出现处理入口，其他人的处理按钮保持禁用。
  • US-08-AC-02：待审商品已被本人认领 → 审核面板显示当次内容与当前禁发范围；通过或退回都要记录原因并通知发布者，标签随审批生效。
  • US-08-AC-03：举报证据不足且没有实际处置 → 可记录“无法认定／不予处理”并通知举报人；被举报人处不出现该告知。
  • US-08-AC-04：内容移除、封禁或交易冻结生效 → 受影响者在通知与事项页看到原因、范围及本人沟通入口，举报人身份不可见。
  • US-08-AC-05：问询阶段或处置之后 → 分别在原事项提交说明与申辩，管理员回复结论及原因并通知；问询不改变状态，申辩不自动撤销处置。
  • US-08-AC-06：交易被冻结 → 双方推进入口不可用；认领管理员调整时记录前后状态并通知，不伪造确认。
  • US-08-AC-07：解除具体封禁或冻结 → 仅恢复该限制允许恢复的资格，其他有效限制继续提示适用，原非在售商品不自动上架。
  • US-08-AC-08：管理员维护禁发细目并保存 → 登录用户查看时显示最新范围，审核面板同步引用；普通用户只看到只读内容，没有保存入口。
