维护商品分类

作为有分类管理权限的平台管理员；申请标签的卖方参与关联审核，我希望维护单级多标签及别名，处理随商品提出的标签申请，以便使商品归类、名称变更与检索使用一致依据。

  • 关联功能 FR-13
  • 主用例 UC-C13
  • 协作用例 UC-C02、UC-C03、UC-C08、UC-C11
  • 依据 US-13-AC-01—AC-07

修改主名

旧主名将自动保留为别名；分类身份、商品归属与历史交易当时名称不变。

卖方随商品提交新标签申请；仅商品审核通过时，新标签或别名才一并批准公开。

标签不合适的处理

若商品本身合规但申请标签不合适：有合适已有标签时说明原因后通过；否则按不通过记录退回补充原因，不因标签名当然拒绝商品。

纠正交易中商品的分类须有依据；仅记录分类变化，不改变交易约定、交易状态与历史内容。

验收要点
US-13-AC-01：卖方发布时缺少合适已有分类 → 可随商品提交新标签申请，仅在商品通过时一并批准并公开为新标签或别名。
US-13-AC-02：申请标签不合适但商品合规 → 有合适已有标签时说明原因后通过，否则退回补充并写明原因，不因标签名拒绝商品。
US-13-AC-03：分类存在主名与别名 → 改名后显示新主名、旧名保留为别名，分类身份与商品归属不变，历史交易保留当时名称。
US-13-AC-04：分类曾关联商品 → 操作只提供停用；旧商品与交易保留，有在售商品时仍可筛选，新的发布不可选。
US-13-AC-05：分类从未关联商品 → 可逻辑删除，并保留必要依据。
US-13-AC-06：交易中商品需纠正分类 → 有权限管理员填写依据后调整，记录前后分类、原因、执行者与时间并通知卖方，交易约定、交易状态与历史不变。
US-13-AC-07：商品匹配多个选定标签 → 检索结果同时满足全部所选标签、关键词与价格；同义别名不重复计标签。
