验收要点 以 US-02 为验收依据，不展开规则细节
US-02-AC-01：提交完整商品与标签或标签申请 → 商品显示“待审核”，通过后公开可交易，申请标签随本次审核生效。
US-02-AC-02：审核未通过 → 卖方可见拒绝原因；修改重提保留当次内容并形成独立审核记录，旧结论保留。
US-02-AC-03：商品允许编辑且存在未结束请求 → 可编辑并保留历史与展示，待接受请求不关闭，相关买方收到变更通知。
US-02-AC-04：商品处于交易中修改关键内容 → 界面拒绝编辑；有权限管理员的分类纠正另行留依据并通知卖方。
US-02-AC-05：无锁单但有待接受请求时主动下架 → 商品显示“已下架”，请求关闭并说明商品已下架，对应分支归档。
US-02-AC-06：已下架商品原审核有效且当前资格允许 → 重新上架后恢复公开可交易，后续新交易使用独立记录及分支。
US-02-AC-07：仅交易冻结、账户未封禁 → 可编辑无关商品，尝试上架被拒绝并提示冻结原因；封禁账户另按写操作限制。
US-02-AC-08：尚未提交商品时查看禁发范围 → 直接展示管理员维护的当前禁发细目，无需先创建商品；管理员保存更新后查看可见最新范围。
US-02-AC-09：本人商品处于待审核 → 可修改内容或标签、撤回标签申请或撤回商品；修改以最新内容审核、不重新排队，撤回后置为已下架、修改后可重新提交审核。
