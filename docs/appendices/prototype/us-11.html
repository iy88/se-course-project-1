管理员待办位置

平台管理员的待办来自共享处理池，可认领后处理；管理员不接收本通知中心的站内通知。

通知中心只呈现与接收人资格相关的业务事件；已读只表示知晓，不代替接受请求、确认约定或确认完成。

验收要点 关键 AC，界面据此设计
  • US-11-AC-01：有效请求已创建 → 卖方提醒与通知中心定位同一请求，不重复生成新请求。
  • US-11-AC-02：多条未读通知 → 仅浏览列表不标读；打开哪一条就只将该条标为已读。
  • US-11-AC-03：通知与聊天都有未读 → 读完通知后聊天未读保留；聊天按具体分支的实际展示范围标读。
  • US-11-AC-04：请求已撤回、关闭或交易已结束 → 从旧通知进入时显示当前状态，旧入口不能继续执行失效操作。
  • US-11-AC-05：审核、约定、完成、取消、编辑或管理事件生效 → 接收方与内容符合事件范围；单方确认只提醒待确认方；管理员待办从共享池读取，不发站内通知。
  • US-11-AC-06：收到他人事项链接或读完通知 → 超出资格的私人内容拒绝访问；已读不代替接受请求、确认约定或确认完成。
