验收要点 以 US-01 为验收依据，不展开规则细节
US-01-AC-01：新邮箱验证控制权后提交完整注册资料 → 界面显示系统分配的唯一用户 ID，并可用该邮箱登录。
US-01-AC-02：邮箱已被其他账户使用 → 注册或换绑时提示“邮箱已被使用”，原账户及其记录保留。
US-01-AC-03：使用邮箱和密码登录 → 有效凭证进入本人账户；邮箱或密码错误时登录被拒绝并显示错误提示，不因失败次数自动锁定；主动退出后访问业务须重新登录。
US-01-AC-04：忘记密码并验证绑定邮箱 → 可设置新密码，用户 ID 保持不变。
US-01-AC-05：已登录改密或更换邮箱 → 改密须验证当前密码；换邮箱校验新旧邮箱与唯一性，生效后使用新邮箱登录。
US-01-AC-06：更换邮箱或显示名称后 → 历史商品、交易与审计记录仍关联原用户 ID，操作主体可追溯。
US-01-AC-07：封禁账户登录并访问业务 → 只读可见本人业务与管理沟通，受限写操作被拒绝。
US-01-AC-08：当前注册邮箱未验证、验证失败或验证后更换邮箱 → 拒绝创建账户，先验证当前邮箱。
