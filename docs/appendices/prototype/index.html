按用户故事组织的多页 HTML 原型

本原型为需求阶段的界面补充材料：每个用户故事一个独立 HTML 页面，页面之间用链接跳转，不做单页应用。界面元素与可操作范围取自该故事的验收条件；页面数据均为示例，不连接后台，不作为功能已实现的证明。

从 US-01 开始 看交易主线 看管理端 看“我的”聚合

结构

15 个文件

1 个目录页（本页）+ 14 个用户故事页，每页一个 HTML 文件，目录与页脚提供前后页跳转。所有页面共用同一套样式与少量演示脚本；没有路由、没有应用状态，刷新页面不保存任何修改。

校园用户：买方 / 卖方（同一账户可随商品分别担任） 平台管理员：认领事项、审核处置、分类与禁发范围维护、统计 游客：仅注册、登录与找回密码入口

阅读方式

无需启动
  • 直接用浏览器打开
    打开本目录下的 index.html，从目录进入任一故事页。
  • 可点击元素
    按钮给出“预期结果”提示；标签页、开关只在当前页面切换显示。
  • 示例数据
    教材、自行车、台灯及人名均为示例，不代表真实用户或商品。
成员的原型观察与问题处理记录见需求分析质量验证报告；页面用于展示界面与模拟交互。
