验收要点 关键 AC，界面据此设计
  • US-09-AC-01：商品初次发布或审核拒绝 → 分别显示“待审核”／“审核未通过”，公开搜索和详情都不展示。
  • US-09-AC-02：商品公开可交易时卖方接受请求 → 转“交易中”并停止新请求、退出搜索；已登录有资格用户仍可看详情并评论。
  • US-09-AC-03：普通商品交易完成或终止 → 默认“已下架”；卖方明确继续且资格满足后才恢复公开可交易。
  • US-09-AC-04：已下架、审核有效且限制允许 → 卖方重新上架后恢复公开可交易，下一笔交易与聊天分支独立。
  • US-09-AC-05：管理处置撤销公开访问 → 处置期间旧链接拒绝公开详情；解除只恢复原展示资格，原非在售状态保留。
  • US-09-AC-06：商品已下架 → 公开详情不可访问；授权本人历史或既有事项仍可按规则读取。
