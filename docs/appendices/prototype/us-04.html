验收要点 以 US-04 为验收依据，不展开规则细节
US-04-AC-01：已登录且商品公开时收藏 → 按本人归属建立收藏与清单，其他人无权查看。
US-04-AC-02：收藏已失效且账户未封禁 → 只显示失效提示，可取消本人收藏，不泄露不可见商品内容。
US-04-AC-03：商品公开可交易或交易中 → 可发表评论、卖方回复；已下架后拒绝新增，作者可按资格删除本人旧评论。
US-04-AC-04：与对方无商品或购买请求 → 任一方校验账户与发送资格后，可建立或复用双人普通私聊。
US-04-AC-05：已有不同购买请求 → 每笔交易分支独立，系统引导该笔交流，普通私聊历史不迁移。
US-04-AC-06：存在多个会话或分支未读 → 仅当前分支已展示消息标读，不影响列表、其他分支及通知未读。
US-04-AC-07：p、q 之间任一交易冻结 → 双方普通私聊与交易分支均禁发、历史可读；其他用户间会话不受影响。
US-04-AC-08：请求拒绝、撤回、关闭或交易结束 → 对应交易分支归档、历史可读、不可发送；普通私聊独立保留，旧交易消息不自动迁移。
US-04-AC-09：管理处置解除且商品恢复公开访问 → 原收藏自动恢复有效；其他限制仍有效或商品已下架时保持失效。
