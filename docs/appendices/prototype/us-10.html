作为平台管理员，我希望查看查询时点指标，并显式选择时间范围或全部统计完成交易，以便按统一口径理解账户、商品、待办和交易结果规模。

  • 关联功能 FR-10
  • 主用例 UC-C10；统计只读取各业务记录，不改变其原业务结果
  • 依据 US-10-AC-01—US-10-AC-06（场景 SC-08）

验收要点 关键 AC，界面据此设计
  • US-10-AC-01：普通校园用户访问统计入口 → 拒绝访问，界面不显示任何统计指标。
  • US-10-AC-02：管理员执行查询 → 显示用户总数及封禁数、各状态商品数、审核／举报待办数，以及已完成／已终止／有争议交易数。
  • US-10-AC-03：尚未选择时间范围 → 完成交易区域等待显式选择范围或“全部”，不预填默认范围，也不给出数字。
  • US-10-AC-04：已选择范围或全部 → 按交易结果确认时间显示完成交易数，并与查询时点指标分栏标明。
  • US-10-AC-05：所选范围无匹配记录 → 显示 0 或空结果，不推断缺失原因。
  • US-10-AC-06：查看失败交易数量 → 已终止计入失败；拒绝、撤回、锁单关闭不计入已接受交易失败数，页面不含真实资金数据。
