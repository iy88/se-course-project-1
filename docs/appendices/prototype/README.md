# 多页 HTML 原型说明

本原型是需求阶段的界面补充材料。现行15个页面用于辅助理解用户目标、界面信息和演示交互。

## 一、材料与结构

- 目录页 [index.html](index.html)，用户故事页 `us-01.html`—`us-14.html`，共 15 个独立 HTML 页面。
- **一个 HTML 文件只承载一个页面**；页面之间用链接跳转，不使用单页应用路由，不维护应用状态。
- 每页自包含（样式与演示脚本内联），用浏览器直接打开目录页即可浏览，无需安装依赖或启动服务。
- 组织依据为用户故事及其验收条件：每页先给出该故事的用户目标、关联功能与用例，再给出界面示意与关键验收要点。
- 页面数据均为示例（教材、自行车、台灯等），不连接后台、不保存数据、不发送请求；按钮提示用于说明预期结果，不代表功能已实现。

## 三、交互演示边界

- 演示只有前端切换与提示：标签页、状态开关、提示条；刷新页面后全部复位。
- 不提供登录、存储、网络请求或后台逻辑；页面中的“成功”“已提交”等提示均为预期结果说明。
- 人工观察与走查结果待写；页面中的示例与演示仍属于界面说明，不据此认定后台业务已实现。

## 四、与旧纸面原型的关系

2026-10-22，本项目将原 P-01—P-07 纸面原型替换为当前多页 HTML 原型。替换原因：旧版本按规则组织，页面内规则注释与第 4 章重复，且未成为任何用户故事、场景或验收条目的输入；新版本以用户故事为组织依据，每页直接对应一个故事及其验收条件。旧源文件与 PNG 已移除，历史版本与决定见 Git 记录及 [AI-13 档案](../ai-usage/AI-13-2026-10-23-按用户故事重写多页原型.md)。

## 五、评审与维护

- 原型人工观察、走查及问题处理内容待写。

- 本原型不影响用户故事、用例、场景、规则及验收条件；与这些材料冲突时，以需求正文为准。
