# UC-C11 接收通知与待办

| 要素 | 内容 |
|---|---|
| 参与者 | 校园用户；平台管理员通过共享处理池查看待办，不接收站内通知 |
| 目标 | 校园用户收到与本人资格相关的站内提醒并进入当前事项；管理员通过共享处理池查看待办 |
| 触发规律 | 审核、请求、约定、完成、取消、商品编辑、举报及管理事件生效 |
| 前置条件 | 业务事件已生效，当前用户为有资格的接收人；进入事项时重新校验访问权限。 |
| 正常流程 | 1. 按事件类型及接收人资格产生通知（管理员待办来自共享处理池，不发送站内通知），关联原业务事项，通知中心和分支入口定位同一请求；2. 用户查看通知列表和具体通知；仅打开具体通知才标为已读；3. 进入旧通知时重新校验身份及对象资格，显示事项当前状态；4. 聊天消息按会话／分支实际展示范围单独标读；业务操作仍在对应入口明确执行。 |
| 替代与异常流程 | 1. 多个未读通知时，仅打开列表或其中一条通知：列表不标读；打开哪一条仅该通知标为已读；2. 通知及聊天均未读时，将通知读完：聊天未读保持，聊天消息按具体分支实际展示范围标读；3. 请求已撤回、关闭或交易已结束时，从旧通知进入：显示当前状态并校验当前资格，旧入口不能继续执行失效操作；4. 审核、约定、完成、取消、编辑或管理事件生效时，按事件发送提醒：接收方和内容符合4.17；单方确认只提醒待确认方，未通知为交易已完成；5. 收到他人事项链接时，尝试访问：拒绝超出资格的私人内容；已读不代替请求接受、约定确认或完成确认 |
| 后置结果 | 查询返回当前有资格内容；写操作按各分支保存记录及关联结果，失败或拒绝时保留原业务状态。 |
| 关联需求及用户故事 | FR-11；US-11；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-11及各业务事件通知条目；FR-11；4.17；BR-01、BR-04、BR-10、BR-18、BR-19、BR-25、BR-27、BR-33、BR-34 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C11-01 接收业务事件通知 | 对应业务事件已生效且接收人有资格 | 产生关联原事项的站内通知，多个入口不重复创建业务 | C-01、C-04、C-07、C-08、C-09、C-12、C-13、C-15 | 站内触发及接收方见第4章4.17，提醒通过站内通知中心提供 |
| UC-C11-02 查看与管理待办 | 本人有相关通知或管理员有共享池事项 | 查看待办并进入当前事项，业务操作在原入口明确执行 | C-01、C-04、C-07、C-08、C-09、C-12、C-13、C-15 | 按本人有资格的关联事项处理；管理员待办来自共享处理池（BR-34）；通知不代业务确认 |
| UC-C11-03 查看通知并自动标记已读 | 打开具体通知 | 仅该通知自动标已读；列表和其他分支不标读，聊天单独计算 | C-01、C-04、C-07、C-08、C-09、C-12、C-13、C-15 | 打开具体通知才已读，进入列表不算；不代替业务确认，通知与 IM 按各自范围独立标读 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验通知接收人、关联事项访问资格及管理员共享池查看资格 |
| [C-04 审核记录](../class-analysis/C-04-审核记录.md) | 商品、审核结论、拒绝原因 | 提供审核结果事件及当前内容，供通知定位，不在通知入口重新审核 |
| [C-07 IM会话](../class-analysis/C-07-咨询会话.md) | 会话类别、参与双方、所属交易分支、归档标记 | 定位通知关联的会话或分支，区分各分支消息已读范围 |
| [C-08 消息](../class-analysis/C-08-消息.md) | 所属分支、关联请求、接收方已读标记 | 读取分支消息及未读；仅按实际展示范围标读，不被通知已读替代 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 请求或交易标识、当前状态、相关事件 | 提供业务事件及旧通知所指事项的当前结果，阻止失效入口继续操作 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 举报标识、处理进度、可公开结论 | 提供举报结果事件及本人可见内容，不开放对方申辩 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、认领管理员、处理进度、问询及处置结果 | 提供问询或处置事件及有资格的沟通入口；管理员待办从共享池读取 |
| [C-15 站内通知](../class-analysis/C-15-站内通知.md) | 业务事件、接收人、来源业务对象、内容、产生时间、未读标记 | 生成并查看通知；打开具体通知标读，进入事项时重新校验资格 |

## 对象行为协作

1. C-04／C-09／C-12／C-13的已生效事件按4.17产生C-15提醒，接收人和来源对象分别保存。
2. C-15打开时校验C-01及对象资格并更新该通知已读；C-07／C-08仅按具体会话已展示消息另行标读。
