## 用例关系与业务复用

- UC-C06承接UC-C05普通完成路径中的同一次确认及历史记录，扩展点为“有效约定后提交完成确认”；拒绝、撤回及取消路径不强制执行确认。
- UC-C08-01在实际处置告知或用户说明／申辩时发生；不予处置不主动告知被举报人，仍按规则通知举报人。
- UC-C14在UC-C05单方确认超时后触发，是异常处理扩展；系统内部计时不是外部参与者。
- UC-C02和UC-C08中的商品审核是卖方流程与管理员流程的同一次业务处理；UC-C13分类申请随该审核生效。UC-C02提供禁发范围查看及审核依据，UC-C08详细列明独立的禁发范围维护路径；维护不依赖具体商品事项认领。
