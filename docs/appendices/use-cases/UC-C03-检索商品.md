# UC-C03 检索商品

| 要素 | 内容 |
|---|---|
| 参与者 | 校园用户 |
| 目标 | 组合关键词、分类标签和价格区间查找商品并查看详情 |
| 触发规律 | 有物品需求或浏览在售商品 |
| 前置条件 | 访问者已登录；每次查询与详情读取均按商品最新展示资格校验。 |
| 正常流程 | 1. 登录后按关键词、一个或多个标签及价格区间组合查询；2. 多标签要求全部匹配；关键词、标签、价格条件共同生效，价格区间包含端点；3. 结果只含当前公开可交易且有展示资格的商品；打开详情时重新校验资格。 |
| 替代与异常流程 | 1. 分类具有主名称及别名时，使用主名或别名筛选：定位同一分类，别名不重复计作标签；2. 没有满足条件的商品时，执行查询：显示空列表和无匹配商品提示；3. 商品处于交易中时，搜索或通过已有链接访问详情：不进入在售搜索；登录用户可按展示资格查看详情；4. 商品已下架或被撤销公开访问时，访问公开详情或旧链接：拒绝公开详情访问；本人历史及既有事项按对应资格处理；5. 访问者未登录时，检索、查看列表或详情：引导登录，不返回业务内容 |
| 后置结果 | 查询返回当前有资格内容；写操作按各分支保存记录及关联结果，失败或拒绝时保留原业务状态。 |
| 关联需求及用户故事 | FR-03；US-03；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-03、SC-10；BR-14、BR-15、BR-22；4.16 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C03-01 关键词检索 | 已登录 | 匹配关键词并返回当前公开可交易商品 | C-01、C-02、C-03 | BR-15 |
| UC-C03-02 按分类筛选 | 已登录并选择分类 | 解析主名／别名，多标签全部匹配，与其他条件同时生效 | C-01、C-02、C-03 | BR-15；分类来源见 UC-C13 |
| UC-C03-03 按价格区间筛选 | 已登录并设定价格区间 | 包含端点匹配价格，与关键词及标签共同过滤 | C-01、C-02、C-03 | BR-15；含端点 |
| UC-C03-04 查看商品详情与状态 | 有商品入口 | 重新校验展示资格，展示当前详情及可操作范围 | C-01、C-02、C-03 | BR-14、BR-15；交易中仍可查看详情 |
| UC-C03-05 空结果提示 | 当前条件无匹配 | 返回空列表和无匹配商品提示，隐藏非公开商品 | C-01、C-02、C-03 | BR-15；返回空列表并提示，不返回非公开商品 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态 | 校验登录身份及当前读取资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 标题、描述、标价、分类、生命周期状态、展示资格 | 按组合条件返回可交易商品；请求详情时重新校验公开资格，不改写商品 |
| [C-03 商品分类](../class-analysis/C-03-商品分类.md) | 分类标识、主名称、别名、启用状态 | 解析主名与别名；提供全部所选标签匹配及可用筛选入口 |

## 对象行为协作

1. C-01提供当前身份，C-03解析主名与别名及多标签条件，C-02提供当前可检索内容。
2. 打开详情重新校验C-02展示资格，查询不修改商品或交易状态。
