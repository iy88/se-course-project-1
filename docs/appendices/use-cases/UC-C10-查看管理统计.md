# UC-C10 查看管理统计

| 要素 | 内容 |
|---|---|
| 参与者 | 平台管理员 |
| 目标 | 查看查询时点指标，并显式选择时间范围或全部统计完成交易 |
| 触发规律 | 管理员需要了解当前平台业务情况 |
| 前置条件 | 操作者具有平台管理员资格；时间范围由其显式选择。 |
| 正常流程 | 1. 进入统计先校验管理员身份，当前指标按查询时点统计；2. 用户总数包含封禁用户，另列封禁数；商品各状态数与待审核／举报事项数分别统计；3. 完成交易时间范围由管理员显式选择范围或全部，按结果确认时间计算；4. 统计为业务记录派生数量，不记录付款流水或真实收入。 |
| 替代与异常流程 | 1. 管理员查看当前指标时，执行查询：显示用户总数及封禁数、各状态商品数、审核／举报待办数及已完成／已终止／有争议交易数；2. 尚未选择时间范围时，进入完成交易范围统计：等待管理员显式选择范围或全部，不套用默认时间范围；3. 已选择范围或全部时，统计完成交易数：按交易结果确认时间计算，与查询时点状态指标分别标明；4. 范围无匹配记录时，查询：返回空结果或零计数，不推断缺失原因；5. 交易记录含拒绝、撤回、关闭及终止时，查看失败交易数量：已终止计失败，拒绝／撤回／锁单关闭不计已接受交易失败数；不输出真实资金数据 |
| 后置结果 | 返回按查询时点和所选范围分别计算的数量，原业务记录及状态保持不变。 |
| 关联需求及用户故事 | FR-10；US-10；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-08；BR-06、BR-31 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C10-01 按时间范围查询统计 | 管理员已登录 | 显式选范围或全部，按结果确认时间统计完成交易 | C-01、C-02、C-04、C-09、C-12、C-13、C-14 | BR-31；显式选择范围或全部，无默认值 |
| UC-C10-02 查看当前状态与待办数量 | 管理员已登录 | 按查询时点读取用户、各状态商品、审核／举报待办及交易状态数，封禁数单列 | C-01、C-02、C-04、C-09、C-12、C-13、C-14 | BR-31；按查询时点，单列封禁账户数 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验管理员资格；提供用户总数及封禁账户统计口径 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 生命周期状态 | 提供查询时点的各状态商品计数 |
| [C-04 审核记录](../class-analysis/C-04-审核记录.md) | 商品及当次内容、审核结论 | 提供查询时点未完成审核计数，结合 C-13 待审事项区分商品状态与待办 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 请求及交易状态、结果确认时间 | 提供完成、终止、争议状态计数及所选时间范围完成数；区分请求结束与失败交易 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 处理进度、处理结论 | 提供查询时点待处理举报计数 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项类型、处理进度 | 读取审核及举报待处理事项，提供计数依据，不认领或处置事项 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 提供当前有效封禁计数依据，不执行封禁或解除 |

## 对象行为协作

1. C-01校验管理员资格；C-02按查询时点提供各状态商品数量，C-04／C-12／C-13提供未处理事项。
2. C-01／C-14提供用户及封禁数量；C-09按当前状态和结果确认时间提供派生计数，不从支付约定推断收入。
