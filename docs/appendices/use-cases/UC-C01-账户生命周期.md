# UC-C01 账户生命周期

| 要素 | 内容 |
|---|---|
| 参与者 | 访客或校园用户 |
| 目标 | 注册、使用邮箱登录、退出，并自主维护密码、邮箱和显示名称 |
| 触发规律 | 首次访问、再次登录、忘记密码或主动维护账户资料 |
| 前置条件 | 注册、登录与重置入口向访客开放；资料修改、主动退出及本人查询按当前身份校验。 |
| 正常流程 | 1. 注册填写邮箱、显示名称和密码，系统分配稳定且唯一的用户 ID；邮箱另行唯一，用于登录；2. 正常登录后进入本人业务，用户可主动退出；忘记密码时通过绑定邮箱验证后自助重置；3. 主动修改密码须验证当前密码；更换邮箱须验证新旧邮箱并校验新邮箱未被占用；4. 显示名称可自行修改，用户 ID 与既有业务及审计归属保持不变。 |
| 替代与异常流程 | 1. 邮箱已被其他账户使用时，注册或更换为该邮箱：拒绝并提示邮箱已被使用，保留原账户及其记录；2. 账户存在时，使用邮箱和密码登录或主动退出：有效凭证进入本人账户；邮箱或密码错误时拒绝登录，首版不设登录失败次数阈值，不因失败次数触发账户自动锁定（BR-21）；退出后访问业务内容须重新登录；3. 忘记密码时，验证绑定邮箱后重置：允许设置新密码并保留原用户 ID；4. 已登录时，主动改密或更换邮箱：改密验证当前密码；换邮箱验证新旧邮箱和唯一性，生效后使用新邮箱登录；5. 已有历史业务及审计记录时，更换邮箱或显示名称：历史记录仍关联原用户 ID，原操作主体可追溯；6. 账户已被封禁时，登录并访问业务：允许原资格只读访问及管理沟通，拒绝受限业务写操作 |
| 后置结果 | 查询返回当前有资格内容；写操作按各分支保存记录及关联结果，失败或拒绝时保留原业务状态。 |
| 关联需求及用户故事 | FR-01；US-01；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-01；BR-32、BR-20—BR-23；4.19 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C01-01 注册账户 | 未注册、邮箱可用 | 校验邮箱和必填资料，分配唯一用户ID，保存唯一登录邮箱，创建账户 | C-01、C-14 | BR-20、BR-21；注册填写邮箱、显示名称、密码；系统分配唯一用户 ID，邮箱另行唯一，用于登录 |
| UC-C01-02 登录与身份验证 | 账户已存在 | 校验邮箱与密码，有效时进入本人账户；错误时拒绝，首版不设登录失败次数阈值，不因失败次数自动锁定账户 | C-01、C-14 | BR-21、BR-22；访客不得访问业务内容 |
| UC-C01-03 退出登录 | 已登录 | 结束本次登录访问，后续业务访问重新验证身份 | C-01、C-14 | 用户可主动退出登录 |
| UC-C01-04 忘记密码与自助重置 | 忘记密码 | 验证绑定邮箱后设置新密码，用户ID及历史保持 | C-01、C-14 | BR-20 |
| UC-C01-05 修改密码 | 已登录并能验证当前密码 | 验证当前密码后更新，保留原用户ID | C-01、C-14 | 已登录主动改密须验证当前密码；忘记密码另走绑定邮箱验证后自助重置 |
| UC-C01-06 绑定或更换邮箱 | 已登录且可验证新旧邮箱 | 验证两邮箱及新邮箱唯一性，成功后用新邮箱登录，ID及历史保持 | C-01、C-14 | 更换须验证新旧邮箱且新邮箱未被占用，通过后使用新邮箱登录，用户 ID 及审计归属保持不变 |
| UC-C01-07 修改显示名称 | 已登录本人账户 | 按内容规则修改显示名称，历史操作主体及当时名称保留 | C-01、C-14 | 用户自行修改，不设次数／间隔／审批，遵守内容规则；不改账户及历史归属 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、邮箱、显示名称、登录凭据、账户状态 | 注册分配身份；验证登录及退出；按验证条件修改邮箱、密码及显示名称，保持历史归属 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、认领管理员、处置原因、本人沟通入口 | 受限账户进入有资格的管理沟通渠道；处理与回复沿用 UC-C08 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取当前限制，决定账户访问与写操作资格；封禁及解除沿用 UC-C08 |

## 对象行为协作

1. C-01 校验登录邮箱和凭据、维护资料；用户 ID 作为稳定主体关联各业务对象。
2. C-14 提供生效账户限制，C-01 据此返回当前操作资格；封禁期间管理沟通由C-13保持。
