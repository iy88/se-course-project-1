# UC-C09 了解商品状态

| 要素 | 内容 |
|---|---|
| 参与者 | 校园用户或卖方 |
| 目标 | 查看商品状态、展示资格及相应操作范围 |
| 触发规律 | 浏览详情或本人商品、接受请求、交易结束或管理处置 |
| 前置条件 | 公开查询要求登录及商品展示资格；本人历史／管理事项访问按对应归属与必要范围校验。 |
| 正常流程 | 1. 商品生命周期为待审核、审核未通过、公开可交易、交易中和已下架，展示资格另按限制判断；2. 接受请求转交易中并锁单，搜索退出，但有资格登录用户仍可看详情及评论；3. 交易结束默认下架，卖方按当前资格明确继续上架；下一笔为独立交易；4. 违规撤销访问、解除恢复、封禁及交易冻结与生命周期分开解释。 |
| 替代与异常流程 | 1. 商品公开可交易时，卖方接受一条请求：转交易中并停止新请求；已登录有资格用户仍可看详情并评论；2. 普通商品交易完成或终止时，查看上架结果：默认已下架；卖方明确继续且资格满足才公开可交易；3. 本人商品处于已下架状态、审核有效且当前账户及商品限制允许时，卖方重新上架：恢复公开可交易，新交易和聊天分支独立；4. 管理处置撤销公开访问时，访问旧链接或解除处置：处置期间拒绝公开详情；解除只恢复原展示资格，原非在售状态保留；5. 商品已下架时，查看公开详情或本人历史：公开详情不可访问，授权本人历史或既有事项可按规则读取 |
| 后置结果 | 查询返回当前有资格内容；写操作按各分支保存记录及关联结果，失败或拒绝时保留原业务状态。 |
| 关联需求及用户故事 | FR-09；US-09；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-02、SC-03、SC-05、SC-06、SC-09；BR-03、BR-04、BR-07、BR-09、BR-11、BR-14、BR-33 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C09-01 查看商品当前状态与可操作范围 | 有商品访问资格 | 读取生命周期及展示资格，明确当前允许的请求／评论／维护操作 | C-01、C-02、C-09、C-13、C-14 | BR-14；交易中禁新请求但可评论，已下架禁请求与评论 |
| UC-C09-02 查看状态联动结果 | 接受请求、交易结束或处置事件生效 | 读取商品联动结果；结束默认下架，有资格明确继续才公开 | C-01、C-02、C-09、C-13、C-14 | TR-05、TR-06；接受锁单、双方统一确认交付及支付后完成，商品默认下架；卖方可按资格明确继续上架 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态、管理资格 | 校验状态读取及卖方重新上架资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、生命周期状态、展示资格 | 呈现状态及可操作范围；按接受、交易结束及本人重新上架结果更新商品 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 交易状态、买卖双方、锁单及结束结果 | 提供接受锁单、结束释放的业务结果，驱动商品状态联动，不在此重新执行交易确认 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、处置及解除依据、处理结果 | 提供管理撤销公开及解除的依据；恢复原展示资格，处置沿用 UC-C08 |
| [C-14 账户限制记录](../class-analysis/C-14-账户限制记录.md) | 受限账户、限制类型、生效及解除时间 | 读取账户限制，决定商品展示和重新上架资格 |

## 对象行为协作

1. C-02保存生命周期及独立展示资格，C-09的接受／结束结果联动锁单和上架选择。
2. C-13的处置及C-14的账户限制影响当前展示资格，解除时依据原资格恢复。
