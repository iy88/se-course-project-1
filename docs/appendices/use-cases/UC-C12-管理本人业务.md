# UC-C12 管理本人业务

| 要素 | 内容 |
|---|---|
| 参与者 | 校园用户 |
| 目标 | 集中查看本人商品、交易、收藏、双向评价、举报及处置沟通 |
| 触发规律 | 返回平台查看历史、查询进度或继续处理本人事项 |
| 前置条件 | 用户已登录，查询对象按本人身份或已实际处置且有访问资格的事项过滤。 |
| 正常流程 | 1. 我的商品覆盖全部生命周期和关联请求、审核原因；我的交易覆盖买卖两种身份的请求及交易；2. 收藏及评价按本人归属查询，评价区分我发表与我收到，并定位原交易；3. 我的举报与我收到的举报分别进入，收到事项仅列已实际处置且有访问资格的记录；4. 进入后续操作继续使用各业务的当前资格；结束交易只读，评价或管理沟通按独立规则处理。 |
| 替代与异常流程 | 1. 本人曾作为买方或卖方时，查看我的交易：覆盖两种身份的全部请求及交易，结束交易只读并保留历史；2. 本人发表或收到评价时，查询双向评价：分别展示并关联交易，自行修改／删除被拒绝；3. 有本人提交或已实际处置的举报事项时，查看两个举报入口：独立可查，收到的举报隐去举报人身份，未处置事项不额外披露；4. 商品或对象已失效但有既有本人举报时，进入本人事项：按既有举报资格读取关联内容，不开放对方申辩及其他私有记录；5. 他人业务链接或本人资格已变化时，从聚合入口继续操作：重新校验对象及当前权限；聚合入口不增加访问、删除或重开权限 |
| 后置结果 | 查询返回当前有资格内容；写操作按各分支保存记录及关联结果，失败或拒绝时保留原业务状态。 |
| 关联需求及用户故事 | FR-12；US-12；协作故事见[故事索引](../user-stories/index.md) |
| 关联场景及规则 | SC-12；FR-12；BR-16、BR-24、BR-25、BR-26、BR-27、BR-32；4.18 |

## 子用例的具体条件与结果

| 编号与目标 | 触发及前置 | 业务动作与结果 | 主要参与类 | 依据 |
|---|---|---|---|---|
| UC-C12-01 查看本人全部状态商品及关联请求 | 本人有发布记录 | 查全部状态商品、审核原因及关联请求，按资格继续维护 | C-01、C-02、C-05、C-09、C-11、C-12、C-13 | FR-12；包括待审、拒绝、在售、交易中、下架，查看审核原因并按资格继续处理；不新增删除权或他人记录访问权 |
| UC-C12-02 查看本人交易与收藏 | 本人有买卖交易及收藏记录 | 聚合两种身份的全部请求／交易与本人收藏，结束交易只读 | C-01、C-02、C-05、C-09、C-11、C-12、C-13 | BR-27、FR-12；本人买卖双方身份全部请求／交易可查，结束记录只读、不自行删除；收藏及独立后续事项按各自规则处理 |
| UC-C12-03 查看本人双向评价、举报与处置沟通 | 本人有评价或举报及处置沟通 | 分我发表／收到评价、我的举报／我收到的举报，收到事项仅已实际处置且隐去举报人 | C-01、C-02、C-05、C-09、C-11、C-12、C-13 | BR-25、BR-32；评价分“我发表的评价”“我收到的评价”，关联交易、不可自行修改或删除；提供“我的举报”“我收到的举报”独立入口，可进入有资格的事项及沟通；收到的举报仅列已实际处置事项，不显示举报人身份，未处置事项不额外披露 |

## 参与类、业务属性及必要行为

| 领域类 | 相关业务属性 | 必要行为与协作 |
|---|---|---|
| [C-01 用户账户](../class-analysis/C-01-用户账户.md) | 用户ID、账户状态 | 校验本人业务归属及当前访问资格 |
| [C-02 商品](../class-analysis/C-02-商品.md) | 发布者、生命周期状态、编辑历史及关联审核结果 | 按本人归属展示全部状态商品和有资格的历史，后续发布维护沿用 UC-C02 |
| [C-05 收藏记录](../class-analysis/C-05-收藏记录.md) | 收藏者、商品、收藏时间 | 读取本人收藏清单及失效提示；收藏写操作沿用 UC-C04 |
| [C-09 交易记录](../class-analysis/C-09-交易记录.md) | 买卖双方、请求及交易状态、商品及交易时内容 | 聚合本人两种身份的全部请求和交易；结束记录只读，后续操作沿用 UC-C05／C06 |
| [C-11 评价](../class-analysis/C-11-评价.md) | 交易、评价者、被评价者、评分、文字 | 按本人归属分别读取我发表及我收到的评价，关联交易，拒绝他人越权；商品下架不影响本人读取，不提供修改删除 |
| [C-12 举报记录](../class-analysis/C-12-举报记录.md) | 举报者、举报对象、处理进度、可见结论 | 查询我的举报及已实际处置的我收到的举报，隐去举报人身份，不披露未处置事项 |
| [C-13 处置记录](../class-analysis/C-13-处置记录.md) | 事项对象、说明或申辩、回复、当前处理结果 | 按本人事项资格提供沟通入口及可见记录；问询和申辩处理沿用 UC-C08 |

## 对象行为协作

1. C-01稳定用户ID定位本人C-02、C-05、C-09、C-11、C-12及C-13。
2. 聚合仅提供入口与当前有资格内容；进入后续操作继续由原对象校验及执行，不生成另一套记录。
