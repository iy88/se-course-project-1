# E-09 规则合并与编号重排

记录 2026-10-22 规则合并与全仓编号重排的停用内容、旧→新编号映射及文件改名。报告正文与 A／B 报告不保留已停用／撤销编号及其内容，历史仅在本页追溯。

依据：袁尚峰当面决定“去掉编号不复用限制，进行真合并，全部重新编号”，并要求停用/撤销项目连同内容移入 evidence、附每次修改的编号映射表与文件名表。

## 一、停用／撤销内容

### BR-13（原“修改后二次审核”）

原内容：已撤销：修改后暂停公开并二次审核。编号保留不复用；首次审核及审核拒绝后修改重提仍按 BR-10、BR-14。

处理：不再作为规则。信息修改不二审的现行要求由新 BR-11 承载，审核与重提由新 BR-10 承载。

### TR-05（原“修改后二审通过恢复公开”）

原内容：商品：原“修改后二审通过恢复公开”转换撤销，编号保留；袁尚峰取消信息修改二次审核；首次审核及审核拒绝后重提按 TR-01—TR-03，不新增此类二审转换。

处理：不再作为转换。相关约束并入新 BR-11（编辑不二审）与新 TR-01—TR-03。

### TR-19（原“普通用户争议中直接完成”）

原内容：交易记录：原普通用户“有争议 → 已完成”转换撤销，编号保留；普通用户须先解决争议；不限制认领管理员按 BR-08 有依据管理调整，不伪造双方确认。

处理：不再作为转换。普通用户须恢复进行中后完成的约束并入新 BR-07（争议与恢复），管理员调整见新 BR-08。

### TR-22、TR-23、TR-24（管理留痕约束）

- TR-22 原内容：审核记录：认领管理员审核商品时记录执行者、时间、结论及拒绝原因（BR-33、BR-51）。
- TR-23 原内容：举报记录：认领管理员核查举报时记录处置结论及理由；违规涉及交易按 BR-53 冻结；不承诺时限（BR-21、BR-50、BR-51、BR-53）。
- TR-24 原内容：账户限制：认领相关事项的管理员执行或解除封禁时记录执行者与理由；限制期间按既定权限执行；解决问题并解除后自动恢复原权限及展示资格（BR-22、BR-51、BR-53）。

处理：三者不是状态转换，分别并入新 BR-13（审核留痕）、新 BR-26（举报处置留痕）、新 BR-32（封禁留痕与解除）。
