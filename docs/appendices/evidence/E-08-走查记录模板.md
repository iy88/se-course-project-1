# E-08 场景走查记录（模板）

状态：**模板，尚未填写**。本文件不含任何走查结果，不得作为已完成验证的证据引用。实际走查时复制本文件内容另建 `E-08-场景走查记录.md`，填写后删除本模板中的提示文字。

使用说明：

- 走查为**业务推演**，不是功能测试，也不等同于原型走查；不能用「界面可点击」证明后台功能已实现。
- 检查项按 [7 章 7.3.2](../../requirements/07-验收与验证.md) 的逐场景检查单执行，编号保持一致以便追溯。
- 原型走查沿用本模板，批次编号用 `W-06`，检查项按 [7.3.4 原型走查安排](../../requirements/07-验收与验证.md) 执行，并在「走查层次」栏注明页面走查或模拟交互；纸面原型不得填「实际功能验证」通过。
- 结论只能填「通过／不通过／待确认／不适用」；「不通过」须登记 `V` 编号，「待确认」须写明缺失的规则依据与对应 `P`／`T` 编号。
- 规则未明确的分支不得临时裁定，一律记「待确认」。
- 修改由作者完成，复核由另一成员完成；不代签、不补写未参加者。
