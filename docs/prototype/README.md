# 纸面原型说明

状态：纸面原型草稿（低保真线框），**原型走查尚未开展**。本目录只表达页面元素与可见信息，不代表系统已实现，也不作为验收通过的证明。

## 一、性质与边界

- 原型为**纸面低保真线框**，用 PlantUML salt 绘制，源文件 `.puml` 与同名 `.svg` 导出图成对存放。
- 只表达页面元素、可见信息与规则提示，不表达视觉设计、交互细节、分页或响应式布局。
- 不承担真实数据、真实登录、真实支付或后台功能；付款与交付在平台外完成，无线上支付环节。
- 页面中的数值、商品名、人名均为界面示例，不是真实业务数据。
- 规则依据为第 4 章现行 BR-01—BR-53、DT-01—DT-05、TR-01—TR-24；BR-13、TR-05、TR-19 已撤销，页面不表达“修改后二次审核”与“争议中直接完成”。
- 页面标注“待 P-xx／T-xx”者对应 [未决问题与复核清单](../../bits/未决问题与复核清单.md) 与 7 章待登记项，不擅自裁定。

## 二、查看方式

- 直接查看：浏览器或图片查看器打开同名 `.svg`。
- 编辑源文件：用 PlantUML 打开 `.puml`；渲染命令为 `java -jar plantuml.jar -charset UTF-8 -tsvg *.puml`。
- 页面清单如下，源文件与导出图均在本目录。

## 五、关联场景的登记口径

- 上表“覆盖场景”为页面能体现的场景情境，不表示走查已通过；一个场景可能跨多页（如 SC-05 的部分分支落在 P-03、P-05），以场景卡为准。
- 原型走查按 [7 章 7.3.4](../requirements/draft-07-验收与验证.md) 的 W-06 执行，逐页检查项与结论在该节；走查记录用 [E-08 模板](../evidence/E-08-走查记录模板.md)，在“走查层次”栏注明页面走查或模拟交互。
- 页面与场景不一致时，先核对 05 章场景卡与 4 章规则，不按页面改规则。

## 七、版本规则

- 源文件 `.puml` 与导出图 `.svg` 分别记录版本与版本时间；`.svg` 为文本文件，版本写在文件头注释中，不另建 `.version`。
- 修改页面时递增版本并同步本说明的页面清单；新增页面按“编号-名称”命名并补登清单。
- 原型材料的版本变化不影响 05／07 的规则版本，但走查记录须注明所用原型版本。
