# AI 使用档案

按任务保存关键交互、人工决定及产物位置；本目录是过程档案，B 报告通过链接引用，不重复复制全部内容。

## 命名与记录要求

- 文件采用 `AI-序号-日期-任务名称.md`，例如 `AI-01-2026-10-15-需求范围与仓库规范.md`。
- 实际发生的过程记录可直接使用 AI 编号；尚待核对的记录以 `draft-AI-` 开头，核对后再改名。模板使用 `draft-` 前缀。
- 每份记录包含版本号、带时区的版本时间、操作者、工具及已知模型、任务目的、输入与约束、关键提示和输出、人工反馈与决定、核验方法及状态、产物和证据链接、剩余问题、提交关联。
- 关键提示保留必要原文；摘要不能冒充完整对话。原始对话未归档或无法定位时明确说明，不编造证据、追问、模型版本或核验结果。
- 每次 commit 前先新增或补充对应记录，再检查文件版本并提交；同一任务多次提交可以沿用一份记录，但需更新版本、时间和本次变更。提交说明引用档案路径或 AI 编号。
- 未使用 AI 的提交，也建立简短记录，注明“本次未使用 AI”、人工变更和检查情况；不虚构使用过程。
- 记录与相关变更一并提交，提交关联可写“随本次提交”；不要求提前填写尚未产生的提交哈希。
- 不记录密码、令牌或无关个人信息。
