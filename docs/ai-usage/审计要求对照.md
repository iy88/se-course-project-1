|---|---|---|
| B.1 基本信息与实际使用方式 | 项目与操作者可定位，Codex 使用方式已补；本次模型由用户确认 | 小组编号、完整提交信息及最终需求版本待组长填报 |

## 记录边界

AI 使用档案不记录 Git 是否提交、是否待提交或哈希流水状态；提交前补 AI 档案的仓库规则仍保留。原始对话留存、证据可访问性与人工核验记录仍有实质缺口，不能靠补模板宣称已满足全部审计要求。

本次修订依据：用户要求去除无意义的 Git 状态，并参考课程审计要求。已据此调整记录，当前审计记录版本已由组长确认，所列证据与核验缺口仍然保留。
