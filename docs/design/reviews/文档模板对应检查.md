## 一致性核对

- 需求规则、用例与状态图采用相同的商品生命周期口径。买方直接取消及双方协商终止恢复公开状态，交易完成或管理终止时商品下架，展示限制按各自来源生效。
- 需求、接口及 TC 使用同一举报边界。决定前复用，决定后按当前资格另建，已结案事项供查阅。历史读取分别按卖方、买方请求与认领商品事项投影。
- 管理统计在页面默认近 7 天，单次响应提供当期快照、选定范围的完成数及适用 UTC 日桶。原有批次执行记录保留其当时版本，当前案例已采用单次请求。
- GitHub Actions 与 Jenkins 以当前检出范围为准。Flyway 迁移与 OSS 部署探针见运行说明，文档生成及链接核对使用仓库文档命令。
