# ADR-008 异步邮件验证

| 字段 | 内容 |
|---|---|
| 编号/标题 | ADR-008 异步邮件验证 |
| 协作入口 | [任务 Issue](https://github.com/iy88/se-course-project-1/issues/38) |
| 背景 | FR-01；注册前验证及密码邮箱流程。 关联 Q：Q-003。 |
| 比较 | 见下表可行方案及影响 |
| 决定 | PostgreSQL 的 email_verification 单表保存验证请求及投递进度，code 短期明文保存，不增加应用层加密；可靠保存后返回受理，页面输入验证码，后台 Taskiq 按记录ID读取并投递。重发新轮替代旧轮，同轮重试保持凭据及期限；错误验证码尝试原子计数，成功原子消费。 |
| 理由 | 用户交互统一，投递工作支持多实例和有限重试。 |
| 代价 | 本轮选择单表短期明文方案，受控读取和及时清理见 Q-003；SMTP结果不明可产生同轮重复邮件，邮件到达顺序与发送重试需核对。 |
| 验证 | 重复申请、乱序到达、过期任务、幂等错误计数和并发消费。 预期由对应任务的实际审查人核验，执行版本、环境、命令和结果在任务证据中登记。 结果位置随任务证据登记。 |
| 确认 | 本会话已明确采纳；确认姓名：袁尚峰；实际确认日期按会话记录登记，整理日期2026-11-13；交叉复核姓名及日期待登记。 |
| 重新评估条件 | 邮件服务、用途或验证规则变化。 |
| 替代关系 | 首次登记；后续替代关联新旧 ADR |

## 可行方案比较

| 方案 | 收益与代价 |
|---|---|
| 方案 A | 等待 SMTP，直接返回本次发送结果，请求受外部耗时影响 |
| 方案 B | 保存受理后后台发送，可统一重试与并发，需保护投递载荷 |

选择异步发送，用户进入验证码输入，后台状态用于恢复及排查。

## 2026-11-14 单表与明文决定

袁尚峰（iy88）通过标注并明确“标注即为决定”，确认一张表承载邮箱验证及其投递进度，PostgreSQL短期明文保存验证码、不增加应用层加密。校验和worker共享同一条事实记录，成功消费或失效后清空原码；详细字段、认领、并发消费和失败次数协议见[邮箱验证与投递](../../detailed-design/key-designs/邮箱验证与投递.md)。
