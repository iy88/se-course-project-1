## 2026-11-14 共存边界与推进顺序

袁尚峰（iy88）在逐轮部署问题中选择同机并存及独立目录；PostgreSQL共用实例、独立数据库名与用户；Redis共用实例，键前缀隔离，逻辑DB可在部署时选择；域名及OSS采用独立资源。原生进程、systemd、Nginx及CI/CD沿用类似legacy的方式。

袁尚峰同时要求现阶段优先接口和技术设计，实际部署在后续阶段推进。本轮记录部署输入，目录／端口／预算和服务器配置由C7在部署准备阶段落实；清理、迁移和恢复命令限定v2资源。
