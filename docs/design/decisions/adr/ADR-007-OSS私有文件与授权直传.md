# ADR-007 OSS 私有文件与授权直传

| 字段 | 内容 |
|---|---|
| 编号/标题 | ADR-007 OSS 私有文件与授权直传 |
| 协作入口 | [任务 Issue](https://github.com/iy88/se-course-project-1/issues/38) |
| 背景 | FR-02、FR-07、FR-08；媒体访问及证据隐私。 关联 Q：Q-002。 |
| 比较 | 见下表可行方案及影响 |
| 决定 | 采用阿里云 OSS，数据库保存元数据及引用，后端授权直传、核验后允许引用，按业务权限签发短期读取地址，回收过期无引用暂存对象。按 Q-002 采用独立对象键及签名禁止覆盖，私有 Bucket 从未开启版本控制。 |
| 理由 | 文件流量由对象存储承载，服务实例共享访问。 |
| 代价 | 对象和数据库通过状态流程衔接，签名地址具有期限内的持有者访问语义；上传前检查 Bucket 版本状态；核验按实际内容完成；对象键永久不复用，清理含迟到上传复查。具体协议见 Q-002。 |
| 验证 | 上传中断、重复完成、权限读取、引用与回收竞争。 预期由对应任务的实际审查人核验，执行版本、环境、命令和结果在任务证据中登记。 结果位置随任务证据登记。 |
| 确认 | 本会话已明确采纳；确认姓名：袁尚峰；实际确认日期按会话记录登记，整理日期2026-11-13；交叉复核姓名及日期待登记。 |
| 重新评估条件 | 文件用途、隐私或存储条件变化。 |
| 替代关系 | 首次登记；后续替代关联新旧 ADR |

## 可行方案比较

| 方案 | 收益与代价 |
|---|---|
| 方案 A | API 转发文件，入口集中，应用实例承担文件流量 |
| 方案 B | 授权直传对象存储，减轻 API 文件流量，需完成核验／引用／回收流程 |

选择 OSS 私有访问；地址授权的覆盖和有效期语义继续细化。

## 2026-11-14 覆盖控制决定

袁尚峰（iy88）在 Q-002 逐轮决策中选择 A，并提出不开启 Bucket 版本控制。本批以从未开启版本控制为部署条件，上传授权固定唯一 key 和禁止覆盖字段；已开启或暂停过版本控制的 Bucket 通过 Q-002 重新评估。上传接口、稳定内容标识、回收及验证入口见[文件专题](../../detailed-design/key-designs/文件与邮件.md)。
