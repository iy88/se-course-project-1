## 公共输入与并行

[公共交付清单](../detailed-design/03-公共契约交付清单.md)列明输入状态，[并行对接与交界归属](../detailed-design/04-并行对接与交界归属.md)指定每项关系的唯一设计任务。

商品与交易联动由 TASK-003 定义；会话模型和处置执行请求由 TASK-004 定义；公共事务、身份、文件、通知及传输由 TASK-001 定义；商品与分类的本体及资格由 TASK-002 定义。使用任务在自己的适配设计中引用来源，每份 PR 由指定审查人完成交叉审查。

各任务同时开展本域内容，优先发布短小交界版本，再对齐完整接口。审查人可在其他任务仍在细化时开展审查。部署设计与模块设计并行。

## 提交与集成

各任务必须按任务卡的批次表使用独立分支，分多个 PR 提交；每批小步 commit 并提出 Draft PR，按一个目的组织每个 commit，尽量缩小差异。需求引用、契约与必要案例按同一修改目的同步。已可独立审查的小批次通过后集成，后续批次登记新分支及关联 Issue。

公共源文件及拼合清单由 TASK-001 集成，其他任务维护各自模块源文件。复核按商品—交易、交易—会话、事项—主体交界登记实际姓名和记录。部署工作由 TASK-001 承接。
