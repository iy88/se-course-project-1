## 独立启动与测试

各工作包使用共同契约和隔离数据独立验证。阶段联调接入实际依赖并执行以下验收。

- [ ] 在 S2 真实账户与商品上演示请求 → 接受 → 交易会话 → 约定 → 完成 → 评价。
- [ ] 核对竞争锁单、取消、超时或争议、异常事项真实持久化、交易会话隔离、通知与断线补取。
