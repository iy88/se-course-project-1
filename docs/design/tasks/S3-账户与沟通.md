## 独立启动与测试

| 子任务 | 启动及替换 | 数据、操作及预期 | 统一联调 |
|---|---|---|---|
| S3-01 | 使用 S1 的真实基础设施和隔离 Redis，启动两个实时入口。替换 Session、通知及会话读取，提交测试业务事件 | 准备同一用户的两条有效连接、已过期与有效游标、重复事件和不可见事件。检查顺序、权限、重连补拉、ACK 与去重。参见 TC-COM-023、TC-COM-024、TC-COM-025 | 接入真实账户、会话与通知，核对多实例分发及快照权限 |
| S3-02 | 装配真实账户服务、测试 PostgreSQL 和 Redis。通过 S1 的 SMTP 和调度设施使用测试收件箱、可控时钟 | 准备访客、有效与过期验证码、两个有效 Session 及封禁账户。验证登录、CSRF、退出、改密和换绑，检查旧凭据或 Session 的失效。参见 TC-COM-015、TC-COM-019、TC-COM-020 | 接入真实通知、账户限制执行和前端同源 Cookie 流程 |
| S3-03 | 装配真实通知读写和本任务的聚合入口。前端通过模拟 HTTP 和受控 WebSocket 验证账户及会话路由，使用其他目标的业务入口替身 | 准备两账户、列表未读、具体详情及不再可见的来源，模拟重连缺口和查询能力未启用。检查详情标读、来源权限、空状态和同步。参见 TC-COM-022、TC-COM-029、TC-COM-030 | 接入真实账户、会话、通知投递及业务查询，核对未读和本人入口 |
| S3-04 | 装配真实会话服务及本任务迁移。替换账户、交易、事项资格和投递出口 | 准备普通私聊、同一账户对的两笔交易、已归档分支及事项线程。检查会话归属、历史分页、发送及已读推进和冻结后的访问。参见 TC-CONV-001、TC-CONV-002、TC-CONV-005 | 真实交易和事项驱动创建、追加、归档，校验与业务写入的事务一致性 |
