|---|---|
| 任务编号/名称 | TASK-编号／名称 |

| 变更评审触发条件 | 登记需求／接口／架构／迁移／依赖变化，确认后继续对应子项 |
| 状态 | 待准备／可开始／实现中／待审查／需修改／已完成 |

## 扩展字段

- 交付类型：设计细化／编码实现。
- 多批次交付表、每批指定分支、design 起点提交、PR 目标与 Issue 关联。
- 待完成子项：每项明确交付文件、内容及完成判据。
- 依赖矩阵：公共输入、可先行部分、具体受阻子项及解除依据。
- 提交要求：每项任务拆成多个 PR、每个 PR 使用独立分支并由多个单一职责小 commit 组成，关联引用同步、尽量缩小差异；独立批次经审查集成。
- 检查与证据：实际命令、版本、环境、结果、待执行及原因。
