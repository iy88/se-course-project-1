## 依赖与可先行部分

优先并行建立两份短小 PR：第1批 R2a 三类会话基础模型，第2批 R2b 事项主体及处置执行请求。两份 PR 均从可用 design 输入独立建立，分别按需求与公共骨架审查。R2a 定义会话参与、消息、已读及归档；R2b 定义动作类型、目标 ID、依据、认领要求、预期结果和具名错误。

第1批维护 `会话与处置事项.md` 的会话模型；第2批维护独立的 `事项主体与处置执行.md` 及 `处置与主体协同.md`。通过各自文件交付，完成后互相链接。M2／M4 的本域接口及 M5 业务预期持续推进。

交易触发和主体执行的具体适配另开 PR，采用 R0 商品能力、R1 占用及分支触发，以及 C1／C3 评审版本，对齐会话分支调用、商品与交易执行结果、证据引用和事务。每份适配 PR 登记采用的源文件及提交；就绪标准见[并行对接安排](../detailed-design/04-并行对接与交界归属.md)。
