## 独立启动与测试

| 子任务 | 启动及替换 | 数据、操作及预期 | 统一联调 |
|---|---|---|---|
| S2-01 | 装配真实交易服务和本任务的 PostgreSQL 持久层。复用 S1 的通用事务、事件及调度设施，替换身份、商品占用、会话和管理业务命令。用可控时钟推进等待时间 | 同商品两条待接受请求、不同版本的约定、单方确认、争议中交易及终态交易。验证状态机只接受合法转换，锁单冲突、重试、超时和恢复的结果及调用顺序符合契约。参见 TC-TRD-001、TC-TRD-005、TC-TRD-006 | 以真实商品和会话端口验证跨模块竞争锁单、结束释放与系统消息归档 |
| S2-02 | 装配真实商品、分类服务及本任务迁移。使用 S1 文件服务完成图片授权、上传和核验，替换身份、认领、交易执行和通知业务 | 卖方、认领管理员、待审商品、两项待审核分类和已核验图片。尝试认领前撤回、拒绝后重提、批准分类、上下架和组合搜索，检查权限、历史及分类原子性。参见 TC-PRD-036、TC-PRD-037、TC-PRD-040 | 连接真实事项、账户资格和交易占用，核对图片引用、审核及下架的联动 |
| S2-03 | 启动用户端的商品和交易路由。用 OpenAPI 模拟账号、商品、文件、交易 API，以同名占位组件接入 S2-04 的插槽 | 在手机和桌面浏览、筛选、发布、发起请求和提交确认。模拟空列表、上传失败、会话失效及 409 冲突，检查按钮状态、提示和重试策略 | 挂载实际互动组件并使用真实 API 联调发布、购买及交易详情 |
| S2-04 | 装配本任务的评论、收藏、评价服务及持久层，替换商品查询、交易终态及身份。互动组件在独立预览页启动 | 准备公开与失效商品、买卖双方和已完成交易。核对评论作者权限、失效收藏的提示与恢复、每方一次评价及本人查询 | 将组件接入 S2-03 的页面，核对真实商品可见性及完成交易后的评价资格 |
