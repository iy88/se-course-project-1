## 用户端 PWA

PWA 归入 S2-03（[#75](https://github.com/iy88/se-course-project-1/issues/75)），依据[用户端架构设计](../architecture/01-设计依据与目标.md)。用户端生产构建提供 Web App Manifest、安装图标和 Service Worker，可从 HTTPS 站点安装并以独立窗口启动。离线时提供已缓存的应用壳和明确提示，联网恢复后可重试。Service Worker 缓存范围限于应用壳和带版本的静态资源，API、登录态及私有文件响应不进入该缓存，离线写操作直接反馈失败。

发布验证覆盖 HTTPS 下的注册与作用域、版本升级和旧缓存清理，确保上线后可获得新应用壳且静态资源版本一致。旧版验收参考 [#1](https://github.com/iy88/se-course-project-1/issues/1) 与离线空白页回归 [#9](https://github.com/iy88/se-course-project-1/issues/9)。

## 独立启动与测试

各工作包使用共同契约和隔离数据独立验证。阶段联调接入实际依赖并执行以下验收。

- [ ] 用真实账户、商品、分类、审核事项、文件及通知服务演示发布 → 认领 → 审核 → 展示，核对拒绝重提和多分类搜索。
- [ ] 在“我的”验证头像上传、更换、移除及默认显示；核对文件用途、归属和已核验状态，确认旧头像引用释放。
- [ ] 用阶段版本本地启动双前端、API 和所需后台进程，记录冒烟版本、环境和结果。
- [ ] 用移动浏览器验证安装、独立窗口启动和断网刷新；恢复网络后重试业务请求。发布下一版本，确认客户端能取得新应用壳，且登录、退出及切换账号均不读取旧账号数据。
