## 独立启动与测试

| 子任务 | 启动及替换 | 数据、操作及预期 | 统一联调 |
|---|---|---|---|
| S4-01 | 装配处置编排及 S1 真实事务、审计、幂等和文件服务，使用隔离 PostgreSQL 与 OSS。替换账户、商品、交易、会话、事项及通知等业务端口，事务测试替身可在同一测试数据源写入可检查记录 | 固定锁集合、同次请求、处理中失败、待核验与已核验文件。检查记录回滚、同键重放、按事项入口校验授权、用途和证据引用。参见 TC-COM-001、TC-CASE-005、TC-CASE-006 | 连接真实主体及会话验证封禁、冻结、下架和归档的原子性，核对图片与证据引用 |
| S4-02 | 装配真实统计逻辑和管理前端，替换各主体统计事实、分类、认领与审核 API | 给定两个管理员、时间边界上的已确认结果与处理中事项。验证共享池、审核提示、分类操作、鉴权和统计口径。参见 TC-COM-031、TC-CASE-001 | 真实管理入口验证统计快照、当前权限和审核执行结果 |
| S4-03 | 启动事项用户端页面。模拟账户、事项 API、文件直传与核验，在独立路由加载会话及本人事项占位组件 | 准备举报、逐条问询、决定和申辩样例。模拟核验失败、权限变化、已结案或超期，检查反馈、可用动作和提交结果 | 接入真实会话、OSS 上传、事项 API 及通知，在手机与桌面联合核对 |
| S4-04 | 装配真实事项服务与本任务迁移，使用 S1 文件能力，替换会话、主体处置、通知及账户资格，以固定时钟推进申辩期 | 两名管理员并发认领，准备未决问询、待处理申辩及匿名结果。检查固定认领、逐条回复、申辩期限和访问隔离。参见 TC-CASE-001、TC-CASE-004、TC-CASE-008 | 用真实主体执行结果核对处置依据、事项状态、审计、归档和匿名投影 |
