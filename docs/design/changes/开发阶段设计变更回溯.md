## CHG-002 OSS 内容核验与上传约束

| 字段 | 内容 |
|---|---|
| 阶段 | S1 |
| 原因及变更 | 已登记的文件核验使用 SHA-256 对实际字节摘要，上传能力公开图片像素预算。S1 改用 If-Match 条件读取和前后 ETag 比较，内部标识移除 SHA-256，API 不再返回摘要或像素上限。单文件初始上限为 100 MiB，核验按实际字节及格式进行。开发与联调共用一个 v2 私有 Bucket，生产独立。 |
| 影响与同步 | Q-002 的禁止覆盖约束、文件身份与配置快照、API-COM-FILE-002／003。 |
| 确认与复核 | 见 [提交 `51c2bc79`](https://github.com/iy88/se-course-project-1/commit/51c2bc79)、[PR #87](https://github.com/iy88/se-course-project-1/pull/87)，2026-11-19 并入 main |
| 回归依据 | TC-COM-011—014 的真实 OSS 验证应覆盖覆盖拒绝、条件读取失败及规则快照。 |
