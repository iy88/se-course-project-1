# 运行与部署说明

状态：已确认运行原则；实际版本、命令、路径与资源在部署实现时登记。

## 环境与配置

开发、测试和正式环境分别登记 PostgreSQL、Redis、OSS、SMTP 和访问地址。后端统一 .env，前端各自维护开发／构建配置；配置模型检查类型、范围、必要依赖和关联关系。各实例连接池和内存统一预算。

## 启动与迁移

独立步骤执行 Alembic 迁移，再由 systemd 启动原生 API、IM、worker、scheduler 多实例。Nginx 维护静态资源与 HTTP／WS 上游。实际启动命令及监听清单待部署任务细化。

## CI/CD

GitHub Actions 验证提交，Jenkins 构建并部署明确版本，执行配置资源检查、迁移、逐实例滚动、就绪检查和业务验证。前端独立构建，发布登记接口兼容及配置版本。

## 停止与恢复

实例停止新接入／领取工作，按配置排空，IM 重连及任务认领协议衔接。保留可用版本及配置，按数据库兼容范围回退。数据库、Redis 和文件备份恢复步骤及会话恢复语义在实际部署计划中明确并验证。

## 责任

部署、服务器、Nginx、实例、配置发布、迁移执行、回退和部署验收由 TASK-001专门负责。模块成员提供交付及兼容性说明。
