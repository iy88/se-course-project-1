## 观察与修正

| 观察 | 分类 | 处理 | 结论 |
|---|---|---|---|
| 并行测试首次加载时 Rsbuild 日志出现 `Unexpected token '<'` | 测试工具链问题，非业务缺陷 | E2E 环境关闭 Rsbuild 懒编译；完整重复运行未再出现 | 已解决 |
| `__Host-` CSRF Cookie 不能直接通过 Playwright `addCookies` 在 HTTP loopback 构造 | 测试夹具问题 | 改为会话响应下发真实 `Set-Cookie` 头 | 已解决 |
| PR #188 复审指出离线阶段 Mock API 仍可能返回商品 | P2 测试真实性 | 离线时显式阻断 API，验证 `NavigationTiming.workerStart`，断言应用壳与数据不可用；联网重试后验证 API 和数据显示恢复 | 已修正，复测通过 |
| PR #188 复审指出旧响应屏障只证明 Mock handler 结束 | P2 竞态真实性 | 拆为浏览器确认请求中止、传输忽略 abort 且客户端收到旧响应两条路径；使用 XHR `loadend` 作为客户端完成屏障，并增加 generation guard | 已修正，复测通过 |
| PR #188 复审指出 Playwright TS 未被类型检查 | P2 检查缺口 | 新增 `tsconfig.e2e.json`，统一 `typecheck` 覆盖 E2E 与配置，并接入 CI | 已修正，检查通过 |
| PR #188 复审指出 Mock handler 异常可能被隐藏为 500 | P2 失败可见性 | 记录非预期 handler 异常并在 teardown 断言；主动取消的 Route 不记录 | 已修正，完整套件无非预期异常 |

## 未覆盖与边界

- 只执行 Chromium，未覆盖 Firefox、WebKit、移动设备或真实浏览器扩展。
- API 全部模拟，未验证真实后端事务、PostgreSQL 唯一约束、Redis 游标、OSS、SMTP 和跨实例并发。
- 多浏览器协同只验证客户端状态刷新，不替代后端并发接受与唯一占用测试。
- PWA 使用本机生产预览和离线上下文，不替代 HTTPS、反向代理缓存策略、CDN 或生产服务端部署验收。
- 测试不包含真实账号、密码、Cookie、CSRF 原值、签名 URL 或个人数据。
