## 维护规则

1. 每个批次只维护一份报告；报告中按 RUN 覆盖多个执行项。
2. 发现产品问题时提独立缺陷 Issue，不为每个原 TC 开 Issue。
3. 修复 PR 合入后由原批次追加复测证据，再更新本表。
4. 原 TC 的自动测试数量和覆盖范围继续增加，不要求与 72 个人工项一一对应。
