### 覆盖率口径

本报告记录的是 **Failsafe 套件覆盖率**，包含由 Failsafe 执行的集成测试以及该套件中的配置边界用例，不包含 Surefire 单元测试的执行数据。独立聚合只加载 `backend-app/target/jacoco-it.exec`，覆盖 11 个 Java 模块并排除 `maintenance`。前端代码和 SQL 迁移脚本不在 Java 字节码统计范围内。
