## 真实环境与准备

- 本批负责人使用自己独立的 PostgreSQL 测试库、Redis 和私有 OSS，自行创建、维护和清理本 Issue 所需的全部数据。四个测试 Issue 可并行执行，彼此不依赖数据、对象 ID、导出数据或执行结果。
- B、C、D 批允许用 SQL 或种子脚本直接写入自己的测试库，准备已满足约束的前置样本。例如，可预置账户、商品和事项。A 批通过真实流程验证这些数据的创建。报告记录样本来源和初始状态。本批被测的页面操作及结果须真实执行、观察和取证，涉及实际上传、通知或实时的断言须使用自己的真实依赖。
- 自行准备买卖双方和两名管理员账户、已完成且可评价的交易、举报对象及统计和聚合所需样本。已有事项可作为前置样本，D 项要求的新举报及其创建结果须实际提交和验证。
- 两名管理员使用独立浏览器验证认领竞争与权限隔离。使用本批 OSS 上传举报／处置证据，使用本批 Redis 验证通知、断线与补取，并用本批数据库核对事项、处置、待办、统计和聚合。
