## 会话接口

### 账户多 Session 与多连接

同一账户可同时持有多个 Session 与多条连接，接口按账户身份鉴权，不把连接当作参与者。发送成功的消息投递到本人其他连接；各连接维护自身投递游标，断线或换设备后按类型会话与 `seq` 重新补拉数据库历史，不依赖连接内缓存。已读推进为账户级单调值，`message_read` 只同步本人其他连接，不告知对端；会话列表、事项列表、通知列表与通知标读均不推进会话已读。

### API-CONV-001 建立或复用普通私聊

| 项目 | 内容 |
|---|---|
| 需求与决策依据 | FR-04、BR-18、BR-32；[会话与处置事项](../key-designs/会话与处置事项.md) |
| 方法与路径 | `POST /api/v1/conversations/private` |
| 调用者及权限 | 已登录本账户；不得向本人发起；封禁账户可读既有会话但不得新建 |
| 请求 | `target_account_id`：EntityId 字符串，必填；名称等其他字段由服务端读取，不接受客户端指定 |
| 成功响应 | `200`：`conversation_id`、`branch_id`、`branch_type = private`、`peer {account_id, display_name}`、`reused`。已有同一对用户会话时返回既有标识且 `reused = true` |
| 失败响应 | `SELF_CONVERSATION_FORBIDDEN`（422，本人）、`RESOURCE_NOT_VISIBLE`（404，目标账户不存在或不可见，不区分具体原因）、`ACCOUNT_WRITE_RESTRICTED`（403，封禁账户） |
| 前置与后置 | 前置：目标为其他已存在账户。后置：会话与普通私聊分支存在且参与关系为两条 `peer`；不自动发送任何消息，不创建交易分支 |
| 并发与幂等 | 同一 `Idempotency-Key` 重放返回同次结果；并发建立同一 `pair_key` 时唯一约束协调，后到者读取既有会话返回同一标识 |
| 事务 | 会话、分支、参与关系同一事务提交 |
| 隐私 | 只返回对端当前显示名称与分支标识，不返回邮箱、Session 或其他分支 |

### API-CONV-002 会话与分支列表

| 项目 | 内容 |
|---|---|
| 需求与决策依据 | FR-04、FR-12、BR-18、第 4 章 4.17 |
| 方法与路径 | `GET /api/v1/conversations?page=&page_size=` |
| 调用者及权限 | 已登录本账户，只返回本人参与的会话；封禁账户可读 |
| 请求 | 查询参数分页；无过滤参数时返回全部双人入口 |
| 成功响应 | `items[]`：`conversation_id`、`peer {account_id, display_name}`、`branches[] {branch_id, branch_type, source_ref, archived_at, unread_count, last_message_at, last_message_preview}`；`page`、`page_size`、`total`。按 `last_message_at` 倒序，缺失时按分支建立时间 |
| 失败响应 | `SESSION_REQUIRED`（401）、`INPUT_INVALID`（422，分页越界） |
| 前置与后置 | 后置：只读，不改变任何分支的已读进度；进入列表不等于阅读消息（4.17） |
| 并发与幂等 | 只读接口，`unread_count` 取查询时点；同一时刻重复调用结果一致 |
| 事务 | 只读，不写库 |
| 隐私 | 事项线程不出现在本列表，由事项入口进入；`last_message_preview` 只取正文前若干字符，系统事件取通知摘要 |

### API-CONV-003 历史消息（游标）

| 项目 | 内容 |
|---|---|
| 需求与决策依据 | FR-04、FR-12、BR-18、BR-19；[会话与处置事项](../key-designs/会话与处置事项.md) |
| 方法与路径 | `GET /api/v1/branches/{branch_id}/messages?after_seq=&before_seq=&limit=` |
| 调用者及权限 | 该分支参与者；事项分支还须通过事项访问资格校验；认领管理员读取买卖双方消息不走本接口，按证据引用定位 |
| 请求 | `branch_id` 路径必填；`after_seq`／`before_seq` 二选一，缺省取最新一页；`limit` 取配置上限 |
| 成功响应 | `items[]`：`message_id` 或 `case_message_id`、`seq`、`sender {account_id, display_name, sender_kind}`、`message_type` 或 `message_kind`、`body`、`created_at`；`next_after_seq`／`next_before_seq`；`branch_status`（`active`／`archived`） |

| 前置与后置 | 后置：返回消息不自动标读；归档分支可读且 `branch_status = archived`；解冻不改变分支状态 |
| 并发与幂等 | 只读；按 `seq` 稳定排序，游标期间新增消息不打断翻页 |
| 事务 | 只读，不写库 |
| 隐私 | 事项分支只返回该线程的消息；不返回其他线程、举报人身份或管理员身份以外的信息；正文不做二次加工 |

| 方法与路径 | `POST /api/v1/branches/{branch_id}/messages` |
| 调用者及权限 | 该分支参与者；分支不得归档；账户不得封禁；该对用户之间不得存在有效交易冻结；事项分支不适用本接口 |

| 项目 | 内容 |
|---|---|
| 需求与决策依据 | FR-07、BR-25、BR-32、第 4 章 4.18；[事项主体与处置执行](../key-designs/事项主体与处置执行.md) |

| 事务 | 事项、流水（`submit`／`supplement`）、证据引用同一事务；通知意图仅在实际处置时产生 |
| 隐私 | 响应不回显举报人身份；不返回其他事项或对象信息 |

### API-CASE-007 处置决定与执行

| 项目 | 内容 |
|---|---|
| 需求与决策依据 | FR-08、BR-08、BR-26、BR-32、BR-33、TR-09、TR-10；[处置与主体协同](../key-designs/处置与主体协同.md) |

| 成功响应 | `201`：`decision_kind`、`decided_at`、`case_status = decided`、`enforcements[] {enforcement_id, action, target_ref, result_ref, result_status, previous_state, current_state, affected_scope}`、`notified_account_ids` |
| 失败响应 | `BASIS_REQUIRED`（422）、`TARGET_STATE_CONFLICT`（409）、`TRANSITION_NOT_ALLOWED`（409）、`LOCK_CONFLICT`（409，同商品已有锁单）、`OWNERSHIP_MISMATCH`（403）、`TRADE_FREEZE_NOT_ACTIVE`／`RESTRICTION_NOT_ACTIVE`（409）；任一执行失败整次回滚 |

| 事务 | 按公共锁序取得商品、交易、事项、会话锁后一次提交；目标集合变化时整事务重规划 |
| 隐私 | 响应只返回执行结果与受影响账户标识，不返回证据内容与他方申辩 |

| 成功响应 | `200`：`enforcement_id`、`lifted_at`、`lifted_by`、`restored_scope`、`remaining_restrictions[]` |
| 失败响应 | `RESTRICTION_NOT_ACTIVE`／`TRADE_FREEZE_NOT_ACTIVE`（409，已解除或已随交易结束自动解除）、`BASIS_REQUIRED`（422）、`NOT_CASE_MANAGER`（404） |
| 前置与后置 | 后置：按目标主体当前资格恢复，其他有效限制保留，不将原非在售商品变为在售；保留原执行记录 |
| 并发与幂等 | 同键重放返回同一解除结果；并发解除仅一次生效 |
| 事务 | 解除记录、主体状态与通知同一事务 |
| 隐私 | 只返回恢复范围与剩余限制类别，不返回其他事项信息 |

## 错误码与 HTTP 映射

| 错误码 | HTTP | 语义 |
|---|---|---|
| `SESSION_REQUIRED`／`SESSION_EXPIRED` | 401 | 进入登录流程 |
| `ACTION_NOT_ALLOWED`／`ACCOUNT_WRITE_RESTRICTED`／`OWNERSHIP_MISMATCH` | 403 | 当前资格与动作不匹配 |
| `RESOURCE_NOT_VISIBLE`／`PARTICIPANT_REQUIRED`／`NOT_CASE_MANAGER`／`NOT_CASE_PARTICIPANT` | 404 | 当前访问范围内无对应资源，不泄露存在性 |
| `STATE_CONFLICT`／`BRANCH_ARCHIVED`／`CASE_CLOSED`／`CASE_ALREADY_CLAIMED`／`TARGET_STATE_CONFLICT`／`TRANSITION_NOT_ALLOWED`／`LOCK_CONFLICT`／`RESTRICTION_NOT_ACTIVE`／`TRADE_FREEZE_NOT_ACTIVE` | 409 | 状态或并发前置不满足 |
| `TARGET_INVALID`／`EVIDENCE_OUT_OF_SCOPE`／`BASIS_REQUIRED`／`INPUT_INVALID`／`SELF_CONVERSATION_FORBIDDEN` | 422 | 输入、对象或依据不合法 |
| `RATE_LIMITED` | 429 | 附可重试时间 |
| `DEPENDENCY_UNAVAILABLE`／`TRANSACTION_RETRY_EXHAUSTED`／`INTERNAL_ERROR` | 503／500 | 按公共约定返回请求标识 |
