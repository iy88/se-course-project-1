# 交易与评价接口契约

设计归属：TASK-003。本文件第 3 批登记交易与评价本域接口；跨主体签名、锁集合与原子范围在第 4 批对齐 R0／R2a／R2b／C1／C3 评审版本。

## 通用约定

- 基础路径 `/api/v1`；JSON 使用 snake_case；ID 为十进制字符串；金额为整数分；时间为 UTC ISO 8601；状态与阶段为具名字符串。
- 写接口必须携带 `Idempotency-Key`；状态动作请求体必须携带 `expected_version`（整数，来自上一次 TradeView）。
- 成功响应按资源组织；错误结构按 C1：`error: {code, message, details}`、`request_id`、必要时 `operation_id`。
- 权限：仅交易双方可读写本域资源；管理员通过 TASK-004 的事项执行接口操作，不直接调用本域写接口；非参与方返回 404，避免泄露资源存在。
- 隐私：响应不含邮箱、Session、内部凭据；对方仅展示 `id`、`display_name`、`avatar_url`；历史与冻结原因仅参与方可见。
- 事务：所有写接口在同一事务内完成状态、约定、确认、计时、冻结、历史、会话创建／归档与通知意图；提交后投递。
- 幂等：作用域为 `(actor_id, operation_name, Idempotency-Key)`；同键同负载返回已保存结果，同键不同负载返回 `IDEMPOTENCY_PAYLOAD_CONFLICT`。
- 版本：`expected_version` 与当前 `version` 不一致返回 `VERSION_CONFLICT`；业务状态不匹配返回 `STATE_CONFLICT`；两者均不改变数据。

### 稳定错误码

| 错误码 | HTTP | 语义 |
|---|---|---|
| SESSION_REQUIRED／SESSION_EXPIRED | 401 | 需登录／重新登录 |
| ACTION_NOT_ALLOWED／ACCOUNT_WRITE_RESTRICTED | 403 | 资格或账户限制不允许 |
| RESOURCE_NOT_VISIBLE | 404 | 非参与方或资源不可见 |
| STATE_CONFLICT | 409 | 请求／交易／约定状态已变化 |
| VERSION_CONFLICT | 409 | `expected_version` 已过期 |
| IDEMPOTENCY_PAYLOAD_CONFLICT | 409 | 同键不同负载 |
| TRADE_FROZEN | 409 | 交易处于冻结，禁止推进 |
| PRODUCT_NOT_AVAILABLE | 409 | 商品生命周期或展示资格不允许 |
| OCCUPANCY_CONFLICT | 409 | 商品已有其他有效占用 |
| REQUEST_DUPLICATE | 409 | 同商品同买方已有待接受请求 |
| REQUEST_ALREADY_ENDED | 409 | 请求已结束；返回既有结果时按幂等处理 |
| AGREEMENT_REQUIRED | 409 | 尚无生效约定，不能确认完成 |
| AGREEMENT_ALREADY_PENDING | 409 | 本交易已有待决约定提案 |
| AGREEMENT_NOT_PENDING | 409 | 约定提案已决或不属于本交易 |
| CONFIRMATION_ALREADY_SUBMITTED | 409 | 本人已有当前确认 |
| CANCELLATION_NOT_ALLOWED | 409 | 当前阶段／角色不允许该取消方式 |
| CANCELLATION_ALREADY_PENDING | 409 | 本交易已有待决取消申请 |
| CANCELLATION_NOT_PENDING | 409 | 取消申请已决或不属于本交易 |
| DISPUTE_ALREADY_OPEN | 409 | 已有未解决争议 |
| DISPUTE_NOT_OPEN | 409 | 争议已解决或不存在 |
| TRADE_NOT_COMPLETED | 409 | 交易未完成，不能评价 |
| REVIEW_ALREADY_SUBMITTED | 409 | 本人已评价本笔交易 |
| TRADE_TERMINAL | 409 | 交易已完成或已终止，状态不可再改变 |
| RATE_LIMITED | 429 | 频率限制 |
| DEPENDENCY_UNAVAILABLE | 503 | 依赖暂不可用 |

已完成／已终止为终态；写接口对终态交易返回 `TRADE_TERMINAL`，不改变交易、商品、会话或限制。

### TradeView

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 交易标识 |
| product | object | `id`、`title`、`price_cents`；详情资格按 R0，不输出受限内容 |
| buyer／seller | object | `id`、`display_name`、`avatar_url` |
| status／phase | string／string? | 生命周期与阶段；阶段由交易状态与有效约定派生 |
| terminal_reason | string? | `completed`／`cancelled`／`admin_terminated`；终态时有值 |
| request | object | `note`、`requested_at`、`responded_at`、`close_reason` |
| agreement | object | `current`（生效约定）、`pending`（待决提案）；字段同约定 |
| confirmations | object | `current` 数组（确认人、时间、说明）；`both_current` 布尔 |
| wait | object | `active`、`started_at`、`deadline_at`、`remaining_seconds`、`paused` |
| freeze | object | `active`、`items`（来源、原因、开始时间；不输出管理员私人信息） |
| cancellation | object | `pending`（提案人、原因、时间） |
| dispute | object | `open`（发起人、说明、时间） |
| trade_conversation_id | string | 交易会话标识（R2a `TradeConversation`） |
| version | integer | 乐观版本 |
| permissions | object | `allowed_actions` 数组，供前端展示按钮 |
| created_at／updated_at | string | 时间 |

## API-TRD-001 提交购买请求

| 项目 | 内容 |
|---|---|
| 接口编号／名称 | API-TRD-001／create_purchase_request |
| 需求与决策依据 | FR-05；US-05-AC-01；BR-01、BR-02、BR-03；TR-11；ADR-003、010 |
| 方法与路径 | POST `/products/{product_id}/purchase-requests` |
| 调用者及权限 | 已登录买方；不得为商品卖方；账户未封禁；商品公开可交易；非本人商品 |
| 请求 | 路径 `product_id`；体 `{note?: string ≤500, expected_product_version: integer}` |
| 成功响应 | 201，`Location: /api/v1/trades/{id}`；体 `TradeView`，`status=pending_acceptance`，返回 `trade_conversation_id` |
| 失败响应 | 403 `ACTION_NOT_ALLOWED`；409 `PRODUCT_NOT_AVAILABLE`／`REQUEST_DUPLICATE`／`VERSION_CONFLICT`；422 `INPUT_INVALID` |
| 前置与后置 | 前置：商品公开、无本人待接受请求；后置：新增待接受交易与会话，商品不变、不锁单；快照于接受时创建 |
| 并发与幂等 | 唯一约束 `(product_id,buyer_id) where pending`；商品版本校验；同键同负载返回既有结果，同键不同负载冲突 |
| 事务 | 交易 + 会话 + 状态历史 + 通知意图同事务；会话失败回滚 |
| 隐私 | 仅返回本人、卖方与商品公开信息；不返回其他买方 |
| 测试关联 | TC-TRD-002、TC-TRD-015 |

|---|---|
| 接口编号／名称 | API-TRD-002／accept_purchase_request |
| 需求与决策依据 | FR-05、FR-09；US-05-AC-02；BR-01—BR-03；TR-05、TR-11、TR-12；4.15 |
| 方法与路径 | POST `/trades/{trade_id}/accept` |
| 调用者及权限 | 卖方本人；账户未封禁；交易未冻结；请求为待接受 |
| 请求 | 体 `{expected_version: integer}` |
| 成功响应 | 200 `TradeView`：`in_progress`、`phase=first_agreement_pending`；其他待接受请求已关闭；商品交易中 |
| 失败响应 | 403 `ACTION_NOT_ALLOWED`；409 `OCCUPANCY_CONFLICT`／`PRODUCT_NOT_AVAILABLE`／`REQUEST_ALREADY_ENDED`／`STATE_CONFLICT`／`VERSION_CONFLICT`／`TRADE_FROZEN` |

| 并发与幂等 | 账户资格锁 → 商品行锁 → 交易行锁；商品唯一占用部分索引；同键重放不重复关闭／通知 |
| 事务 | 占用、交易、其他请求关闭、快照、会话保持、通知同事务 |
| 隐私 | 仅返回本交易双方与商品公开信息 |
| 测试关联 | TC-TRD-001、TC-TRD-003、TC-TRD-014 |

## 写接口示例（正常／业务失败／同次重复）

| 接口 | 正常 | 业务失败 | 同次重复 |
|---|---|---|---|
| 001 | 201，`status=pending_acceptance`，返回 `trade_conversation_id` | 409 `REQUEST_DUPLICATE`（同商品同买方已有待接受） | 同键重放 201，返回同一 `id`／`trade_conversation_id`，不重复建会话 |
| 002 | 200，`in_progress`，其他请求 `closed` | 409 `OCCUPANCY_CONFLICT`（并发另一笔先接受） | 同键重放 200，同一结果，不再关闭／通知 |
| 003 | 200，`rejected` | 409 `STATE_CONFLICT`（已撤回） | 同键重放 200，同一结果 |
| 004 | 200，`withdrawn` | 409 `STATE_CONFLICT`（已接受） | 同键重放 200，同一结果 |
| 005 | 201，提案 `proposed` | 409 `TRADE_FROZEN` 或 422 要素缺失 | 同键重放 201，同一 `agreement_id` |
| 006 | 200，`effective` 或 `rejected` | 409 `AGREEMENT_NOT_PENDING`（已决） | 同键重放 200，同一决定结果 |
| 007 | 201，本人确认；第二方确认后 200／完成 | 409 `AGREEMENT_REQUIRED`（无生效约定） | 同键重放 201，同一 `confirmation_id`；不同键重复 409 `CONFIRMATION_ALREADY_SUBMITTED` |
| 008 | 201，`direct` 返回 `terminated`；`approval` 返回 `pending` | 409 `CANCELLATION_NOT_ALLOWED`（约定后单方直接取消） | 同键重放 201，同一提案／终止结果 |
| 009 | 200，`accepted` 后 `terminated` | 409 `CANCELLATION_NOT_PENDING` | 同键重放 200，同一结果 |
| 010 | 201，`disputed` | 409 `DISPUTE_ALREADY_OPEN` | 同键重放 201，同一 `dispute_id` |
| 011 | 200，双方确认后 `in_progress` | 409 `DISPUTE_NOT_OPEN` | 同键重放 200，同一结果 |

## 查询约定

- 列表默认按更新时间与 ID 稳定排序；分页参数非法返回 422；越权不返回资源存在性。
- `include=state_history` 仅参与方可用；历史按时间正序，分页上限 200；管理员不从本接口读取。
- 交易详情中的 `permissions.allowed_actions` 仅作展示提示，服务端每次仍按当前状态与资格重新校验。
