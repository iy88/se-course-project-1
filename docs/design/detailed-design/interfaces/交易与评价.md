# 交易与评价接口契约

设计归属：TASK-003。本文件第 3 批登记交易与评价本域接口；跨主体签名、锁集合与原子范围在第 4 批对齐 R0／R2a／R2b／C1／C3 评审版本。

## 通用约定

- 基础路径 `/api/v1`；JSON 使用 snake_case；ID 为十进制字符串；金额为整数分；时间为 UTC ISO 8601；状态与阶段为具名字符串。
- 写接口必须携带 `Idempotency-Key`；状态动作请求体必须携带 `expected_version`（整数，来自上一次 TradeView）。
- 成功响应按资源组织；错误结构按 C1：`error: {code, message, details}`、`request_id`、必要时 `operation_id`。
- 权限：仅交易双方可读写本域资源；管理员通过 TASK-004 的事项执行接口操作，不直接调用本域写接口；非参与方返回 404，避免泄露资源存在。
- 隐私：响应不含邮箱、Session、内部凭据；对方仅展示 `id`、`display_name`、`avatar_url`；历史与冻结原因仅参与方可见。
- 事务：所有写接口在同一事务内完成状态、约定、确认、计时、冻结、历史、会话创建／归档与通知意图；提交后投递。
- 幂等：作用域为 `(actor_id, operation_name, Idempotency-Key)`；同键同负载返回已保存结果，同键不同负载返回 `IDEMPOTENCY_PAYLOAD_CONFLICT`。
- 版本：`expected_version` 与当前 `version` 不一致返回 `VERSION_CONFLICT`；业务状态不匹配返回 `STATE_CONFLICT`；两者均不改变数据。

### 稳定错误码

| 错误码 | HTTP | 语义 |
|---|---|---|
| SESSION_REQUIRED／SESSION_EXPIRED | 401 | 需登录／重新登录 |
| ACTION_NOT_ALLOWED／ACCOUNT_WRITE_RESTRICTED | 403 | 资格或账户限制不允许 |
| RESOURCE_NOT_VISIBLE | 404 | 非参与方或资源不可见 |
| STATE_CONFLICT | 409 | 请求／交易／约定状态已变化 |
| VERSION_CONFLICT | 409 | `expected_version` 已过期 |
| IDEMPOTENCY_PAYLOAD_CONFLICT | 409 | 同键不同负载 |
| TRADE_FROZEN | 409 | 交易处于冻结，禁止推进 |
| PRODUCT_NOT_AVAILABLE | 409 | 商品生命周期或展示资格不允许 |
| OCCUPANCY_CONFLICT | 409 | 商品已有其他有效占用 |
| REQUEST_DUPLICATE | 409 | 同商品同买方已有待接受请求 |
| REQUEST_ALREADY_ENDED | 409 | 请求已结束；返回既有结果时按幂等处理 |
| AGREEMENT_REQUIRED | 409 | 尚无生效约定，不能确认完成 |
| AGREEMENT_NOT_PENDING | 409 | 约定提案已决或不属于本交易 |
| CONFIRMATION_ALREADY_SUBMITTED | 409 | 本人已有当前确认 |
| CANCELLATION_NOT_ALLOWED | 409 | 当前阶段／角色不允许该取消方式 |
| CANCELLATION_NOT_PENDING | 409 | 取消申请已决或不属于本交易 |
| DISPUTE_ALREADY_OPEN | 409 | 已有未解决争议 |
| DISPUTE_NOT_OPEN | 409 | 争议已解决或不存在 |
| TRADE_NOT_COMPLETED | 409 | 交易未完成，不能评价 |
| REVIEW_ALREADY_SUBMITTED | 409 | 本人已评价本笔交易 |
| TRADE_TERMINAL | 409 | 交易已完成或已终止，状态不可再改变 |
| RATE_LIMITED | 429 | 频率限制 |
| DEPENDENCY_UNAVAILABLE | 503 | 依赖暂不可用 |

已完成／已终止为终态；写接口对终态交易返回 `TRADE_TERMINAL`，不改变交易、商品、会话或限制。

### TradeView

| 字段 | 类型 | 说明 |
|---|---|---|
| id | string | 交易标识 |
| product | object | `id`、`title`、`price_cents`；详情资格按 R0，不输出受限内容 |
| buyer／seller | object | `id`、`display_name`、`avatar_url` |
| status／phase | string／string? | 生命周期与阶段；阶段由交易状态与有效约定派生 |
| terminal_reason | string? | `completed`／`cancelled`／`admin_terminated`；终态时有值 |
| request | object | `note`、`requested_at`、`responded_at`、`close_reason` |
| agreement | object | `current`（生效约定）、`pending`（待决提案）；字段同约定 |
| confirmations | object | `current` 数组（确认人、时间、说明）；`both_current` 布尔 |
| wait | object | `active`、`started_at`、`deadline_at`、`remaining_seconds`、`paused` |
| freeze | object | `active`、`items`（来源、原因、开始时间；不输出管理员私人信息） |
| cancellation | object | `pending`（提案人、原因、时间） |
| dispute | object | `open`（发起人、说明、时间） |
| trade_conversation_id | string | 交易会话标识（R2a `TradeConversation`） |
| version | integer | 乐观版本 |
| permissions | object | `allowed_actions` 数组，供前端展示按钮 |
| created_at／updated_at | string | 时间 |

| API-TRD-003 | POST `/trades/{trade_id}/reject` | 拒绝请求 | 卖方 |
| API-TRD-004 | POST `/trades/{trade_id}/withdraw` | 撤回请求 | 买方 |
| API-TRD-005 | POST `/trades/{trade_id}/agreements` | 提出首次约定或变更 | 买方／卖方 |
| API-TRD-006 | POST `/trades/{trade_id}/agreements/{agreement_id}/decisions` | 同意／拒绝约定 | 对方 |
| API-TRD-007 | POST `/trades/{trade_id}/completion-confirmations` | 提交完成确认 | 买方／卖方 |
| API-TRD-008 | POST `/trades/{trade_id}/cancellation-proposals` | 提出取消／直接取消 | 买方／卖方 |

| API-TRD-011 | POST `/trades/{trade_id}/disputes/{dispute_id}/resolution-confirmations` | 确认争议已解决 | 买方／卖方 |
| API-TRD-012 | POST `/trades/{trade_id}/reviews` | 提交评价 | 买方／卖方 |
| API-TRD-013 | GET `/trades/{trade_id}` | 交易详情 | 参与方 |

| API-TRD-015 | GET `/me/reviews` | 本人评价列表 | 本人 |
