| 项目 | 内容 |
|---|---|
| 接口编号／名称 | 待填写 |
| 需求与决策依据 | FR、BR、权限、状态转换与 ADR：待填写 |
| 方法与路径 | 待讨论 |
| 调用者及权限 | 角色、对象归属、受限账户行为：待讨论 |
| 请求 | 路径、查询、请求头、请求体；字段、类型、必填、范围与空值规则：待讨论 |
| 成功响应 | HTTP 状态、字段类型、业务状态及示例：待讨论 |
| 失败响应 | 条件、错误码、字段、示例及数据变化：待讨论 |
| 前置与后置 | 原状态、允许条件与业务不变量：待讨论 |
| 并发与幂等 | 请求键、版本检查、重复请求、不同负载与竞争校验结果：待讨论 |
| 事务 | 同时成功的数据变化及事务外副作用：待讨论 |
| 隐私 | 各角色输出字段、日志字段清单及脱敏：待讨论 |
| 测试关联 | TC 编号：待填写 |
| 确认 | 提供方、调用方、复核人及版本：待填写 |
