# 商品与分类接口契约

设计归属：TASK-002；编写账号：`GALAXY-JIN`。本文件第 2 批登记商品本域接口：发布审核、上下架、检索详情、编辑历史及禁发范围；第 3 批登记分类维护与申请、评论回复、收藏接口。占用、处置执行、文件与通知的商品侧适配在第 4 批按 R1／R2b／C1／C3 评审版本对齐。

## 归属与约定

| 项目 | 约定 |
|---|---|
| 需求与规则 | FR-02、FR-03、FR-08 审核部分、FR-09 商品部分、FR-13；BR-09—BR-17、BR-32—BR-34；TR-01—TR-10、TR-20、TR-21；4.3、4.4、4.10、4.13、4.16、4.18。业务规则见[商品与分类](../key-designs/商品与分类.md)，字段与派生的判定以该文件 `Product`、`Category`、`CategoryName`、`ProductComment` 方法为准 |
| 基础路径 | `/api/v1`；资源用复数名词；管理端操作置于 `/admin` |
| 命名与类型 | JSON `snake_case`；ID 为十进制字符串；金额为整数分；时间为 UTC ISO 8601；状态为具名字符串 |
| 鉴权 | 持久 Secure／HttpOnly Cookie 携带 Session 凭据；状态变更请求校验 CSRF（[共享接口约定](../02-共享接口约定.md)） |
| 写操作 | 所有 `POST`／`PATCH`／`PUT` 携带 `Idempotency-Key`；状态动作携带 `expected_version`，取 `ProductDetail.content_version`；审核结论按最新内容规则不要求 `expected_version`（API-PRD-006） |
| 错误结构 | `error: {code, message, details}`、`request_id`，已建立逻辑操作时附 `operation_id`（[公共事务与权限](../key-designs/公共事务与权限.md)） |
| 权限 | 仅已登录账户访问；卖方按本人商品、管理员按事项认领、买方按参与关系；不可见资源统一返回 404，不泄露存在 |
| 隐私 | 响应不含邮箱、Session 或内部凭据；卖方仅展示 `id`、`display_name`；图片使用短期签名地址；日志不记录描述正文 |
| 事务 | 由用例持有同一 `AsyncSession` 与执行上下文；商品、审核、分类、文件引用及通知意图同事务，内部能力不提交 |
| 幂等 | 作用域为 `(actor_id, operation_name, Idempotency-Key)`；同键同负载返回已保存结果，同键不同负载返回 `IDEMPOTENCY_PAYLOAD_CONFLICT` |
| 版本 | `expected_version` 与当前 `content_version` 不一致返回 `VERSION_CONFLICT`；生命周期或审核状态不匹配返回 `STATE_CONFLICT`；两者均不改变数据 |
| 分页 | 列表使用 `page`／`page_size` 并返回 `total`；搜索按 `created_at` 倒序、`product_id` 倒序；编辑历史按 `edited_at` 倒序、`edit_id` 倒序 |
| 测试关联 | 逐接口 `TC-PRD` 编号与第 5 批 `test-cases/商品与分类.md` 一致；本文件登记设计预期 |
| 确认 | 提供方金婉怡（`GALAXY-JIN`）；调用方 TASK-001、TASK-003、TASK-004；复核人袁尚峰（`iy88`），评审意见与日期随 PR 登记 |

## 稳定错误码

| 错误码 | HTTP | 语义 |
|---|---|---|
| SESSION_REQUIRED／SESSION_EXPIRED | 401 | 需登录／重新登录 |
| ACTION_NOT_ALLOWED | 403 | 当前身份、对象归属或管理资格不允许 |
| ACCOUNT_WRITE_RESTRICTED | 403 | 账户封禁或发布限制生效 |
| RESOURCE_NOT_VISIBLE | 404 | 资源不在当前可见范围，或审核事项不属于当前认领管理员 |
| STATE_CONFLICT | 409 | 生命周期、审核状态或取消／结束状态已变化 |
| VERSION_CONFLICT | 409 | `expected_version` 已过期 |
| IDEMPOTENCY_PAYLOAD_CONFLICT | 409 | 同键对应其他输入 |
| TRADE_FROZEN | 409 | 交易冻结施加的发布、上架或下架限制生效 |
| PRODUCT_LOCKED | 409 | 存在未结束占用，不能主动下架 |
| PRODUCT_NOT_RELISTABLE | 409 | 已下架但最新审核未通过或生命周期不符 |
| DISPLAY_RESTRICTED | 409 | 存在生效展示限制，当前动作不可执行 |
| EDIT_NOT_ALLOWED_IN_TRADE | 409 | 交易中禁止修改关键内容 |
| PRODUCT_NOT_RESUBMITTABLE | 409 | 当前生命周期或审核结论不允许重新提交 |
| REVIEW_NOT_PENDING | 409 | 审核记录不在待处理状态 |
| REVIEW_ALREADY_CLAIMED | 409 | 审核事项已被认领，卖方不能撤回商品 |
| REVIEW_CATEGORY_INSUFFICIENT | 409 | 提交结论时无获认可分类，不能通过 |
| CATEGORY_REQUIRED | 422 | 未选择分类且无新增分类申请 |
| CATEGORY_NOT_SELECTABLE | 422 | 分类不存在、已停用或已删除 |
| CATEGORY_APPLICATION_CONFLICT | 409 | 同商品已有待处理分类申请 |
| CATEGORY_APPLICATION_NOT_ALLOWED | 409 | 商品当前生命周期不允许提交或撤回分类申请 |
| CATEGORY_APPLICATION_NOT_PENDING | 409 | 同商品没有待处理分类申请 |
| CATEGORY_NOT_DELETABLE | 409 | 分类已关联商品，只能停用 |
| CATEGORY_NAME_NOT_ALIAS | 409 | 指定名称不是该分类的有效别名 |
| COMMENT_NOT_ALLOWED | 409 | 商品当前不可见或不允许新增评论／回复 |
| COMMENT_REPLY_NOT_ALLOWED | 403 | 只有商品卖方可以回复，且回复只能指向顶级评论 |
| COMMENT_ALREADY_REMOVED | 409 | 评论已由管理员移除，作者不能删除 |
| FAVORITE_NOT_ALLOWED | 403 | 账户封禁期间不能收藏或取消收藏 |
| CATEGORY_NAME_CONFLICT | 409 | 分类名称的有效规范化结果已被占用 |
| BANNED_SCOPE_INCOMPLETE | 422 | 禁发范围未覆盖 BR-13 要求的类目 |
| FILE_NOT_REFERENCEABLE | 409 | 文件状态不允许建立引用 |
| FILE_PURPOSE_MISMATCH | 422 | 文件用途与 `product_image` 不符 |
| FILE_ACTION_NOT_ALLOWED | 403 | 文件归属或复制资格不符 |
| INPUT_INVALID | 422 | 输入格式、长度、范围或组合校验失败 |
| RATE_LIMITED | 429 | 返回可用重试时间 |
| DEPENDENCY_UNAVAILABLE | 503 | 依赖暂不可用 |

`PRODUCT_NOT_AVAILABLE`、`OCCUPANCY_CONFLICT`、`OCCUPANCY_NOT_HELD` 由 R1 的接受／结束接口按 R0 结果映射，不在本文件重复定义。

### ProductDetail

| 字段 | 类型 | 说明 |
|---|---|---|

| title／description | string | 当前内容；描述正文按权限返回 |
| price_cents | integer | 整数分 |
| images | array | `file_id`、`url`、`expires_at`，按当前图片引用 `slot` 排序 |
| categories | array | `id`、`name`；当前名称 |
| seller | object | `id`、`display_name` |
| lifecycle_state | string | `pending_review`／`review_rejected`／`public`／`in_trade`／`off_shelf` |
| content_version | integer | 内容及分类关联版本；状态动作的 `expected_version` |
| created_at／updated_at | string | 时间 |
| pending_review | object? | 本人或认领管理员可见：`audit_id`、`case_id`、`submitted_at` |
| latest_review | object? | 本人或认领管理员可见：`audit_id`、`status`、`reason`、`decided_at` |

| permissions | object? | 本人可见：`can_edit`、`can_off_shelf`、`can_relist`、`can_withdraw_review`、`can_submit_review`；分别由 `Product.require_edit_key_content`、`require_off_shelf`、`require_relist`、`require_withdraw_pending`、`require_resubmit` 按当前上下文计算 |

## 审核事项认领

待审商品在 R2b 共享池形成 `case_type = product_review` 的事项，`target_ref = audit_id`。管理员通过 R2b 事项接口 `API-CASE-004 POST /api/v1/admin/cases/{case_id}/claim` 认领；认领后商品的审核详情与结论接口要求调用者为该事项当前认领人，认领人及时间从事项读取。本文件不重复定义认领接口；商品审核记录通过 `case_id` 关联事项，不复制认领字段。

## API-PRD-001 发布商品并提交审核

| 项目 | 内容 |
|---|---|
| 接口编号／名称 | API-PRD-001／create_product |
| 需求与决策依据 | FR-02、FR-09、FR-13；BR-10、BR-12、BR-13、BR-14、BR-22、BR-32、BR-33；TR-01；ADR-002、003、006、007、010 |
| 方法与路径 | POST `/api/v1/products` |
| 调用者及权限 | 已登录卖方；账户未封禁；无交易冻结施加的发布限制；不以已有商品为前提 |
| 请求 | 体 `{title, description, image_file_ids[], price_cents, category_ids[], category_application?: {proposed_name}}`；标题、描述长度与图片数量按配置；`category_ids` 与 `category_application` 至少一项 |
| 成功响应 | 201，`Location: /api/v1/products/{id}`；`ProductDetail`：`lifecycle_state = pending_review`，`pending_review {audit_id, case_id}` |
| 失败响应 | 403 `ACCOUNT_WRITE_RESTRICTED`；409 `TRADE_FROZEN`／`IDEMPOTENCY_PAYLOAD_CONFLICT`；422 `INPUT_INVALID`／`CATEGORY_REQUIRED`／`CATEGORY_NOT_SELECTABLE`／`FILE_NOT_REFERENCEABLE`／`FILE_PURPOSE_MISMATCH`／`FILE_ACTION_NOT_ALLOWED`；429 `RATE_LIMITED` |
| 前置与后置 | 前置：已有分类通过 `Category.require_selectable`；新分类申请按名称规范化提交；文件为本人已核验的 `product_image`；后置：商品、待处理审核、R2b 审核事项、分类申请及文件引用同事务建立；不通知卖方 |
| 并发与幂等 | 同键重放返回同一商品；同一商品至多一条待处理审核；新分类名称在审核通过时按 `CategoryName` 唯一索引解析，重复名称不阻止发布提交 |
| 事务 | 商品 + 审核记录 + 事项 + 分类申请 + 文件引用同事务；事项或文件失败整体回滚 |
| 隐私 | 仅返回本人商品与提交内容；不返回其他卖方或审核管理员信息 |
| 测试关联 | TC-PRD-001、TC-PRD-002 |

## API-PRD-002 编辑商品

| 项目 | 内容 |
|---|---|
| 接口编号／名称 | API-PRD-002／update_product |
| 需求与决策依据 | FR-02、FR-09；BR-10、BR-11、BR-12、BR-14、BR-33；TR-04；4.18；ADR-003、006、007 |
| 方法与路径 | PATCH `/api/v1/products/{product_id}` |
| 调用者及权限 | 商品卖方本人；账户未封禁；生命周期为待审核、审核未通过、公开可交易或已下架；交易中禁止修改关键内容；交易冻结时仅允许无关商品的合规编辑 |
| 请求 | 体可选字段 `{title?, description?, image_file_ids?, price_cents?, category_ids?, category_application?, expected_version}`；省略表示不修改；提供 `image_file_ids`／`category_ids` 时整体替换；`category_application` 仅在生命周期为待审核或审核未通过且无待处理申请时创建 |
| 成功响应 | 200 `ProductDetail`：`content_version` 递增；编辑历史追加一条；公开商品的相关买方收到变更通知 |

## 查询与分页约定

搜索以查询时点已提交数据为准，只在分页前应用 `Product.can_appear_in_search` 同一规则的查询谓词；多分类为全部匹配，关键词、分类与价格区间同时满足。编辑历史按读取者范围裁剪后分页，不在返回后由前端二次过滤。评论列表按顶级评论分页，回复随顶级评论返回；收藏列表按收藏时间倒序，失效项不返回商品内容；分类列表不设分页。列表不返回审核记录、限制依据或卖方联系方式。
