# C-07 咨询会话

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

组织买卖双方针对某件商品的私人文字沟通，承载会话建立、消息归属与访问资格。会话由买方发起，卖方在已有会话中回复，不主动发起新会话；会话不承载管理处置沟通，后者由 C-13 的处置通知与沟通单表达。

边界：同一买卖双方对同一商品不重复建立并行会话；首版不支持撤回、编辑、附件及群聊（BR-26）。会话不代替交易状态，也不因交易结束而删除历史（BR-27）。

## 主要业务属性

所属商品、参与双方、建立时间、最近活动时间（候选）。消息内容、发送者与发送时间属于 C-08，不在本类重复保存。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 咨询会话—商品 | 0..* : 1 | 会话总关联一件商品 |
| 咨询会话—消息（C-08） | 1 : 0..* | 消息归属会话 |
| 咨询会话—参与双方 | 2 | 买方与卖方，双方可查看本人参与的会话 |

## 关联规则、场景与用例

- 会话由买方向商品卖方发起，卖方在已有会话中回复：BR-17、BR-48。
- 同一双方同一商品沿用已有会话，不重复创建：BR-48。
- 不得向本人发起私聊：BR-28。
- 撤销公开访问后不允许新建商品咨询会话；交易中／已售出不新建会话，已有会话保留读取：BR-27。
- 封禁或涉事冻结期间禁止发送，会话保留查看：BR-22、BR-53。
- 管理访问限于认领事项处理所需的相关消息，不具日常任意浏览权限：BR-18、BR-51。
- 场景：SC-04；用例：UC-C04。

## 状态归属

本节不强制为会话建立独立状态模型（[5.2](../draft-05-行为与状态.md) 只要求确有生命周期规则时再分析）。当前可表达的是发送资格与读取资格随封禁、冻结、商品展示资格变化，属条件而非会话状态。

## 待决与边界

- 会话归档或关闭是否需要独立表达，规则中未出现，不预设；如后续引入须先登记为未决并由组长决定。
- FR-11 未读提示与会话未读的关系待 P-20 定，不在此先行合并规则。
