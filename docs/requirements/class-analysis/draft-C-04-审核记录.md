# C-04 审核记录

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

记录认领管理员对某件商品及其内容范围的审核结论、拒绝理由与执行者，作为商品展示资格的依据之一。审核记录负责留痕，不直接改写商品生命周期；商品状态由审核结论与其他条件汇总得出。

边界：审核记录不能与商品状态混同（BR-33）；审核记录只承载商品审核，不承担举报处理（C-12／C-13）。

## 主要业务属性

被审核内容及其范围、审核者、审核时间、结论（通过／不通过）、拒绝理由。不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 审核记录—商品 | 0..* : 1 | 首审、拒绝重提可形成多条结论，历史保留 |
| 审核记录—管理员 | 0..* : 1 | 限该事项认领人 |

## 关联规则、场景与用例

- 商品发布后由认领管理员审核，通过后才公开：BR-10、BR-33、BR-51。
- 审核不通过须显示拒绝原因：BR-14、TR-02。
- 审核检查描述与图片清晰、分类与价格合理完整、是否含明显违规或与二手交易无关内容：BR-33。
- 审核结论记录审核者、时间及拒绝理由：BR-33、TR-22。
- 场景：SC-02；用例：UC-C02、UC-C08。

## 状态归属

结果表述：待处理（进入共享待处理池、尚未认领）、通过、不通过（含拒绝理由）。审核记录不设“商品状态”，也不因处置解除而改写。同一商品多次重提是否新增记录为候选：建议每次重提形成新结论并保留历史，待负责人确认。

## 待决与边界

- 重提是否新增审核记录、是否保存被审核内容版本（候选：保留，便于追溯），待评审确认。
- 认领归属变化（如原认领人不在）不在规则中出现，不预设转派功能（BR-51 明确不新增转派）。
