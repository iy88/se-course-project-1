# C-14 账户限制记录

状态：候选类分析初稿，负责人张新悦；未开展人工模型评审，不表示类职责已确认。

## 职责与边界

记录账户封禁及解除的原因、执行者、时间与处置依据，支撑限制期间的权限执行与解除后按原资格恢复（BR-22、TR-24）。

边界：交易冻结不是账户限制，由交易进度的暂停标记表达（BR-53）；本类不记录买卖双方 IM 限制，也不记录商品展示资格，后者由 C-02 与 TR-11 表达。限制记录保留、不覆盖历史。

## 主要业务属性

受限账户、限制类型、原因、执行者、生效与解除时间、处置依据。不写字段类型与索引。

## 关联与数量约束

| 关联 | 重数（候选） | 说明 |
|---|---|---|
| 账户限制记录—受限账户（C-01） | 0..* : 1 | 一次封禁一条记录，解除后保留 |
| 账户限制记录—处置记录（C-13） | 0..* : 0..* | 处置依据与解除确认 |

## 关联规则、场景与用例

- 封禁后禁止发布／修改商品、交易操作、评论、IM、新增举报及评价既往已完成交易；本人相关记录保留只读：BR-22。
- 允许使用本人处置通知与沟通单与认领管理员沟通、反驳／申诉：BR-22、BR-53。
- 封禁账户可浏览原本有权查看的公共内容及本人收藏；禁止收藏／取消收藏等业务写操作：BR-22、DT-03。
- 仅交易冻结且账户未封禁时，既往已完成交易评价、其他举报与收藏操作仍允许：BR-53。
- 解除后自动恢复原权限及因处置停止的展示：BR-22、TR-24。
- 场景：SC-07；用例：UC-C08。

## 状态归属

状态：未限制、封禁生效、已解除（记录保留）。封禁与交易冻结分别表达，不能以“冻结”替代封禁，也不能因单方确认或争议解决自动解除（BR-53）。

## 待决与边界

- 是否存在仅冻结而无账户封禁的独立限制记录：候选结论为不新建，冻结由交易进度表达；待评审确认。
- P-22：处置告知与申诉对象范围影响本类与 C-13 的协作方式。
