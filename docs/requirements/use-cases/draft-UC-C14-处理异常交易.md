# UC-C14 处理异常交易

| 要素 | 内容 |
|---|---|
| 编号／名称 | UC-C14 处理异常交易 |
| 参与者 | R-04 平台管理员；R-02 买方、R-03 卖方（该笔交易双方） |
| 触发 | 一方确认完成后另一方未回应，达到暂定阈值（初定 7 天）（BR-04、BR-09、TR-15） |
| 前置条件 | ① 交易处于进行中且已记录一方完成确认；② 未进入争议状态；③ 双方账户未另行封禁 |
| 正常流程 | ① 一方确认后记录确认进度并计算未回应时间（BR-04、TR-15）；② 达到暂定阈值，交易转为异常交易，锁单不释放（BR-04、TR-15）；③ 按冻结规则限制双方上架与交易操作，禁止该笔交易双方 IM，保留处置通知与沟通单（BR-53）；④ 异常事项进入共享待处理池并由管理员认领（BR-51）；⑤ 管理员记录处置结论并解除限制，按原资格恢复（BR-53、TR-24） |
| 替代流程 | A1 另一方在阈值内回应或确认：按正常确认流程继续，不进入异常（BR-03、BR-04）｜A2 任一方说明后发起争议：视为有效响应，未回应计时结束（BR-04、BR-06、TR-17）｜A3 争议解决并恢复进行中：清空双方当前完成确认、保留历史，重新单方确认后才重启完整计时（BR-30、TR-21）｜A4 双方一致终止：记为已终止并计为失败交易，解除锁单（BR-05、BR-29、TR-20） |
| 异常流程 | E1 自动完成或自动取消交易：不允许（BR-09）｜E2 管理员替双方确认交付：不允许（BR-08、BR-30）｜E3 冻结期间视为交易完成或终止：不允许，冻结保留进度与历史（BR-53）｜E4 处理方式、恢复路径与是否承诺时限尚未决定，按待决项处理，不预填（P-21） |
| 后置结果 | 异常交易标记与冻结限制记录保留；确认历史与交易进度不删除；解除后按原资格恢复，不将非在售商品变为在售（BR-22、TR-11） |
| 关联规则 | BR-03—BR-06、BR-08、BR-09、BR-22、BR-29、BR-30、BR-53；TR-15—TR-17、TR-20、TR-21、TR-24；DT-04 |
| 关联需求、故事、场景与类 | FR-14、US-14、SC-05、SC-06；C-09、C-10、C-13 |
| 验收条件 | ① 单方确认不触发自动完成或自动取消；② 未回应达到暂定阈值后交易进入异常交易，并限制双方上架、交易与涉事 IM；③ 进入争议即结束未回应计时；④ 争议恢复后须重新单方确认并重启完整计时；⑤ 管理员处理不代替双方确认交付；⑥ 解除后原权限恢复，非在售商品不自动上架 |
