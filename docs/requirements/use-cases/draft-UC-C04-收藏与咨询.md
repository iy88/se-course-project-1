# UC-C04 收藏与咨询

| 要素 | 内容 |
|---|---|
| 编号／名称 | UC-C04 收藏与咨询 |
| 参与者 | R-01 校园用户（收藏与评论）；R-02 买方（发起会话）；R-03 卖方（回复、会话一方） |
| 触发 | 用户收藏或取消收藏；登录用户在商品页发表评论或卖方回复；买方从商品页发起会话或双方发送消息 |
| 前置条件 | ① 已登录（BR-38）；② 商品公开可交易或处于交易中（评论 BR-47、新建会话 BR-27）；③ 账户未封禁、该笔交易未冻结（BR-22、BR-53） |
| 正常流程 | ① 收藏或取消收藏公开商品，清单仅本人可见（BR-23）；② 登录用户在允许评论的阶段发表评论，该商品卖方回复买方评论（BR-47）；③ 买方从商品页向该商品卖方发起私人文字会话（BR-17）；④ 同商品同买卖双方已有会话时沿用，不新建并行会话（BR-48）；⑤ 双方发送文字消息，会话列表显示未读提示（BR-26） |
| 替代流程 | A1 商品交易中或已售出：退出在售搜索但登录用户仍可查看详情与状态，交易中可评论、已售出不可评论或回复（BR-27、BR-46）｜A2 商品被撤销公开访问：收藏仅显示失效提示，不泄露内容（BR-23）｜A3 会话已存在：继续沿用原会话（BR-48） |
| 异常流程 | E1 非会话成员访问会话或消息：拒绝（BR-17）｜E2 向本人发起私聊：拒绝（BR-28）｜E3 账户封禁：可读原资格公共内容与本人收藏，禁止评论、发送及收藏写操作（BR-22）｜E4 交易被冻结：禁止该笔交易双方 IM，处置通知与沟通单不受影响（BR-53）｜E5 评论长度与发表频率：阈值留待设计（BR-47） |
| 后置结果 | 收藏清单更新；评论与回复按作者及认领管理员权限留存或移除（BR-26）；会话与消息保留，参与者可查看历史（BR-27） |
| 关联规则 | BR-16—BR-18、BR-22、BR-23、BR-26—BR-28、BR-38、BR-46—BR-48、BR-53 |
| 关联需求、故事、场景与类 | FR-04、US-04、SC-03、SC-04；C-05、C-06、C-07、C-08 |
| 验收条件 | ① 未登录访客无法访问收藏、评论与会话；② 已售出商品不能新增评论或回复；③ 同商品同买卖双方不出现并行会话；④ 非会话成员无法读取消息；⑤ 封禁期间可读原资格内容但写操作被拒绝；⑥ 冻结期间该笔交易双方 IM 被禁止而处置沟通单可用；⑦ 删除评论仅限作者或该事项认领管理员 |
