# UC-C08 审核与处置沟通

| 要素 | 内容 |
|---|---|
| 编号／名称 | UC-C08 审核与处置沟通 |
| 参与者 | R-04 平台管理员；R-01 受处置用户；R-01 举报人 |
| 触发 | 待处理事项进入共享池并被认领；用户通过处置通知与沟通单提交说明、反驳或申诉；管理员回复或解除限制 |
| 前置条件 | ① 管理员已登录且为该事项认领人（BR-51）；② 事项未处理完毕（BR-20、BR-21） |
| 正常流程 | ① 管理员在共享待处理池认领事项，同一事项同时仅归属一名管理员（BR-51）；② 仅按事项必要范围查阅非公开记录，私聊消息限于相关举报或争议处理（BR-18、BR-51）；③ 形成结论并记录处置结论与理由（BR-21、TR-23）；④ 按结论不予处理、移除违规内容或封禁账户；违规涉及交易时冻结整个交易进度并撤销涉事商品公开访问（BR-21、BR-53、TR-10）；⑤ 通过处置通知与沟通单告知原因、范围与状态（BR-22、BR-53）；⑥ 管理员确认问题解决后解除限制，按原资格恢复权限及因处置停止的展示（BR-22、TR-11、TR-24） |
| 替代流程 | A1 证据不足：记录无法认定，维持原状态，不推定平台外付款或交付事实（BR-21、DT-05）｜A2 举报成立：移除违规内容并记录理由，举报结果经确认后隐去用户与管理员信息向登录用户公开（BR-20、BR-50）｜A3 用户反驳或申诉：通过同一沟通单说明，管理员在事项内回复（BR-22、BR-53）｜A4 解除后商品恢复：仅恢复原展示资格，不将非在售商品变为在售（BR-22、TR-11） |
| 异常流程 | E1 非该事项认领人尝试处置：拒绝（BR-51）｜E2 超出必要范围访问私人会话：拒绝（BR-18）｜E3 冻结期间将交易判为完成或终止：不允许，冻结保留历史与进度（BR-53）｜E4 要求承诺处理时限：规则不设承诺时限（BR-50） |
| 后置结果 | 处置记录与账户限制记录保留执行者、结论、理由及解除情况（TR-22—TR-24）；处置通知与沟通单留存管理沟通；举报结果确认后公开 |
| 关联规则 | BR-08、BR-18、BR-20—BR-22、BR-26、BR-33、BR-40、BR-48、BR-50、BR-51、BR-53；TR-10、TR-11、TR-22—TR-24；DT-03、DT-05 |
| 关联需求、故事、场景与类 | FR-08、US-08、SC-07；C-01、C-12、C-13、C-14 |
| 验收条件 | ① 同一事项同时仅一名认领人可处置；② 处置记录含结论与理由；③ 举报结果确认前不可见，确认后隐去用户与管理员信息；④ 冻结期间交易不得被判为完成或终止；⑤ 封禁期间用户可读原资格内容，仅通过沟通单与管理方交互；⑥ 解除后原权限与展示资格恢复，非在售商品不自动上架 |
