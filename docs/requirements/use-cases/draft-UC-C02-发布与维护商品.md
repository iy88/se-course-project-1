# UC-C02 发布与维护商品

| 要素 | 内容 |
|---|---|
| 编号／名称 | UC-C02 发布与维护商品 |
| 参与者 | R-03 卖方；R-04 平台管理员（认领审核事项） |
| 触发 | 卖方提交发布、修改信息或上架／下架；管理员处理本人认领的待审事项 |
| 前置条件 | ① 已登录，且未处于封禁或交易冻结导致的上架限制（BR-22、BR-53）；② 操作对象为本人商品；③ 修改关键内容时商品不处于交易中或已售出（BR-15） |
| 正常流程 | ① 卖方填写标题、描述、图片、价格、分类并提交（BR-12）；② 商品进入待审核，进入共享待处理池并由一名管理员认领（BR-51）；③ 认领管理员按 BR-33 审核，记录结论、时间与拒绝理由（TR-01、TR-22）；④ 审核通过后商品公开可交易，进入在售搜索与详情（BR-10、BR-24）；⑤ 卖方修改信息按微调处理，不触发二次审核、不暂停公开、不关闭已有待接受请求（BR-11、TR-04）；⑥ 无锁单交易时卖方可主动下架（BR-07） |
| 替代流程 | A1 审核不通过：向卖方显示拒绝原因，商品不公开，修改后可重新提交（BR-14、TR-02、TR-03）｜A2 商品处于交易中或已售出：禁止修改关键内容（BR-15）｜A3 存在未结束且仍锁单的交易：禁止卖方主动下架，须先由双方终止（BR-07）｜A4 下架时存在待接受请求：请求记为已关闭，说明原因为商品已下架（BR-31、BR-42） |
| 异常流程 | E1 未登录访客：仅可使用注册、登录、忘记密码入口（BR-38）｜E2 账户封禁或交易冻结：上架与修改入口被拒绝，处置通知与沟通单仍可用（BR-22、BR-53）｜E3 操作他人商品：拒绝｜E4 待审事项已被其他管理员认领：不重复处理（BR-51） |
| 后置结果 | 商品处于待审核、公开可交易、审核未通过或下架；审核记录保留审核者、时间、结论与拒绝理由（TR-22）；已有待接受请求按保留或关闭原因记录 |
| 关联规则 | BR-07、BR-10—BR-15、BR-22、BR-24、BR-31、BR-33、BR-40、BR-42、BR-51、BR-53；TR-01—TR-04、TR-08、TR-22 |
| 关联需求、故事、场景与类 | FR-02、US-02、SC-02；C-01、C-02、C-04 |
| 验收条件 | ① 未通过审核的商品不出现在在售搜索；② 审核不通过时卖方可见拒绝原因并可修改重提；③ 信息修改不触发二次审核、不暂停公开、不关闭已有待接受请求；④ 存在锁单交易时无法主动下架；⑤ 下架后原待接受请求记为已关闭并注明原因；⑥ 封禁或冻结期间上架与修改被拒绝；⑦ 审核记录含审核者、时间与结论 |
