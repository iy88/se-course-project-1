## 4.2 交易业务规则（BR-01—BR-09）

确认依据：[E-01，D-08](../evidence/E-01-范围讨论结果.md)。付款与实际交付均在平台外完成。

| 编号 | 已采纳规则 |
|---|---|
| BR-01 | 买方在商品页发起交易请求，由该商品卖方接受或拒绝。“交易请求”承接题目中的“下单”，不涉及线上付款。 |
| BR-02 | 卖方接受后，商品进入“交易中”，停止接受新交易；同一商品只能有一笔进行中的交易。 |
| BR-03 | 买卖双方分别确认完成；仅双方均确认后交易完成，商品标记为“已售出”。 |
| BR-04 | 仅一方确认时，记录该方已确认，交易保持进行中，等待另一方确认；不将单方确认等同于双方已交付。 |
| BR-05 | 卖方接受前，买方可撤回请求；接受后，一方提出终止，另一方同意后关闭交易。 |
| BR-06 | 双方对结果存在争议时，标记为“有争议”，保留双方记录，可提交管理员处理；不自动判断平台外付款、交付事实。 |
| BR-07 | 交易失败后，由卖方决定重新上架或下架，系统不因失败自动恢复为可交易商品。 |
| BR-08 | 管理员可查看争议相关记录、处理举报与违规，不承担付款核实、退款或赔付责任；证据不足时保留争议，不替双方认定交易完成。 |
| BR-09 | 首版不设置自动确认完成或自动超时取消。 |

基本流程：买方发起请求 → 卖方接受 → 双方平台外付款、交付 → 双方分别确认 → 平台记录交易完成。

### 交易权限矩阵

以下矩阵仅覆盖已采纳交易规则；账户封禁等跨业务限制见 BR-22。

| 操作 | 执行角色及对象范围 | 条件与限制 | 关联规则 |
|---|---|---|---|
| 发起交易请求 | 拟购买商品的买方 | 对应目标商品；允许请求的商品状态等前置条件待用例细化 | BR-01、BR-02 |
| 接受／拒绝请求 | 请求所关联商品的卖方 | 只能处理自己商品的请求；同一商品不得产生多笔进行中交易 | BR-01、BR-02 |
| 撤回请求 | 请求发起买方 | 仅自己的请求，且卖方尚未接受 | BR-05 |
| 确认完成 | 该笔交易的买方、卖方 | 各自确认本人一方；双方确认后才完成，不得代对方确认 | BR-03、BR-04 |
| 提出终止／同意终止 | 该笔交易双方 | 接受后一方提出，由另一方同意后关闭 | BR-05 |
| 选择重新上架或下架 | 失败交易所关联商品的卖方 | 仅自己的商品；重新上架需重新审核，见 BR-31 | BR-07 |
| 查看争议相关记录、处理举报与违规 | 平台管理员 | 限相关处置范围，不承担付款核实、退款或赔付；可查信息类别另行细化 | BR-06、BR-08 |

## 4.3 商品发布与审核（BR-10—BR-15）

确认依据：[E-01，D-09、D-10](../evidence/E-01-范围讨论结果.md)。以下原则已由组长确认，审核标准见 BR-33，交叉场景仍待验证。

| 编号 | 已采纳规则 |
|---|---|
| BR-10 | 商品发布后由平台管理员审核，通过审核后才对其他用户公开展示。 |
| BR-11 | 商品修改关键内容后需要重新审核。 |
| BR-12 | 商品关键内容包括标题、描述、图片、价格、分类。 |
| BR-13 | 重新审核期间，商品暂停向其他用户公开展示；审核通过后恢复展示。 |
| BR-14 | 审核不通过时，向卖方显示拒绝原因；卖方修改后可重新提交审核。 |
| BR-15 | 商品处于“交易中”或“已售出”时，禁止卖方修改上述关键内容。 |

| 操作 | 执行角色及对象范围 | 条件与限制 | 关联规则 |
|---|---|---|---|
| 发布商品 | 校园用户，作为该商品卖方 | 发布后须经管理员审核通过才公开展示 | BR-10 |
| 审核商品 | 平台管理员 | 审核待审商品；审核不通过须向卖方显示原因；具体审核标准和处置记录待细化 | BR-10、BR-11、BR-14 |
| 修改关键内容 | 该商品卖方 | 仅修改自己的商品；标题、描述、图片、价格、分类修改后重新审核，重审期间暂停公开展示；交易中或已售出禁止修改 | BR-11—BR-13、BR-15 |
| 修改后重新提交审核 | 被拒商品的卖方 | 仅自己的商品；根据拒绝原因修改后重新提交 | BR-14 |

| 因举报或争议查看消息 | 平台管理员 | 仅限具体举报或争议处理所需的相关消息；不允许日常任意浏览私人会话 | BR-18 |

## 4.5 账户与访问规则（BR-35—BR-39）

依据：本轮起草，用于填补 FR-01 与开放项 P-01 的空缺。其中 BR-38 已于 2026-10-16 经组长确认（[E-01 D-13](../evidence/E-01-范围讨论结果.md)）；BR-35—BR-37、BR-39 仍属建议口径，确认前不作为已确认规则使用。

| 编号 | 规则（BR-38 已确认，其余待确认） |
|---|---|
| BR-35 | 校园用户以邮箱或手机号作为账户标识，配合密码普通注册；首版不进行校园身份、学籍或教职工身份核验，与“单校场景、普通注册”的范围摘要一致。注册字段最小集为账户标识、显示名称、密码；是否需要其他字段待确认。 |
| BR-36 | 账户标识在同一平台内唯一；重复注册应被拒绝并提示标识已存在，不自动合并或接管既有账户。首版不设置登录失败次数阈值与自动锁定；是否引入及阈值待确认。 |
| BR-37 | 首版不提供用户自助找回密码；账户访问受阻时由平台管理员按流程协助重置，并记录操作者、时间与理由。是否纳入自助恢复方式待确认。 |
| BR-38 | 未登录访客只可浏览公开商品列表、商品详情与公开评论；不能发布或修改商品、收藏、发表评论、发起会话、发起交易、评价或举报。该边界于 2026-10-16 经组长确认（E-01 D-13）。 |
| BR-39 | 首版不提供“仅本人可见”的私密发布或分组可见设置；商品审核通过后即对所有校园用户公开，未公开即不可浏览，与 BR-24 一致。 |

| 操作 | 执行角色及对象范围 | 条件与限制 | 关联规则 |
|---|---|---|---|
| 注册账户 | 未登录访客 | 账户标识唯一，不核验校园身份；字段范围待确认 | BR-35、BR-36 |
| 登录与访问 | 已注册校园用户 | 不设失败锁定；账户访问受阻时走管理员协助重置 | BR-36、BR-37 |
| 浏览公开商品与评论 | 未登录访客、登录用户 | 仅已公开展示的商品及其公开评论 | BR-16、BR-24、BR-38 |
| 登录后受限操作 | 未登录访客 | 收藏、评论、会话、交易、评价、举报均要求登录 | BR-38 |

## 4.9 补充业务规则（BR-19—BR-34）

依据：[E-01，D-12](../evidence/E-01-范围讨论结果.md)。组长授权按助手建议批量补齐，作为当前工作设定；不是已开展人工走查或外部业务确认的证明。

| 编号 | 规则 |
|---|---|
| BR-19 | 交易完成后双方可互评，每方每笔交易一条评价，包含 1—5 分评分及文字；不得评价未完成交易或代他人评价。首版不支持用户修改已提交评价，管理员可处理违规评价并记录理由。评分范围为项目设定。 |
| BR-20 | 登录用户可举报商品、评论、消息、评价或用户，提交理由及可选证据；举报者查看本人举报的处理结果，被举报对象不因举报自动判定违规。 |
| BR-21 | 管理员按举报核查，记录处理结论及理由，可不予处理、移除违规内容或封禁违规账户；证据不足记录无法认定，不推定平台外付款、交付事实。 |
| BR-22 | 封禁账户不得发布或修改商品、发起或接受新交易、发表评论或发送 IM；其商品停止公开展示。允许登录查看本人历史记录、处理现有交易的结果确认／终止及举报，避免现有交易无人处理；管理员可解除封禁并记录理由，商品不自动恢复上架。 |
| BR-23 | 用户可收藏／取消收藏公开商品，收藏清单仅本人可见；商品失去公开资格后清单保留失效提示，不向收藏者继续暴露未公开内容。 |
| BR-24 | 商品搜索和筛选仅返回当前公开且可供浏览的商品，支持关键词、分类和价格范围；交易中、已售出、下架、待审或被拒商品不进入公开搜索结果。 |
| BR-25 | 交易双方可查看自己交易关联的商品信息及历史沟通，其他用户不因此获得访问权限；历史交易中的商品信息保留交易时内容，后续编辑不改写历史交易记录。 |
| BR-26 | 发布者可删除本人评论，不能编辑已发布评论；违规评论可由管理员移除并记录理由。首版 IM 支持双方文字消息，不提供撤回、编辑、附件及群聊；消息不向非会话成员公开，管理员访问遵守 BR-18。 |
| BR-27 | 商品停止公开展示后，不再允许新增公开评论或新建商品咨询会话；已存在会话保留查看和沟通能力，受封禁发送限制约束。交易中或已售出的交易双方仍可访问本人相关交易及会话。 |
| BR-28 | 同一商品允许多个买方存在待接受请求，同一买方对同一商品最多一条有效待接受请求；卖方接受一条时，其他待接受请求关闭并说明原因，不产生多笔进行中交易。用户不得购买本人商品或向本人发起私聊。 |
| BR-29 | 请求被拒记为“已拒绝”，买方撤回记为“已撤回”；双方接受交易后同意终止记为“已终止”，完成记为“已完成”；统计中将已终止计为失败交易，拒绝、撤回不计入已接受交易的失败数。 |
| BR-30 | 一方确认完成后另一方提出终止或异议时，不自动关闭或完成；交易转为“有争议”，商品维持不可交易。双方达成一致后可共同确认完成或共同同意终止；管理员可记录处置意见，但不得替双方确认交付。未达成一致时保留争议。 |
| BR-31 | 失败后重新上架的商品提交管理员重新审核，通过后公开；拒绝、撤回等尚未被接受的请求本身不改变原商品公开状态。 |
| BR-32 | 线下交付记录由交易双方各自确认完成时提交，记录确认人、确认时间及可选交付说明；不强制上传凭证、精确位置或支付信息。双方确认记录分别保存，不允许覆盖对方记录。 |
| BR-33 | 商品审核检查描述与图片是否清晰、分类及价格是否合理完整、是否含明显违规或与二手物品交易无关内容；禁止物品细目由管理员维护并向用户展示，不宣称该教学规则已覆盖全部现实监管要求。审核结论记录审核者、时间及拒绝理由。 |

## 4.12 决策表（DT-01—DT-05）

决策表用于说明多条规则同时成立时的处理顺序与状态保持，均为文本推演结果，尚未经人工场景走查。

### DT-01 卖方接受后的并行请求处置

| 情形 | 处理结果 | 状态保持 | 关联规则 |
|---|---|---|---|
| 同一商品存在多条待接受请求，卖方接受其中一条 | 被接受请求进入“进行中”，其余待接受请求关闭并说明原因 | 其余请求记为“已拒绝”且不计入已接受交易的失败数 | BR-01、BR-02、BR-28、BR-29 |
| 其余请求尚未被处理，卖方已接受另一条 | 由系统在卖方接受时统一关闭其余待接受请求 | 商品进入“交易中”，不再接受新请求 | BR-02、BR-28 |
| 买方在卖方接受前撤回 | 该请求记为“已撤回”，不影响其他待接受请求 | 商品维持原公开状态 | BR-05、BR-29、BR-31 |
| 请求长期未被处理 | 不自动过期、不自动取消 | 请求持续有效，等待卖方处理 | BR-09、BR-42 |

### DT-02 商品展示状态与交易请求的交叉

| 商品情况 | 是否可收到或保留请求 | 处理结果 | 关联规则 |
|---|---|---|---|
| 待审核、审核未通过、重审中 | 不接受新请求（未公开） | 请求入口不对该商品开放 | BR-10、BR-13、BR-24 |
| 公开可交易 | 可存在多条待接受请求 | 由卖方接受其中一条，见 DT-01 | BR-01、BR-28 |
| 交易中 | 不接受新请求 | 已有进行中交易继续；其他待接受请求已按 DT-01 关闭 | BR-02、BR-28 |
| 已售出 | 不接受新请求 | 交易完成后的商品不再进入交易流程 | BR-03、BR-24 |
| 下架或因违规停止公开 | 不接受新请求 | 进行中交易不自动关闭，双方仍可确认或终止；管理员处置留痕，不替双方认定平台外事实 | BR-08、BR-21、BR-27、BR-30 |
| 交易失败后重新上架 | 需重新审核，通过后方可被请求 | 拒绝、撤回等未被接受的请求本身不改变原公开状态 | BR-07、BR-31 |

### DT-03 账户封禁与已有业务

| 情形 | 系统处理 | 关联规则 |
|---|---|---|
| 封禁账户为卖方且存在进行中交易 | 交易保留；不得发布或修改商品、不接受新请求；双方仍可提交确认或终止 | BR-03、BR-05、BR-22 |
| 封禁账户为买方且存在进行中交易 | 交易保留；不得发起新请求；仍可确认或终止现有交易 | BR-22 |
| 封禁账户的商品 | 停止公开展示；已存在会话与进行中交易记录保留 | BR-22、BR-27 |
| 封禁账户参与会话 | 会话保留查看；封禁期间不得发送新消息 | BR-22、BR-26 |
| 封禁解除 | 可重新发布与交易；原商品不自动恢复上架，需重新审核后公开 | BR-22、BR-31 |
| 封禁账户提交举报或评价 | 举报允许；评价资格待确认，不因封禁直接取消其既有交易资格 | BR-19、BR-20、BR-22 |

### DT-04 一方确认后另一方终止或异议

| 情形 | 处理结果 | 商品状态 | 关联规则 |
|---|---|---|---|
| 一方确认完成，另一方未确认且未提出异议 | 交易保持“进行中”，记录已确认方 | 维持“交易中”，不可交易 | BR-04 |
| 一方确认完成，另一方提出终止 | 不自动关闭；转为“有争议”并保留双方记录 | 维持不可交易 | BR-30 |
| 一方确认完成，另一方明确异议 | 转为“有争议” | 维持不可交易 | BR-06、BR-30 |
| 双方均确认完成 | 交易“已完成”，商品“已售出” | 已售出，不可交易 | BR-03 |
| 双方同意终止 | 交易“已终止”，统计中计为失败交易 | 由卖方决定重新上架或下架，重新上架需重审 | BR-05、BR-29、BR-31 |
| 双方未达成一致 | 保留“有争议”，管理员可记录处置意见，不替双方确认交付 | 维持不可交易 | BR-08、BR-30 |

### DT-05 举报处置与内容、商品公开状态

| 情形 | 处理结果 | 关联规则 |
|---|---|---|
| 举报提交但无证据或证据不足 | 记录“无法认定”，商品维持原公开状态；不推定平台外付款或交付事实 | BR-21 |
| 举报成立且内容违规 | 移除违规内容并记录理由；必要时停止商品公开展示 | BR-21、BR-27、BR-33 |
| 举报涉及私聊消息 | 管理员仅查看与该举报或争议相关的消息 | BR-18 |
| 被举报对象未被认定违规 | 不因举报自动判定违规、不自动封禁 | BR-20、BR-21 |
| 举报人对处理结果有异议 | 可查看本人举报的处理结果；是否支持申诉待确认 | BR-20 |
